## Regression 4: Missing Per-Filter Descriptions

### Current State (Incorrect)
Each filter row shows:
- Filter name (formatted)
- Threshold value (if available)
- Count/status badge

**Missing**: Description text explaining what each filter does

### Expected State (Phase 8.7 Final)
Each visible filter row should have:
- Filter name
- **Description paragraph** (e.g., "This filter excludes pairs with very low daily volume...")
- Threshold value
- Count/status badge

Example Phase 8.7 structure:
```jsx
<div className="filter-row">
  <h4>Min Volume</h4>
  <p className="description">
    This filter excludes pairs with very low daily volume that may have 
    liquidity issues or high slippage risk.
  </p>
  <span className="threshold">Threshold: ≥ $5,000</span>
  <Badge>{count}</Badge>
</div>
```

### Affected Files

  - Lines 310-366: Breakdown row rendering needs description text

1. User-friendly (non-technical)
2. Explain WHY the filter exists
3. ~1-2 sentences each
4. Positioned between filter name and threshold
