## 4. Objectives (each with its verification)
- **OBJ-1 — a "money held" balance, one function: the anchor VALUE and its TIME come from ONE anchor event (Langston C-1).** `money held = portfolio_state.balance + realized P&L closed since the anchor event that WROTE that balance`. That event is found by `portfolio_state.anchor_version` → the `portfolio_anchor_events` row with the same `(mode, anchor_version)` (unique index `portfolio_anchor_events_mode_version_idx`); `executeReanchor` writes both in one transaction (`portfolio-anchor-service.ts:133-189`), so they are one event by construction, whatever its reason. **Chosen over "operator anchors only, with the automatic re-anchor's delta netted out", and why:** an `auto_divergence` re-anchor is a mirror reconcile — a MEASUREMENT of money held — so for this question it is a valid starting point, and the realized P&L before it is already inside the value it wrote. The kill switch's window asks a different question (which losses still count against today's budget, `#1171`), which is why it excludes `auto_divergence`; this batch does not reuse `getLastAnchorAt(OPERATOR_REBASE_REASONS)` for that reason. **Fail-closed on a broken pair:** no ledger row for the state row's version, or a ledger `new_balance` that differs from `portfolio_state.balance`, ⇒ the function does not guess; Step 2 sets what the sizing callers do then (a refusal there is not the kill-switch catastrophe the null-session comment describes, because this function does not feed the kill switch). Step 2 also censuses every writer of `portfolio_state.balance` to confirm `executeReanchor` is the only one. **The measured case this rules out:** v4 `auto_divergence` (2026-08-12, 2250.00 → 824.11) came after v3 `measurement_override` (07-16); operator-time pairing would have added the 420 closes / −$315.33 between them that v4 had already absorbed, returning $508.78 against $824.11 measured (38% low). *Verify:* unit tests over a restart (realized before it still counts), over an operator re-anchor (realized before it does not), over an `auto_divergence` re-anchor that follows an operator one (realized before the auto event does not count — the v3/v4 shape), and the broken-pair refusal; a fence that both functions use `getRealizedPnlSince`.
