### 2.1 OBJ-1 — THE CREW-LOGIN DESIGN
1. **Setting the password.** A root script on staging generates a random value that passes `validatePasswordStrength` (`server/services/auth-service.ts:10-16`). It writes the value **only** to `/etc/dawntrader/staging-api.env` (**`0600 root:root`**), and **writes the bcrypt hash (cost 10, as `hashPassword` does) directly to `users.password` for `testuser123`**. ⚠️ **It cannot use the admin route:** that route needs an admin session (`routes.ts:1196`), and after OBJ-0 no session holds an admin password. The value is never printed.
2. **`dt-api <METHOD> <path>`** (the JSON body comes on stdin) runs as **root**, talks only to `http://localhost:5000`, accepts only `GET/POST/PUT/PATCH/DELETE`, requires the path to start with `/api/`, and uses no shell. ⚠️ **It caches its 7-day token** in a root-only file and logs in again only on a 401 or expiry. The login limiter allows **5 logins per 15 min per IP and counts successful ones** (`routes.ts:86-92`, applied at `:941`). With `trust proxy = 2` (`server/index.ts:175`), every localhost caller shares one IP, so logging in on every call would give the whole crew **5 calls per 15 minutes**.
3. **Langston's access.** A **sudoers entry lets `deploy` run exactly `/usr/local/bin/dt-api` with NOPASSWD**, and nothing else. The four sessions reach it as root; Langston reaches it over his existing `deploy@` key. He **uses** the login and **cannot read** the file.
4. **Coltrane's access.** Coltrane has no staging shell, so it uses its browser session only. `agent-staging-session` mints that session over Langston's existing staging key, through `dt-api`. **Both** Helsinki password files are retired: `/etc/langston/staging.env` **and `/etc/coltrane/staging.env`** (`comms-infra/agent-staging-session:43,:172-177`). So is the script's login over the public host (`:46`).
5. ⚠️ **A trade, stated rather than hidden:** both agents hold a **7-day owner-role bearer token** on Helsinki, as they did before this batch. A password rotation does not revoke it; only OBJ-0b (a new signing secret) does.
