## Implementation plan

1. **Carry one immutable quote from the judged frame** (A1, A3, A4). Bind each socket's callbacks to the socket and its generation at installation. Drop retired-socket callbacks before they can stamp raw or affect the new connection's lifecycle. On parse record frame identity, source envelope, monotonic receipt and the delivering generation. Require a usable `update` from the current connected generation. Neither inherited mark freshness, a snapshot arriving after reconnect, nor wall-clock equality with another frame qualifies. No venue timestamp is available. Pass the exact frame, symbol, position ID, mode/class, cause and actual trigger basis to the fill boundary. Keep mark audit fields and TEC switches. In either `guard_off` or `spread_blown_off`, a mark above target can still authorize a policy-permitted taker conversion with a qualified full bid below target. Record mark decision and raw fill separately. Maker-only cannot convert a target. A genuine stop while resting remains a taker path. Disconnection/reconnect retires the old fill generation while preserving the separate mark/cache contracts.
2. **Check each eligible taker fill at consumption** (A1–A4). Include normal price stops/targets, genuine price-based stop variants if enabled and permitted conversion/rest paths. Classify by actual cause so a time-only exit stays outside the freshness gate despite any shared category label. Keep size trace-only at the trigger. After position/config awaits, match the re-read position, require plausible uncrossed sides, a finite positive bid and `bidQty >= current requested quantity` in units. Immediately before simulated fill acceptance, recheck the delivering generation and monotonic age with no intervening external await. At storage precision, record only the accepted bid and require full requested units walked and zero extrapolation. Attach typed frame provenance and the separate actual bases to the close metadata. Preserve mark, independent ticker witness and archive-depth-age meanings. The older archive and later raw cache entry are diagnostic only. Persist the resulting simulated fill without further repricing.
3. **Retry and report without booking a fictitious exit** (A1–A3). When the selected quote fails, leave the position open. Neither archive walk, `walk_yield`, nor extrapolation may let this subset exit. Separate stale/replay, malformed book, unknown size and short size in existing close/size diagnostics. Take the next independent monitor evaluation. A recovered price that no longer triggers leaves the position open. Retain existing lifecycle changes such as expired maker rest removal, mark/P&L updates and paused TEC rules. Reuse per-position refusal bookkeeping only if it can keep these counters separate from yield and paging. Bound repeated logging with one at-cap marker per episode, candidate 60 eligible refused attempts for comparison, continue rechecking without forced close, and end on an evaluable clear or closure/removal. Expected thin or quiet episodes page nobody. Reuse existing impairment alerts and operator escape. Restarts can end the diagnostic episode and must never create a pending close. Do not land a hard age budget or cap from this draft alone.
4. **Make the existing paper xStock close writer single-winner** (A3, A4). Every contending price-booking route, including operator flatten and existing maker/time-only pricing routes, uses the same conditional open-to-closed transition. Match exact trade ID, mode, class, open state and its exact open-position identity; use exact position ID with the expected mode/class/quantity to protect deletion. Keep the conditional close update and corresponding position removal in one storage transaction. If either write has no matching row or an error occurs after updating the close but before removing the position, roll back both. A losing attempt reads the actual stored result and emits no learning, exit archive, trade log, deletion or duplicate cleanup. Only the committed winner can emit post-commit side effects. Guard local cleanup so a retry only reconciles an already removed position and cannot repost a close or remove a replacement. Missing or ambiguous legacy links fail closed; do not infer a winner from symbol alone. Preserve operator's one-attempt observed-price fallback, loss/learning fences and stored `closed` versus `left_open` truth. Existing metadata/open updates keep their normal contract. Test real DB conditional semantics with each monitor/flatten ordering, no row, failed transaction, and after-commit cleanup interruption. This change follows the paper xStock write race, whereas only price-triggered taker cases receive the new fill eligibility check.
