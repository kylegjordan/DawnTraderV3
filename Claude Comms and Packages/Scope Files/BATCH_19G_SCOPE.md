## Items

### 1. DB-Driven Filter Architecture (CRITICAL)

**Problem:** Filter values come from multiple sources — DB `screener_filters` table (quant global), hardcoded `pattern-global-filters.ts` (pattern global), hardcoded `VTS_IMF_THRESHOLDS` in `system-guards.ts` (VTS IMF). The 4-column UI display shows hardcoded values that don't match the DB. The old editable input fields (Min Volume: 5,000, etc.) feed different values than what the system uses.

**Fix:**

a) **Schema migration:** Add `filter_path` column to `screener_filters` table with values: `'active_quant'`, `'active_pattern'`, `'vts_quant'`, `'vts_pattern'`. The existing row becomes `active_quant`. Seed 3 new rows per mode (paper/live) with correct values for each path. ALL fields populated (minVolume, minLiquidity, minPrice, maxPrice, maxBidAskSpread, minMarketCap, excludeStablecoins, regulatedOnly, activeTimeframes, minHistoryDays, plus IMF thresholds: LQ_MIN, VN_MAX, CORR_MAX, DI_MIN).

b) **Code changes:**
- `fx5-scanner.ts`: Load 4 DB rows per mode. Pass correct row to `collectAdaptiveBatch()` for each filter path.
- `market-scanner.ts`: `collectAdaptiveBatch()` receives filter values from DB row, not hardcoded configs.
- Pattern IMF thresholds: Read from DB instead of `pattern-filter-profile.ts` static values.
- VTS IMF thresholds: Read from DB instead of `system-guards.ts` `VTS_IMF_THRESHOLDS`.

c) **Remove old UI inputs:** The legacy editable filter fields (Min Volume, Min Liquidity, Min Price, Max Price, Max Spread, etc.) that fed the old single-row DB are removed from the Screeners tab. Replaced by the read-only 4-column table (expanded to show ALL fields).

d) **API update:** `/api/vts/imf-status` reads all 4 DB rows. Returns actual configured values, not hardcoded numbers.

e) **4-column table expansion:** Show ALL DB fields per column, not just the current 6 (Volume, Spread, History, LQ, VN, Corr). Add: Min Price, Max Price, Min Liquidity, Min Market Cap, Exclude Stablecoins, DI Min, Active Timeframes. Read-only for now.
