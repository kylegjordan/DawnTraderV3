### Audit aid blind spots

- Value lists and database enums: no enum changes or list-equivalence claims.
- Literal copies: the proposed comparison uses the same code/config per episode. Do not duplicate thresholds as an independent source of truth.
- Fields/properties: first held bid, latest/minimum release, episode resets and timestamps were read in their real writers.
- Sibling producers: distinguish per-position release log and close summary from the per-symbol comparator and the separately sampled quote archive.
- Site meaning: a guard release precedes the downstream selector and fill. A sampled quote or trade close alone cannot prove evaluation or quote consumption.
- Error paths: no archive hit, query/read failure, partial timestamp coverage and runtime failure carry distinct labels.
- Library behavior: no library behavior or policy assumptions needed for the comparison.
- Scripts outside TypeScript program: the existing recut helper intentionally substitutes archived context where exact frames are missing. It is not an exact replay source and was not run.

## Implementation plan

1. **Freeze and match the existing evidence (A1–A3).** Use the fixed reconstructed close screen in A3. Give every screened close a status and allow several episodes per position. Keep the first-night 53 events and still-open/right-censored positions in separate cohorts. Join trade and position identity through the close events. A scoring match requires the position's wide yield, its actual comparator deletion with the same yield cause and prior seed, and the successor seed in the same serving process. Require continuous evidence through validation, first eligible decision, release and any booked close. Mark intervals with competing same-symbol writers, restart, unmatched deletion or missing state as partial or unavailable. Check only existing governed files and archive coverage. There is no staging rehydration or new observation.
2. **Run a matched offline comparison (A1–A3).** Begin each arm with the same reconstructed evaluator inputs and state, including the retained ring, comparator, position, stop/target, trailing high-water/locks, and fill prerequisites. Supply the same chronological feed/evaluation tape and configuration to both. Use independent state in each arm, advancing the TEC only on admitted evaluations, including stop/lock updates without a close. Stop an arm on terminal close. A pass on one side and a recorded refusal on the other can change both later timing and trigger eligibility.

   Score quote movement before deciding whether that evaluation can act on an exit. The first attributable, genuine, fresh, two-sided sub-ceiling reseed starts the movement run at zero. Count each strictly later qualifying venue update whose bid/ask pair differs from the preceding eligible pair. Both sides must each change at least once across the counted transitions. The seed and validation evaluations may refuse an exit because the pre-advance comparator is absent or unvalidated. Those two expected refusals preserve movement credit. A wide, missing, crossed, nonpositive, stale or otherwise quote-ineligible input clears credit; the next qualifying update seeds at zero. Snapshots, replayed receipts, repeat evaluations and genuine same-price updates earn zero movement and leave the preceding eligible pair in place unless the observed input is ineligible. Position-level exit checks continue to govern admission independently of the movement run. Consume the current evaluation's qualifying update before checking the two-move gate, and admit on that evaluation if both the movement gate and the existing exit checks pass.

   A known process restart or independent comparator clear ends the scored episode. A gap is unscoreable when any unobserved frame, comparator mutation or evaluation could alter the input, trailing state, eligibility, or measured difference. An independently proved run of no evaluations or unchanged admission-relevant state can bridge elapsed time. Sampled quotes alone cannot bridge missing evaluation history.

   Pin the post-clear sequence with paired fixtures. With fresh `A → B → A`, evaluations 1 and 2 refuse exit admission while the movement count reaches zero and one, respectively. Evaluation 3 earns the second move and both arms admit if the existing exit checks pass. With fresh `A → B → B`, the baseline still admits on evaluation 3 and the candidate remains at one move. Also demonstrate short hold/evaluation 1, clear with absent comparator, retained implausible chain, ordinary restart, mixed reasons, entry, VTS, crypto, opposite-direction later release, two positions sharing a symbol, frozen quotes, interruption, missing history, and diverging trailing stops on an admitted no-close tick. Log changed decisions and timing, witnessed lost opportunities, bid-to-stop change on each arm's own stop, and right-censoring. An improperly delayed GIS short-hold replay fails non-target preservation.
3. **Apply the grading rule and return for review (A2–A3).** Report coverage against the full screened denominator. Require at least one fully matched eligible episode of each kind before recommending a change. **Benefit:** the baseline decision or booked close must link to direct contemporaneous evidence the sale was unusable at that time, and the paired replay must block it. **Recovery:** a replayable decision window must contain a trigger-qualified, fresh bid with enough displayed size for the position, and the pair must show whether the candidate preserves or misses it. A below-stop release, later rebound, frozen quote, or proxy mark earns no safety credit. A blocked witnessed exit or a worsened executable outcome counts as a cost. A positive recommendation requires all preservation fixtures passing, demonstrated benefit and no countervailing missed or worsened witnessed outcome in the matched grade. Additional waiting within a preserved favorable window is reported even where the executable outcome matches. If measured costs and gains cannot be resolved in the matched evidence, keep the present rule and send the measured trade-off to Coltrane. A demonstrated candidate benefit remains a proposal for review, with no runtime or settings change.

The key comparison is whether waiting for quote movement filters a false recovery without losing a brief usable bid. The audit keeps the known paper exits as controls and gives unknowns their own count.
