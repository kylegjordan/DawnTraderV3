## 5. Plain-language summary
The queue keeps one entry per coin-and-strategy, and when a strategy issues a newer signal for the same setup, the newer one replaces the old — that is the decided rule, and it was already how the system behaved, because the code meant to choose between them never ran. Two things fall out. First, that never-run code goes. Second, the replacement is only half done today: the new signal's entry, stop and target are written, but the old signal's expected value, maker-or-taker choice and trend readings stay on the entry, so a trade can open on new prices with an old decision. The plan makes the replacement whole and adds a test so a future field cannot be left behind the same way.
