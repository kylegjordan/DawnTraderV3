## §1 — The NO_SAMPLE labeling design (Kyle directive: low-volume ≠ shutdown)
Friction status gets an explicit machine-readable `reason` everywhere it's null/absent:
- `NO_SOURCE` — the sampler's data source structurally lacks this class (today's xStock state; ERROR-grade: should never occur after this batch).
- `MARKET_CLOSED` — `isXstockMarketOpenUTC()` false / session-lifecycle weekend suspension (the ONLY legitimate "off" state; crypto never emits it).
- `LOW_VOLUME_THIN` — market open, source wired, but fewer than the per-class minimum names have fresh measurements (the genuine overnight-thin case).
- `WARMING` — post-boot/post-idle buffer fill (quantified per Langston C1: `n=k/N`).
The weather aggregator consumes the reason: `MARKET_CLOSED` → IDLE classification; `LOW_VOLUME_THIN` → LIVE weather with degraded-input staleness noted (and thin books are themselves a caution input — NOT silently ignored); `NO_SOURCE` → loud error path. The AMR IDLE state keys off `isXstockMarketOpenUTC` + voteStatus together — never off sample-absence alone.
