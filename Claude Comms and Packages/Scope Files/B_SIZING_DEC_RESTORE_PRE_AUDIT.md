### 13.3 IN PLAIN LANGUAGE
The reset can be done safely with tools that already exist, but three things have to be handled for it to hold. **The balance has to be restarted as well as set**, or trades from before the reset still count. **The closes need their own "reset" label**, which the code cannot produce today.
