**OBJ-2 — the false-HOLLOW instrument for would-refuse runs (condition 2).**
- **Durable corpus (BLOCKER-1).** `error.log` keeps 14 daily files, so a 21-day window cannot be read from it at the end. A daily extractor copies each rotated `error.log` file's `[3n.q7][XS_FRAME]`, `EVAL_EXIT` and restart/deploy marker lines into a dated, compressed archive on staging that is kept 60 days; it is idempotent (a file already extracted is skipped) and its run log names each source file and its line counts, so a missed day is visible. It runs on a schedule on staging from the deploy day; **how it is scheduled (a `deploy` crontab entry versus another existing scheduler) is a server change settled at Step 2 with Infra Claude, and the first extraction must run before day 14.**
- **A run** is consecutive `frame=ok` lines for one position with `spread > thr`. **A run ends at** a `frame=none` line, the position's close, a gap in that position's frames longer than the plan's stated tick-gap bound, a process restart, or a deploy — a restart vacates the comparator (`#1066`), so a run is never merged across one.
- **The stop and target are the per-frame `sl=` / `tp=` on the line** (not the closed row's). At analysis time both locks are re-read (`trailing_enabled_active`, `moonbag_qualifying_strategies` on `xstock_spot`); the population is split at any in-window flip, and a flip makes the stop leg a lower bound (instrument note (c)); the break-even ratchet's independence from those locks stays an OPEN check, stated.
- **A print, not a level (rule 29(b)).** The ticker snapshot table carries no trade timestamp (columns read 2026-09-30: `captured_at, bid, ask, last, volume_24h, …, metadata {schema_version}` only). **A print is established when `volume_24h` strictly rises between two consecutive snapshots of the symbol; its price is that snapshot's `last`.** A `last` with no volume rise is not evidence. (A drop-off leaving the 24 h window can mask a print, so the test can MISS a print — its error is toward "not computable", never toward FALSE.)
- **Classification, for a run with `bidWouldFire=stop`:** **FALSE HOLLOW** when a print inside the run, or within run end + 90 s, is at or below the frame's `sl=` — the refusal withheld a stop the market printed; **TRUE HOLLOW** when prints in that horizon exist and none reaches the stop; **NOT COMPUTABLE** when there is no print in it. The target leg is symmetric (`bidWouldFire=target`, a print at or above `tp=`). **+5 min and +30 min are sensitivity only**, published beside the primary with the direction of their bias (later horizons over-count FALSE: a print past the stop after a recovery means the refusal delayed, not withheld) and the number of runs whose class flips between horizons; if the primary and +5 min disagree in sign, the read is INCONCLUSIVE.
- **Denominators (c)3:** every split (RTH / off-hours / the 13:30Z open, per class) publishes runs AND frames-within-runs beside its counts.
