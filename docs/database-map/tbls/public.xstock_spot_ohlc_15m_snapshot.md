# public.xstock_spot_ohlc_15m_snapshot

## Description

B.4 foundation (2026-06-03): pre-aggregated 15-min OHLC buckets per xStock symbol. Parallel to xstock_spot_ohlc_60m_snapshot; populated by the prewarm script + cache write-back-on-miss on the 15-min cold-read path. Cap sized to DBS-192 + margin (~224 buckets/symbol). xStock-scoped; crypto unaffected.
