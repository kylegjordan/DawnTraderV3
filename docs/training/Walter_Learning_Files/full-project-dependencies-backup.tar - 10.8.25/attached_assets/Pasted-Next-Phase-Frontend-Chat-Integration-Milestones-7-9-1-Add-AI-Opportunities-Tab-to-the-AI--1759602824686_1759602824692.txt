🔹 2. Link Chat Button to Contextual AI Conversation

Goal: When clicking “Chat,” open a ChatGPT-style thread that’s tied to that opportunity.

Implementation Tasks:

On click, call POST /api/ai/conversations/opportunity with { opportunity_id }.

Backend should create a conversation with:

Title: Opportunity: [Symbol] - [Type] - [Date]

Seed message containing structured opportunity JSON (entry, stop, targets, rationale).

Receive conversation_id in the response.

Automatically navigate user to /analysis/chat?conversation_id={id}.

In chat UI, display a breadcrumb:
“🪙 Opportunity → [Symbol] ([Type])” linking back to the AI Opportunities tab.

Within chat:

User can discuss that single opportunity (GPT retains only that context).

User can say: “Execute this” → AI will confirm → Call /api/opportunities/execute.

User can say: “Remove this” → AI will confirm → Call /api/opportunities/dismiss.

All such actions get logged in ai_audit_log.
