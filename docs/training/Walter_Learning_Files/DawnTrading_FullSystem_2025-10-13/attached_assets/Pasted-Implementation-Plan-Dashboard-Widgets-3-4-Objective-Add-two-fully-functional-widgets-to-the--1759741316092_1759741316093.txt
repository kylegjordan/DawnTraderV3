Implementation Plan: Dashboard Widgets 3 & 4
🗂️ Objective

Add two fully functional widgets to the top dashboard row, harmonized with the existing Portfolio Value, Earnings, and Goals Summary widgets.

⚙️ Widget 3 – Trading Activity
📋 Purpose

Provide a snapshot of current trading operations and engagement.

🧱 Metrics to Display
Label	Description	Data Source
Trades Today	Number of trades executed today	/api/trades/summary?period=day
Active Trades	Currently open positions	/api/trades/active
Closed Trades	Trades closed in the selected period	/api/trades/summary?period={selected}
Win Rate %	Closed trades with positive PnL / total closed	calculated client-side
Volume Traded	Total USD or base-asset volume traded	/api/trades/volume?period={selected}
🕹️ Controls

Period Selector: dropdown → Day | Week | Month | 60 Days | 90 Days | Year | Custom Range

Defaults to Day.

Refresh button (optional) re-fetches data.

🎨 UI Specs

Card layout consistent with Portfolio Value/Earnings widgets

Header: Trading Activity

Two-row layout: top → numeric KPIs; bottom → period selector

Uses shared metric-card styling

🧩 Implementation Steps

Backend:

Add /api/trading/activity endpoint (if not already in routes).

Accept mode (live/paper) & period parameters.

Aggregate from trades table (group by status/date).

Frontend:

Create client/src/components/goals/trading-activity-widget.tsx.

Use apiRequest('/api/trading/activity?period=${period}').

Add compact KPI components (“metric blocks”) with tooltips.

Integration:

Add component import in client/src/pages/dashboard.tsx below Earnings widget.

Pass current trading mode as prop.

⚙️ Widget 4 – Results
📋 Purpose

Show higher-level performance metrics over time; connect strategy outcomes to portfolio growth.

🧱 Metrics to Display
Label	Description	Data Source
Total PnL	Net profit/loss for selected period	/api/metrics/summary?period={selected}
Profit Factor	Gross Profit / Gross Loss	calculated
Max Drawdown %	Largest peak-to-trough loss in period	/api/metrics/drawdown?period={selected}
Average Return per Trade %	Mean return across closed trades	calculated
🕹️ Controls

Period Selector identical to Widget 3

Defaults → Day

🎨 UI Specs

Card title: Results

Four metric blocks with labels + values

Period selector beneath metrics

Red/green coloring for negative/positive values

🧩 Implementation Steps

Backend:

Add /api/trading/results endpoint if missing.

Aggregate trade performance metrics for requested period.

Frontend:

Create client/src/components/goals/results-widget.tsx.

Fetch from /api/trading/results?period=${period}.

Calculate profit factor & avg return per trade client-side if not supplied.

Integration:

Place widget immediately after Trading Activity in the top dashboard grid.
