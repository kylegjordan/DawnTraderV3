Functional Requirements for “Daily Briefs” Tab:

Add date range selection inputs:

Start Date (📅 date picker)

End Date (📅 date picker)

Include a “Generate Report” button.

When pressed, it queries the summaries API (or the same backend endpoint currently powering daily briefs) with the specified date range.

Display a period summary of all relevant activity within that timeframe, including:

Trades executed

AI insights generated

Filter calibrations / system optimizations

Portfolio performance summary

Show “No data for this period” if range is empty.

Keep the visual layout consistent with the current daily brief format.

Data Flow:

Use the same backend endpoint currently serving /api/briefs/daily or /api/briefs/:date.

Extend it to accept query parameters ?startDate= and ?endDate=.

Server returns a combined summary object for all days in the range.
