Chat History with Cost Control
1. Database Storage

Use the existing ai_conversations table:

id (UUID, primary key)  
user_id (foreign key → users)  
messages (JSON) → [{ role, content, timestamp }]  
context (JSON) → optional structured context  
last_updated (timestamp)  


Each conversation = 1 row.

Allow multiple conversations per user.

2. Frontend Features

Add Chat History Sidebar (left of Chat Assistant):

Show a list of past chats (title = first user message or custom name).

Options: “Start New Chat”, “Rename”, “Delete”.

Clicking a past chat → loads stored messages into chat window.

New chats → insert empty conversation row in ai_conversations.

3. Backend API

Create endpoints:

GET /api/conversations → list user’s saved chats.

GET /api/conversations/:id → load specific conversation.

POST /api/conversations → start new conversation.

POST /api/conversations/:id/message → append a new user message, call GPT API, append GPT reply.

DELETE /api/conversations/:id → remove chat.

4. Token & Cost Management

Trim long histories before sending to GPT:

Always send the last 20 messages by default.

If user clicks “Load full history,” send all messages.

Add a config setting in settings table:

max_context_messages (default = 20).

Calculate estimated tokens before sending to GPT. If exceeds 4,000 tokens, automatically trim oldest.

5. User Controls

Add Chat Settings dropdown in the Chat Assistant panel:

“Keep last 10 / 20 / 50 messages” (controls context size).

“Always load full history” toggle.

Show cost estimate tooltip when sending:

“This request will use ~1,200 tokens (~$0.0002).”

6. Audit Logging

Log every GPT API call into ai_reports or a new ai_chat_logs table.

Store conversation_id, input_tokens, output_tokens, cost_estimate.

Let user pull up usage reports later (e.g., “How much did my chats cost this week?”).

7. Fail-Safe Design

If no history is loaded → GPT still works (fresh context).

If API quota exceeded → show clear error message:
“Your OpenAI quota is exhausted. Please check your billing.
