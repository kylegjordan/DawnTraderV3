3️⃣ Average Daily Earnings (ADE)
Definition

ADE =
Total Realized Profit/Loss over trailing 30 days ÷ Number of active trading days

Active trading days = days with ≥ 1 trade opened or closed.

If fewer than 5 days of data exist → show N/A.

Round to nearest dollar (or two decimals if < $10).

4️⃣ 7-Day Trend Visualization
Purpose

Give a quick glance at recent earnings consistency — helping you see whether your profitability is trending upward, downward, or oscillating.

Visualization Details

Type: Mini sparkline line chart (no axes, labels, or gridlines).

Data: Last 7 daily realized earnings (positive and negative values).

Color logic:

Green line if latest day ≥ 0

Red line if latest day < 0

Neutral gray if no data

Smooth transitions when new data arrives (animated if possible).

Tooltip on hover (optional in later phase):

“Day: [Date] — Earnings: +$472”

Behavior

Auto-updates each time a new daily brief is finalized.

Uses cached local data to render immediately on load.

Handles missing days (e.g., weekends) by skipping gaps instead of forcing zeros.

If fewer than 3 data points → show placeholder message:

“Insufficient data for trend visualization.”
