Replit Development Instructions — Dashboard & Goals Engine AI Reasoning Integration
📘 Project Overview

The purpose of this development cycle is to:

Replace the existing top dashboard widgets with a new 4+1 widget layout.

Implement the Goals Engine Panel with a new AI Reasoning Loop that lets users set, discuss, and finalize trading goals collaboratively with the AI Analyst.

Link the goals system with portfolio metrics, strategies, guardrails, and screeners — so that goals influence trade prioritization and ongoing optimization.

All of this must function in both Live and Paper Trading modes, remaining data-isolated between the two.

🧩 3. Goals Engine — Tab 1 (Main Goals Engine)
🧾 Structure
(A) Goals Table (top section)

Editable table with:

Metric	Goal	Actual	% Achieved
Earnings per Trade	Input	Calculated	Auto
Average Return (%)	Input	Calculated	Auto
Earnings per Day	Input	Calculated	Auto
Earnings per Week	Auto	Calculated	Auto
Earnings per Month	Auto	Calculated	Auto
Earnings per Year	Auto	Calculated	Auto

Rules:

Only one of the last four (Day/Week/Month/Year) can be edited at a time.

Others auto-calculate based on simple multipliers:

Week = Day × 5

Month = Week × 4

Year = Month × 12

Controls:

“Save Goals” button — commits values to DB

“Discuss Goals with AI” button — opens chat below

(B) AI Discussion Area (bottom section)

Persistent conversational interface with the AI Analyst.

User can:

Type directly into the chat to propose or discuss goals

Say things like “I want to earn $10,000 per week” or “What do we need to change to reach 3% average return?”

AI responses include:

Feasibility analysis

Counter-proposals (conservative / balanced / aggressive tiers)

Specific recommended changes in:

Strategy variables

Portfolio guardrails

Screener filters

Plain language explanations and risk commentary

When goals are agreed:

AI presents “Proposed Adjustments Summary”

User can confirm (“Yes, apply these changes”)

Backend commits new goals + adjustments

🧠 5. AI Reasoning Logic

Prompt Example

You are the AI Analyst for a trading system.
Evaluate the user’s proposed goals vs actual performance metrics.
If goals are unrealistic, propose adjusted targets and recommend strategy, guardrail, or screener changes to achieve them.
Explain the reasoning in simple terms.


AI Response Example

{
  "goal_assessment": [
    {"metric": "earnings_per_day", "feasibility": "Challenging", "recommended_target": 450},
    {"metric": "average_return", "feasibility": "Feasible", "recommended_target": 2.1}
  ],
  "strategy_recommendations": [
    {"strategy": "VWAP Pullback", "adjustments": {"max_trades": 4, "risk_per_trade": 0.02}}
  ],
  "guardrail_changes": {"max_drawdown": 0.15},
  "screener_tuning": {"volatility_filter": "tighten"},
  "explanation": "Given the current capital, earning $500/day is unrealistic. Adjusting risk per trade to 2% and running 4 trades in parallel increases feasibility to 78%."
}
