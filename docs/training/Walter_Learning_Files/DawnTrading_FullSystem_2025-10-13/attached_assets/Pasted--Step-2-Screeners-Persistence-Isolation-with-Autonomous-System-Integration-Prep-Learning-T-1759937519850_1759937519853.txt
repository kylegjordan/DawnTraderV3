⚠️ Important Integration Note

When implementing mode isolation and filter calibration:

Keep operational data (screeners, screener results, trades, portfolios, alerts) fully isolated by mode.

Keep intelligence data (filter calibrations, optimizer adjustments, AI lessons) shared across modes.

Live mode should:

Fall back to the most recent Paper mode calibration if no Live entry exists or if it’s stale (> 24 h).

Use shared learning tables (filterCalibrationLog, intradayAdjustments, aiLessons) so that Paper-mode optimizations carry over.


Paper mode runs its own simulations and writes new learnings, which automatically become available to Live mode.

Add an optional nightly or weekly sync step that copies the most recent Paper-mode rows in these tables into Live if Live is missing them.

Store long-term global strategy parameters (e.g., stop/TP ratios, risk weights) in a shared, non-mode table strategyParameters, used by both modes.


This ensures that Live mode benefits from Paper-mode experience while keeping all monetary and trade data isolated.
