🧩 Part 1 — Add Finnhub.io Stock Data Feed

Instructions:

Create a new backend service file:

/server/services/stocks.ts


Purpose: fetch U.S. stock market data from Finnhub.io.

Add Replit Secret:

FINNHUB_API_KEY=<your_finnhub_api_key>


Implement endpoints:

GET /api/stocks/quote/:symbol → Returns live stock quote

GET /api/stocks/company/:symbol → Returns company info

GET /api/stocks/search/:query → Returns search results (up to 5 matches)

Cache results per user for 60 seconds to stay within free-tier limits.

Verify with sample requests:

/api/stocks/quote/AAPL

/api/stocks/search/Apple

🔍 Part 2 — Smart Search by Name (for Stocks & Crypto)

Instructions:

Update the AI Analysis input field to accept any company or coin name, not just symbols.

When the user types, call both:

/api/stocks/search/:query

/api/crypto/search/:query

Show dropdown suggestions:

[AAPL] Apple Inc (Stock)
[TSLA] Tesla Inc (Stock)
[BTC] Bitcoin (Crypto)
[ETH] Ethereum (Crypto)


Limit to 5–8 suggestions.

Case-insensitive.

No exact match required.

When a user selects a result:

Store { symbol, name, type } (type = “stock” or “crypto”).

If nothing matches:

Display: “No results found for ‘X’. Try another keyword.”
