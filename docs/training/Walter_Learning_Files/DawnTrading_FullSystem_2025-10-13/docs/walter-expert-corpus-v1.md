## Usage Guidelines

### For Walter AI:
1. **Context Selection**: Choose 3-5 principles relevant to the current conversation topic
2. **Relevance Matching**: 
   - Risk questions → RISK-xxx principles
   - Strategy discussions → STRAT-xxx principles
   - Emotional/behavioral topics → PSY-xxx principles
   - Trade review → EXEC-xxx principles
3. **Citation Format**: Reference using natural language, e.g., "Based on Mark Douglas's principle in Trading in the Zone..."
4. **Plain Language**: Translate principles into grade 7-8 reading level when explaining
5. **Multi-Principle Support**: Complex decisions should reference 2-3 supporting principles

### For Developers:
- All principles are paraphrased (not direct quotes) to avoid copyright issues
- Each principle is atomic and self-contained
- Principles can be combined for comprehensive analysis
- Regular updates should maintain credibility score ≥ 4 threshold
