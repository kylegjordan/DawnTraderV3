# Approved Directives

This folder contains directives that were:

1. Proposed by ChatGPT
2. Explicitly approved by the human
3. Executed by Replit

Drafts, ideas, or unapproved instructions do NOT belong here.

---

## Traceability Requirements

Every directive must declare:

### Expected Decision
- What decision(s) will result from this directive
- Decision ID format: DEC-YYYYMMDD-XXXX
- Who must approve the decision

### Expected Execution Trace
- What files will be created/modified
- What configuration changes will occur
- Verification steps to confirm completion

No directive is complete without:
1. A corresponding decision record
2. An execution trace documenting the implementation
