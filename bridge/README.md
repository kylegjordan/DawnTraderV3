# DawnTrader Bridge

The Bridge is the durable coordination layer between:

- ChatGPT (architecture, reasoning, directives)
- Replit (execution and implementation)
- Human authority (final approval)

Purpose:
- Prevent context loss
- Preserve decisions across sessions
- Enforce explicit approval
- Protect canonical system truth

Canonical truth lives in:
- /bridge/canonical

Searchable history lives in:
- /bridge/reference

Nothing executes without approval.
