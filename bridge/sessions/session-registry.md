# DawnTrader Bridge — Session Registry

**This is an append-only chronological registry of all ChatGPT sessions.**

---

## Registry Format

Each entry must include:
- **Session ID**: Unique identifier (SESSION-YYYYMMDD-XXXX)
- **Start Time**: ISO timestamp
- **Declared Purpose**: What the session was created to do
- **Phase**: Active phase at session start
- **Status**: active / closed / superseded
- **Approval Reference**: Human approval ID or directive reference
