A. FRONTEND — ENGINE & TOGGLE LOGIC

1️⃣ TopBar.tsx — Connect Toggle to Real Engine Actions
Replace current handleTradingToggle() logic with:

    const handleTradingToggle = async () => {
        if (mode === 'paper') {
            if (!active) await api.post('/api/paper-sim/start');
            else await api.post('/api/paper-sim/stop');
        } else if (mode === 'live') {
            if (!active) {
                const confirmed = await showConfirmLiveTradingModal();
                if (!confirmed) return; // user canceled
                await api.post('/api/trading/start', { mode: 'live' });
            } else {
                const confirmed = await showConfirmStopLiveTradingModal();
                if (!confirmed) return;
                await api.post('/api/trading/stop', { mode: 'live' });
            }
        }
    };

Note:
- `showConfirmLiveTradingModal()` opens the same modal you see now (Confirm + Cancel).
- If user clicks Cancel → nothing changes.
- If Confirm → executes the API call immediately.

2️⃣ Replace Local State with Backend State
Use `useTradingStore()` or `useTrading()` hook values directly:

    const { active, mode, isPending } = useTradingStore();

    <Switch
      checked={active}
      disabled={isPending}
      onCheckedChange={handleTradingToggle}
      className={active ? 'bg-green-500' : 'bg-gray-500'}
    />
    <span>{active ? 'Active' : 'Stopped'}</span>

This ensures:
✅ Green = active trading  
✅ Gray = stopped  
✅ Always synced with backend-confirmed engine state.

3️⃣ WebSocket Live Sync
In useTrading hook or store:

    socket.on('trading_state_changed', payload => {
        set({ active: payload.isEngineActive, mode: payload.mode });
    });

This updates all open browser tabs instantly when the backend changes state.

4️⃣ Heartbeat Reconciliation
Add a 10-second polling fallback:

    useEffect(() => {
        const interval = setInterval(async () => {
            const { data } = await api.get('/api/trading/status');
            if (data.isEngineActive !== store.active) {
                store.set({ active: data.isEngineActive });
            }
        }, 10000);
        return () => clearInterval(interval);
    }, []);

Ensures UI auto-corrects even if a WebSocket packet is missed.
