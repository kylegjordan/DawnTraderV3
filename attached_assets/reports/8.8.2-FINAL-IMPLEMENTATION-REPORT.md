**Core Method**: `scanMode()`

```typescript
private async scanMode(mode: 'paper' | 'live'): Promise<ScanResult | null> {
  // Load screener filters
  const filters = await storage.getScreenerFilters({ mode });
  
  // Execute FX5 filtering
  const result = await this.filteredPairsService.getValidPairs(mode, filters, true);
  
  // Compute breakdown from filter results
  const diagnosticData = await this.computeBreakdown(mode, filters);
  const breakdown = diagnosticData.breakdown;
  
  // Calculate counts from breakdown (CRITICAL FIX)
  const evaluatedCount = diagnosticData.evaluated;
  const eligibleCount = breakdown.passed_all_filters + breakdown.already_active;
  const ineligibleCount = 
    breakdown.failed_min_volume +
    breakdown.failed_spread +
    breakdown.failed_daily_range +
    breakdown.failed_min_price +
    breakdown.failed_stablecoin +
    breakdown.failed_quote_currency +
    breakdown.failed_history +
    breakdown.failed_market_cap +
    breakdown.failed_guardrail_risk;
  
  // Update Stage-3 cache FIRST
  await updateStage3Cache(mode, { /* ... */ });
  
  // Emit Stage-3 WebSocket events SECOND
  await emitStage3Events(mode, breakdown);
}
```

### 2. Truth Constraint Fix

**Problem Identified by Architect**:
```
eligibleCount from FilteredPairsService EXCLUDES active trades
breakdown.already_active COUNTS them separately
Result: evaluated - eligible ≠ breakdownSum when active trades exist
```

**Solution Implemented**:
```typescript
// OLD (WRONG):
const eligibleCount = result.eligiblePairs;  // Excludes active trades
const ineligibleCount = evaluatedCount - eligibleCount;  // Math breaks!

// NEW (CORRECT):
const eligibleCount = breakdown.passed_all_filters + breakdown.already_active;
const ineligibleCount = sum_of_all_failed_categories;
```

**Truth Constraint Formula**:
```
evaluatedCount = eligibleCount + ineligibleCount

Where:
  eligibleCount = passed_all_filters + already_active
  ineligibleCount = failed_min_volume + 
                    failed_spread + 
                    failed_daily_range + 
                    failed_min_price + 
                    failed_stablecoin + 
                    failed_quote_currency + 
                    failed_history + 
                    failed_market_cap + 
                    failed_guardrail_risk
```

**Breakdown Counting Contract**:
Every evaluated pair MUST increment exactly ONE category to maintain truth constraint.

## Design Patterns & Best Practices

### 1. Kraken API Response Pattern

**Critical**: Kraken API returns objects indexed by pair name, NOT arrays.

```typescript
// WRONG:
for (const ticker of tickers) {  // TypeError: tickers is not iterable
  
// CORRECT:
for (const [symbol, ticker] of Object.entries(tickers)) {
```

### 2. Breakdown Counting Contract

Every evaluated pair must increment exactly ONE category:

```typescript
// Pass all filters
if (meetsAllCriteria) {
  if (isAlreadyActive) {
    breakdown.already_active++;
  } else {
    breakdown.passed_all_filters++;
  }
}

// Fail ANY filter
else {
  if (volumeTooLow) breakdown.failed_min_volume++;
  else if (spreadTooWide) breakdown.failed_spread++;
  else if (rangeTooHigh) breakdown.failed_daily_range++;
  // ... etc (ONLY ONE category incremented)
}
```

### 3. Truth Constraint Validation

Always derive counts from breakdown to ensure math balances:

```typescript
const eligibleCount = breakdown.passed_all_filters + breakdown.already_active;
const ineligibleCount = sum_of_all_failed_categories;
const evaluatedCount = eligibleCount + ineligibleCount;

// Constraint: evaluatedCount MUST equal total pairs evaluated
```
