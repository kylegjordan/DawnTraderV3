Task: Integrate and Cache Live Market Data Feeds in AI Analysis Tab

Paste this into Replit’s AI chat:

Please integrate and test live market data connections for the AI Analysis tab, including a 60-second caching layer to prevent rate-limit issues.

🎯 GOAL
Ensure the Symbol Analysis section retrieves and displays real-time market prices, 24h change, and volume for all supported tickers using CoinGecko as the primary source and Kraken as a fallback. Implement caching to avoid API overuse.

🧠 STEPS TO PERFORM

1. Identify all relevant files and components:
   - server/services/ai-analyst.ts
   - server/services/market-data.ts (create if missing)
   - client/src/hooks/use-trading.tsx
   - Any related API routes (/api/ai/analyze-symbol or /api/market-data)

2. Add or verify a unified data function called getMarketData(symbol):
   - Primary: Fetch from CoinGecko
     https://api.coingecko.com/api/v3/simple/price?ids=bitcoin,ethereum,solana&vs_currencies=usd&include_24hr_change=true&include_last_updated_at=true
   - Fallback: If CoinGecko fails or the symbol isn’t supported, fetch from Kraken:
     https://api.kraken.com/0/public/Ticker?pair=BTCUSD
   - Return standardized data:
     { symbol, price, change24h, source, timestamp }

3. Implement a simple 60-second caching layer:
   - Store the most recent response for each symbol in memory.
   - If a request comes within 60 seconds of the last fetch, serve cached data.
   - After 60 seconds, refresh from the API automatically.
   - Log cache hits vs. API calls.

4. Integrate market data into AI Analysis:
   - Inject live price, 24h change, and data source (CoinGecko or Kraken) into the prompt used for AI Technical Analysis.
   - Display those live metrics on the Technical Analysis card next to AI-generated insights.

5. Test end-to-end functionality:
   - Run analysis for BTC, ETH, SOL, and an unsupported symbol (to test Kraken fallback).
   - Verify:
     ✅ Live API responses (status 200)
     ✅ Correct prices and % change
     ✅ Fallback triggers correctly when CoinGecko fails
     ✅ Cache layer prevents multiple API calls within 60 seconds
     ✅ All four analysis cards render correctly with live data
     ✅ No console or network errors

6. Perform performance and reliability tests:
   - Make 10 sequential requests for the same symbol and confirm only 1 external API call occurs.
   - Log timestamps and data sources to confirm caching works.
   - Confirm latency <2s for cached responses.

7. Generate a detailed diagnostic report:
   - Include:
     • API endpoints tested
     • Response samples (price, timestamp)
     • Cache hit/miss logs
     • Symbols tested
     • Any latency or error observations
   - Save the report as:
     /reports/MARKET_DATA_INTEGRATION_AND_CACHING_REPORT.md

✅ SUCCESS CRITERIA
- The AI Analysis tab displays live prices and 24h changes for BTC, ETH, and SOL.
- Fallback to Kraken works when CoinGecko fails.
- Cached responses are used for repeated requests within 60 seconds.
- The report file is successfully created and includes full results, logs, and recommendations.
