1️⃣ Exponential Backoff + Jitter (Rate Limiter Enhancement)

File: server/services/scanner-service.ts

Replace the flat await new Promise(res => setTimeout(res, 100)); throttle delay with exponential backoff and jitter logic:

async function waitForToken(retryCount: number = 0) {
  const delay = Math.min(100 * Math.pow(2, retryCount), 1000); // cap 1s
  const jitter = Math.random() * 50;
  await new Promise(res => setTimeout(res, delay + jitter));
}


Then modify the scanTimeframe() loop:

for (const symbol of pairs) {
  let retryCount = 0;
  while (!consumeToken()) {
    await waitForToken(retryCount++);
  }
  try {
    const candles = await getOHLC(symbol, interval);
    results.push({ symbol, candles, timeframe: interval });
  } catch (err) {
    logger.warn(`[Cascade] Skipping ${symbol}: ${err.message}`);
  }
}


✅ Benefit:
Smooths scan bursts, reduces Kraken 429 errors, and provides graceful recovery during temporary network stalls.

4️⃣ Hybrid Timeframe Guard (Prevent False Hybrids)

File: server/services/hybrid-integration.ts

Insert a new guard near the start of detectConfluence() to validate allowed timeframe combinations:

const validPairs: [Timeframe, Timeframe][] = [
  ['1h', '15m'],
  ['15m', '5m'],
];

if (!validPairs.some(([a, b]) =>
  (quant.timeframe === a && pattern.timeframe === b)
)) {
  logger.debug(
    `[HybridIntegration] Skipping invalid confluence: Quant=${quant.timeframe}, Pattern=${pattern.timeframe}`
  );
  continue;
}


✅ Benefit:
Prevents invalid 5m–5m merges or same-timeframe hybrids that would create noise signals and false confidence.
