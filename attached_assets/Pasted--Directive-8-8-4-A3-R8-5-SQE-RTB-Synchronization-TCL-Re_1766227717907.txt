🎯 Objective

Eliminate asynchronous SQE bypass, restore NGC gating, re-enable proper RTB status lifecycles, enforce deduplication, and align TCL activation with live queue counts.

This directive ensures that only validated signals enter the RTB, statuses transition visibly (active → reconfirmed → promoted/expired), and TCL promotes signals only after true queue thresholds are reached.

🔧 Implementation Steps
1. ready_to_buy_service.ts

1.1 Enforce SQE Await Before Insert

const result = await SQE.evaluateSignalQuality(signal);
if (result?.passed) {
  await this.insertSignal(signal);
}


1.2 Preserve and Advance Statuses

if (result?.passed) {
  signal.status = signal.status === "active" ? "reconfirmed" : signal.status;
} else {
  // remove immediately on failure
  await this.deleteSignal(signal.id);
}


1.3 Deduplicate During Refresh

if (!pool.find(p => p.symbol === s.symbol && p.strategy === s.strategy)) {
  pool.push(s);
}

2. signal_quality_engine.ts

2.1 Reinstate NGC Threshold

if (ngc < MIN_NGC_THRESHOLD) {
  return { passed: false, reason: "NGC below threshold" };
}


2.2 Maintain Additive Formula

const ngc = (baseNGC * 0.4) + (profitRate * 0.4) + ((1 - risk) * 0.2);


Ensure normalization is performed once and capped [0 , 1].

3. tcl_watchdog.ts

3.1 Replace Cached Snapshot Count with Live Query

const activeCount = await rtbStorage.countActive();
if (activeCount >= this.threshold) {
  this.triggerPromotion();
}


3.2 Retain 5-second debounce window to prevent redundant triggers.

4. api/rtb_signals.ts

4.1 Correct UI Status Mapping

switch (s.status) {
  case "reconfirmed": uiStatus = "Reconfirmed"; break;
  case "promoted":   uiStatus = "Promoted";    break;
  case "expired":    uiStatus = "Expired";     break;
  default:           uiStatus = "Active";
}
