🧭 1. Strategic Objective

The purpose of this directive is to introduce the Dynamic Sizing Engine (DSE) — the final stage in the adaptive intelligence system — enabling each trade to automatically size itself based on predicted edge, market conditions, and risk constraints.

The DSE links together:

Adaptive Learning (11.1) — remembers what works.

Adaptive Scanning (11.2) — identifies where to look.

Predictive Risk Modeling (11.3) — decides how much to risk.

By the end of this directive:

Trade sizing becomes fully dynamic, self-adjusting by regime and strategy.

Risk per trade is contextually optimized.

All sizing actions are telemetry-tracked and bounded by global safety caps.

Task 1 — Dynamic Sizing Engine Module

File: /server/core/risk/dynamic_sizing_engine.ts

Implement the core function:

import { PortfolioService } from "@/server/core/portfolio/portfolio_service";
import { ExecutionConfig } from "@/server/config/execution_config";
import { AdaptiveLearningRepository } from "@/server/core/learning/adaptive_learning_repository";
import { TradeSafetyService } from "@/server/core/safety/trade_safety_service";

export async function computeDynamicSize({
  strategyId,
  symbol,
  regime,
  pool,
  volatility,
  cost,
}: DynamicSizeInput): Promise<number> {
  // --- Dynamic Base Size (Scales with Portfolio Equity) ---
  const balance = await PortfolioService.getCurrentBalance();
  const baseRiskPct = ExecutionConfig.baseRiskPercent ?? 2; // e.g., 2% of balance
  const basePositionSize = balance * (baseRiskPct / 100);

  // --- Predictive Inputs ---
  const learning = await AdaptiveLearningRepository.getWeights(strategyId, regime);
  const baseEdge = learning?.expectedEdge ?? 0.05;
  const confidence = learning?.confidence ?? 0.5;

  // --- Predictive Risk Modifiers ---
  const edgeFactor = 1 + (baseEdge - 0.05) * 4;
  const volPenalty = Math.max(0.7, 1 - (volatility / 0.02));
  const costPenalty = Math.max(0.6, 1 - (cost / 0.001));
  const confFactor = 0.5 + confidence;

  // --- Core Multiplier ---
  let multiplier = edgeFactor * volPenalty * costPenalty * confFactor;
  multiplier = Math.min(1.2, Math.max(0.3, multiplier));

  // --- Hard Cap Enforcement (Invariant T3) ---
  const maxAllowedSize = TradeSafetyService.getMaxPositionSize(balance);
  let finalSize = basePositionSize * multiplier;
  finalSize = Math.min(finalSize, maxAllowedSize);

  return finalSize;
}
