Task 5 — CSV Export Endpoint

Add helper function:
File: /server/utils/export-csv.ts

export function exportVtsDataToCsv(trades, filenamePrefix) {
  const csv = parse(trades, { header: true });
  const filename = `${filenamePrefix}_${Date.now()}.csv`;
  fs.writeFileSync(`logs/exports/${filename}`, csv);
  return `/logs/exports/${filename}`;
}


Both /api/ml/vts/open/export and /api/ml/vts/closed/export should call this helper.
