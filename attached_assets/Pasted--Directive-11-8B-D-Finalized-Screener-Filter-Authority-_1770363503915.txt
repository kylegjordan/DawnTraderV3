Risk Level: Low (Structural only)

1️⃣ Purpose

This directive cleans, consolidates, and formalizes filter authority surfaces so the system is structurally ready for predictive control in Phase 11.8B-E, without introducing any adaptive behavior.

After this directive:

There is exactly one UI surface for screener filters

There is exactly one API authority surface for screener filters

Filter authority is explicit, frozen, and boring

All deprecated or parallel authority paths are removed or neutered

No predictive or automated system may adjust filters

This directive aligns the codebase with the canonical Phase 11 architecture, which already assumes these invariants.

2️⃣ Explicit Non-Goals (Guardrails)

Replit must not:

Add predictive or adaptive logic

Change filter values automatically

Introduce ML-driven decisions

Modify execution behavior

Modify or weaken system guards

Re-enable any dormant authority flags

This is authority cleanup only.
