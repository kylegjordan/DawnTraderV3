🧭 Directive for Replit: Phase 27.F.15 – Full System Audit and Removal of Residual userId Logic
Objective

Perform a complete, system-wide audit and cleanup to eliminate all dependencies on userId (or equivalent identifiers) in the backend, database schema, and frontend codebase.
Replace all such references with mode (paper / live) or globalContextId, ensuring all multi-user synchronization is purely context-based, not account-based.

This phase is mandatory to stabilize global synchronization before expanding to live trading.

PHASE TASK LIST
1️⃣ Global Search and Audit Preparation

Execute a recursive search for all legacy user ID references:

rg -i "(user_id|userId|userID|userid|usercontext|ctx.user|byUser)" --hidden --glob '!node_modules/*' > audit_userid_refs.txt


Output file: audit_userid_refs.txt

Include results from backend, frontend, and shared schema directories:

/server/

/client/

/shared/

/migrations/

/services/

This file will serve as the master reference ledger of all code segments still linked to per-user contexts.

2️⃣ Classification and Replacement Plan

Create a new documentation file:
docs/audit_userid_matrix.md

Populate it with a markdown table in this format:

Location	Purpose	Replacement	Action
/server/services/alerts-service.ts	Filter alerts per user	Replace with mode	Update query and broadcast
/shared/schema.ts	Column user_id in system_alerts	Remove column	Drop and reindex by mode
/client/src/hooks/usePortfolio.tsx	Fetch per-user data	Replace with mode	Refactor API call
/server/services/trading-service.ts	userId in WebSocket broadcast	Replace with mode	Update broadcast signature

Every match from audit_userid_refs.txt must be assigned to one row in this matrix.
No unclassified matches should remain.

Search all React hooks and API calls for userId usage:

No component reads or stores localStorage.userId, session.user, or similar.

5️⃣ Verification Script

Add /scripts/verify-no-userid.js:

import { execSync } from 'child_process';

try {
  const result = execSync('rg -i "(user_id|userId|userID|userid|byUser|usercontext|ctx.user)" --glob "!node_modules/*"', { encoding: 'utf8' });
  if (result.trim().length > 0) {
    console.error("❌ Found lingering userId references:\n", result);
    process.exit(1);
  } else {
    console.log("✅ No userId references detected in codebase!");
  }
} catch (err) {
  console.error("❌ Verification script error:", err);
  process.exit(1);
}


After completion of this phase, Replit must run:

npm run verify-no-userid


Expected output:

✅ No userId references detected in codebase!
