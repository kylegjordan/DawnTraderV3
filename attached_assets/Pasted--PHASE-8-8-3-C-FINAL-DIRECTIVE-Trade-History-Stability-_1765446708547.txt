🔵 PART 1 — FIX GHOST TRADES & PAGINATION (SERVER-SIDE)
---------------------------------------------------------
Problem

Ghost trade filtering happens after pagination, causing correct trades to disappear.

Required Fix

Move the ghost-trade filter into the SQL WHERE clause so that:

A trade is considered valid if:
exit_price IS NOT NULL
exit_price > 0
close_reason IS NOT NULL
close_reason != ''

Required SQL WHERE additions:

Apply to all paginated trade-history queries:

WHERE closed_at IS NOT NULL
  AND exit_price IS NOT NULL
  AND exit_price > 0
  AND close_reason IS NOT NULL
  AND close_reason != ''

Remove the old post-query ghost filter entirely:

In routes.ts remove:

const validTrades = trades.filter(t => { ... });


Pagination, sorting, limit, offset must operate only on valid trades.

🔵 PART 2 — FIX DATE FILTER LOGIC (SERVER-SIDE)
---------------------------------------------------------
Problem

dateTo is interpreted as midnight (00:00:00), which excludes all trades on that date.

Required Fix

When dateTo is provided, convert it to end-of-day 23:59:59.999 UTC before applying filters.

Required implementation:

In storage.ts or routes.ts (wherever filtering is applied):

if (filters.dateTo) {
  const endOfDay = new Date(filters.dateTo);
  endOfDay.setHours(23, 59, 59, 999);
  conditions.push(sql`${paperSimTrades.closedAt} <= ${endOfDay}`);
}


This ensures selecting Dec 12 includes all trades closed on Dec 12.

🔵 PART 5 — FIX FRONTEND QUERY FUNCTION
---------------------------------------------------------
Problem

The frontend continues using an incorrect default queryFn.

Required Fix

Inside trade-history-tab.tsx, the useQuery must always use an explicit queryFn:

queryFn: async () => {
  const params = new URLSearchParams();
  params.set("paginated", "true");
  params.set("limit", String(pageSize));
  params.set("offset", String(page * pageSize));
  params.set("sortBy", sortBy);
  params.set("order", order);
  params.set("closedOnly", "true");

  if (selectedSymbol) params.set("symbol", selectedSymbol);
  if (selectedStrategy) params.set("strategy", selectedStrategy);
  if (closeReason) params.set("closeReason", closeReason);
  if (dateFrom) params.set("dateFrom", dateFrom);
  if (dateTo) params.set("dateTo", dateTo);

  return apiFetch(`/api/paper-sim/trades?${params.toString()}`);
}


This must replace any previously attempted fixes.
