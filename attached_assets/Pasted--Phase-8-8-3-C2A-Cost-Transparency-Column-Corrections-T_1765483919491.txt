📘 Phase 8.8.3-C2A — Cost Transparency + Column Corrections + Table Reformatting Directive
Summary

This directive corrects the new cost-transparency layout introduced in Phase C2.
The implementation currently works, but several columns are mis-ordered or unnecessary, one required column is missing, and some cost columns display values incorrectly.

This directive updates both Active Trades and Trade History tables to their final intended layout and presentation.

---------------------------------------
✅ SECTION A — ACTIVE TRADES TABLE FIXES
---------------------------------------
A1 — Remove “Entry (Actual)” Column

The column Entry (Actual) should be completely removed.

Reason:
It no longer adds value since gross/net P/L already express the effect of slippage.

A2 — Restore the CURRENT PRICE Column (Critical)

Add back a dedicated Current column after Entry and Exit, as it existed before the C2 upgrade.

Column order should be:

Entry

Target Exit / TP

Current ← (newly restored)

Distance metrics

P/L metrics

A3 — Stack Distance Metrics

Distance to TP and Distance to SL must be stacked vertically inside one column:

DIST

TP distance (top)

SL distance (bottom)

(Use the original Dawn Trader stacked metric formatting.)

A4 — Stack Gross Metrics

Gross P/L should be shown as:

Column: GROSS P/L

Dollar value (top)

Percent value (bottom)

No separate columns.

A5 — Stack Net Metrics

Net P/L should be shown as:

Column: NET P/L

Dollar value (top)

Percent value (bottom)

A6 — Exit Fee & Exit Slip Must Show Positive Values

Currently they appear as -0.05 and -0.07.

These values represent costs and should always display as positive numbers, consistent with Entry Fee and Entry Slip.

Implementation:

displayValue = Math.abs(exitFee)


and same for exitSlip.

This matches the mental model of the trading engine and aligns perfectly with your intended UX.
