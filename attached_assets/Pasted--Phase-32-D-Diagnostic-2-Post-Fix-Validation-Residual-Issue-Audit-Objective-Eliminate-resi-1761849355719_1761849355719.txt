Symptoms

Dashboard = $818 → 830 → 835 (new value).

LATTI Goals & Guardrails / Goals Engine = $850 (stale constant).
Probable Cause

Still two portfolio data sources:

/api/goals/summary reads goals_state snapshot table that isn’t refreshed by portfolio_balance_updated.

Consolidate both endpoints to use the same query (storage.getPortfolioBalance(mode)).

Add React Query invalidation for /api/goals/summary whenever portfolio_balance_updated fires.

3️⃣ Trading Toggle & Blue Bar Still Stopped After Toast

Symptoms

Toast fires ✅ , Passive badge disappears ✅ , but toggle / bar remain STOPPED.
Probable Cause

TopBar WebSocket listener now reads from latestUpdate.payload.mode, but payload.active may not be parsed because server broadcasts { active: true } while the frontend checks payload.isEngineActive.
Expected Fix Path

Normalize payload keys:

const isActive = payload.active ?? payload.isEngineActive ?? false;


Ensure /api/paper-sim/status sets both active=true and isRunning=true.

Log [TopBar] trading_state_changed → active:true in browser console to confirm.

4️⃣ Goals Engine & Guardrails Fail to Load / Fetch Errors

Symptoms

“Failed to load presets / guardrails data / Failed to fetch” messages; Goals Engine stalls minutes.
Probable Cause

Backend GET /api/goals/summary & GET /api/goals/presets throwing 500 / timeout due to missing user-ID join after orphaned cleanup.

Possible foreign-key mismatch (NULL userId after Phase 32.D-Fix.7 cleanup).
Expected Fix Path

Confirm both endpoints filter by (userId OR globalUser IS NULL) not strictly userId.

Validate DB joins and indexes: ensure goal_presets.user_id defaults to NULL, not required.

Add short-term logging in server/routes/goals.ts to capture thrown error text.
