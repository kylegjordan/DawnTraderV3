🧩 Task 1 — Add Initialization Guard for Underflow Protection

File: server/services/adaptive-scan-manager.ts

const batch = idealPairs.concat(rotationalPairs);
if (batch.length < 100) {
  console.warn(`[11.4C-R2][AdaptiveScan] Underfilled batch: ${batch.length}/100. Retrying in 5s...`);
  await sleep(5000);
  const retryBatch = this.rebuildBatch();
  if (retryBatch.length < 100)
    console.warn(`[11.4C-R2][AdaptiveScan] Still under 100 after retry (Available ${retryBatch.length})`);
  return retryBatch;
}
return batch;


✅ Ensures first cycles always try to reach full 100-pair scans after any load race.

🧩 Task 3 — Top Batch API Endpoint

File: server/routes/api/pairs.ts

router.get('/ranked', async (req, res) => {
  const top = parseInt(req.query.limit ?? '100');
  const pairs = await telemetry.getRankedPairs(top);
  res.json(pairs.map((p, i) => ({
    rank: i + 1,
    symbol: p.symbol,
    score: p.performanceScore,
    signalType: p.signalType,
    strategy: p.strategy,
    pattern: p.pattern ?? '—',
    regime: p.regime,
    source: p.source // 'simulation' or 'live'
  })));
});


✅ Simplifies client consumption and aligns with your specified columns.
