Control Flags
Each Core Four guardrail and filter stores a control flag in the database:

{ "controlledBy": "lottie" | "manual" }


Behavior

Mode	Lottie Authority	User Authority	Description
Lottie-Controlled	✅	⚠️	LATTI may auto-tune the value in real time. User may switch to manual at any time.
Manual	❌	✅	Value is locked and cannot be changed by LATTI until switched back.

Key Principles

Manual = Frozen. LATTI must work around locked values.

Switching back to Lottie does not revert the value — LATTI inherits your manual baseline.

Mixed Custom configs (manual + Lottie) are fully supported.

Presets stay active until any value changes.
