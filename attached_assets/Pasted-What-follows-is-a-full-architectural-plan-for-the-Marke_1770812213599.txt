2️⃣ Market Context Engine (MCE) – Responsibility Boundaries

The MCE is responsible for:

Computing all canonical secondary metrics

Producing a deterministic MarketContext

Performing zero strategy logic

Performing zero signal math

Performing zero EV math

No ranking

No regime decision

The DSS remains responsible for:

Regime detection

Strategy selection based on context

Nothing else

Strategies become responsible only for:

Entry / Stop / Target logic

Using context values

Not computing indicators

export interface MarketContext {
  pair: string;
  timeframe: string;

  // Price
  price: number;

  // Trend & Structure
  sma50: number;

  hmaCross: 'BULL' | 'BEAR' | null;

  // Volatility

  bollingerLower: number;
  bollingerBandwidth: number;
  volatilityPercentile: number;

  // VWAP
  vwap: number;
  vwapStdDev: number;
  vwapZ: number;

  // Momentum
  momentumPct: number;
  momentumSlope: number;

  // Oscillators
  rsi: number;
  adx: number;

  // Volume
  avgVolume: number;
  volumeRatio: number;

  // Pattern Precursor Metrics
  abcdRatio?: number;

This is the only object DSS and strategies receive.

6️⃣ Where It Hooks In

The correct injection point is:

Inside the pipeline that processes the Active Filter Pool.

Pseudo-code:

for (const pair of activeFilterPool) {

  const candles = await getCandles(pair);

  const context = marketContextEngine.compute(pair, candles, btcCandles);

  const selection = dss.selectStrategy(regime, context);

  if (!selection) continue;

  const signal = strategyExecutor.execute(selection, context);

  if (signal) submit(signal);
}


Important:

BTC candles fetched once per cycle.

Context computed once per pair.

No strategy can compute its own indicators.

7️⃣ Strategy Refactor Plan
Current State (Problem)

Each strategy:

Computes its own RSI

Computes its own VWAP

Computes its own ADX

Duplicates logic

This causes:

Inconsistent thresholds

Drift

Duplicate work

Impossible DSS preconditions

Refactor Target

All strategies must change signature:

BEFORE
detect(candles: Candle[]): Signal | null

AFTER
detect(context: MarketContext, candles: Candle[]): Signal | null


Rules:

Strategies may use context values.

Strategies may NOT recompute RSI, ADX, etc.

If they attempt to compute indicators internally → build fails.

8️⃣ DSS Refactor

DSS now receives:

selectStrategy(regime: Regime, context: MarketContext)


It does:

Canonical priority iteration

Precondition evaluation using context

Returns selected strategy key

It does NOT:

Run detect()

Compute indicators

Rank signals

Use EV
