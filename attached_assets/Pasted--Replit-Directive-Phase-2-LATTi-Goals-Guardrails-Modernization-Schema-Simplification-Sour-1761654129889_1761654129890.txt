D) Transitional Analytics View → transitional_view_guardrails_v1.sql

Create a read-only view for metrics comparison:

CREATE VIEW v_guardrails_transitional AS
SELECT
  g.mode,
  g.portfolio_risk_per_trade_pct AS risk_pct,
  g.daily_loss_kill_switch_pct AS kill_switch_pct,
  g.symbol_cooldown_minutes AS cooldown,
  g.max_open_positions AS positions,
  legacy.maxDailyLoss,
  legacy.maxDrawdown
FROM guardrails_v2 g
LEFT JOIN guardrails legacy
  ON legacy.mode = g.mode;


Purpose: maintain analytics continuity until Phase 4 UI migration is done.
