📌 IMPLEMENTATION REQUIREMENTS
1. Subscribe ALL open positions on trading START

When paper trading starts:

Load all open positions

Extract their normalized Kraken WS symbols via resolver

Call krakenWebSocketAdapter.subscribe() with the full list

Emit diagnostic logs:

[I8C-STARTUP][ENGINE_INIT_SUBSCRIBE] subscribing_to=[...normalizedSymbols]


If zero symbols are open, log:

[I8C-STARTUP] no open positions to subscribe

2. Subscribe each NEW trade immediately upon creation

In paper-execution-engine.ts, within the trade-creation workflow:

Add:

[I8C-ENGINE-SUBCALL] symbol=XYZ reason=new_trade


Then call the websocket adapter:

krakenWebSocketAdapter.subscribe([normalizedSymbol])


The normalized symbol MUST come from kraken-symbol-resolver.resolveAny().

3. SUBSCRIBE ALL open positions again on WEBSOCKET RECONNECT

Inside kraken-websocket-adapter.ts:

When the adapter emits or detects a reconnect event:

[I8C-WS-RECONNECT] reconnect_detected


Then:

Query engine or paper portfolio manager for current open positions

Resolve symbols

Re-subscribe all of them

And log:

[I8C-WS-RESUBSCRIBE][RECONNECT] symbols=[...]

4. Implement a 5-second SUBSCRIPTION HEALTH AUDIT

Create a repeating timer inside the WebSocket adapter:

setInterval(auditWebSocketSubscriptions, 5000)


The audit must:

Collect:

All currently open positions (compact or canonical)

All active Kraken WebSocket subscriptions

Compare:

For each position, determine:

Is it subscribed?

Has the channel expired?

Has tick age become > 10s? (stale)

If unsubscribed or stale:

Re-subscribe immediately

Log:

[I8C-AUDIT][FIX] symbol=XYZ reason=stale_or_missing_subscription

Audit summary log:
[I8C-AUDIT][SUMMARY] total_positions=15 subscribed=14 missing=1 stale=2

5. Implement TICK-ACK CONFIRMATION

Every time Kraken returns ticker data, log:

[I8C-WS-TICK][ACK] symbol=XYZ price=123.45


And update the centralized price cache.

This acts as proof that:

The subscription succeeded

The feed is active

The symbol is no longer reliant on REST fallback

6. Add DIAGNOSTIC ENDPOINT

Add:

GET /api/diagnostics/i8c/subscription-health

This endpoint must return:

{
  ok: true,
  engineRunning: true/false,
  openPositions: [...],
  websocketSubscriptions: [...],
  staleSymbols: [...],
  missingSymbols: [...],
  tickAges: { symbol: ms },
  summary: { total, subscribed, stale, missing }
}


This endpoint is critical for verifying correctness.
