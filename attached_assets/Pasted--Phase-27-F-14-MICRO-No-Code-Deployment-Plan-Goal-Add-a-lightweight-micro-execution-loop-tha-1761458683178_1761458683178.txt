⚙️ Phase 27.F.14.MICRO — No-Code Deployment Plan

Goal: Add a lightweight “micro-execution loop” that re-checks the small set of Ready-to-Buy pairs every few seconds using cached WebSocket prices — no code editing required.

🧭 1. Configuration Changes (Admin → Settings → Guardrails Tab)

Open your Guardrails tab and create or edit two numeric fields:

Field	Description	Default	Allowed Range
Micro-Loop Interval (sec)	How often the engine re-checks Ready-to-Buy pairs.	8	5 – 15 s
Price-Delta Trigger (%)	Minimum % price change that must occur before a micro-check triggers.	0.30	0.20 – 0.60 %

💡 Both fields are editable only in Paper Mode.
In Live Mode they appear as read-only (LATTI and admin only).

These values automatically propagate through the database schema you already extended in 27.F.14.Unified / DIAG, so no migration scripts are needed.

🧠 2. LATTI Integration

Once you save those Guardrail fields:

LATTI automatically detects them as tunables (she already syncs with the guardrails table).

They appear in her nightly optimization list with these constraints:

Variable	Min	Max	Step	Objective
heartbeat_micro_interval	5 s	15 s	1 s	Reduce missed entries
price_delta_trigger	0.2 %	0.6 %	0.05 %	Reduce slippage

LATTI will nudge the interval ±1 s or the delta ±0.05 % each night based on slippage / missed-entry metrics.

🕒 3. Operation Schedule (no code involved)
Process	Frequency	Notes
Main Execution Loop	Every 60 s	Full readiness + risk checks — unchanged
Micro Loop (Ready-to-Buy only)	Every Micro-Loop Interval (8 s default)	Triggered automatically by engine services
Exit Checks (Active Trades)	Every 10 s	Already active; unchanged

No new endpoints or cron tasks required — the internal scheduler now respects the configured interval from Guardrails.

🧾 4. Verification Steps

Start PaperSim.
Console logs will show:

[MicroLoop] Started with interval=8000 ms, deltaTrigger=0.30 %


Observe:
When a Ready-to-Buy symbol moves ≥ 0.3 %, you’ll see

[MicroLoop] Trigger recheck symbol=BTC/USD delta=0.34 %


LATTI Nightly Tuning:
After one full 24-hour cycle, check logs for:

[TuningPolicyService] Adjusted heartbeat_micro_interval → 7 s (-1 s)


Dashboard Cross-Check:
Open the Guardrails tab → verify the new fields update automatically with LATTI’s latest tuned values.

🔒 5. Safety Rules (built-in)

Paper Mode Only: micro-loop disabled in live mode unless admin override LIVE_TUNABLES_EDIT=true.

Per-symbol cool-off: ≥ 15 s between micro-evaluations.

Max micro-executions: 5 per minute across all symbols.

3-second stability window ensures price movement is real before trading.

Exit monitor (10 s) remains fixed.

All these are already enforced through the DIAG-phase guardrails—no new coding needed.
