🔷 Replit Directive — Phase N5: Repo Read-Only Introspection

Directive ID: N5-REPO-READONLY-INTROSPECTION
Lifecycle State: EXECUTION REQUESTED
Phase Context (Required):
Phase N5 establishes safe, governed, read-only introspection of the DawnTrader repository for ChatGPT. This eliminates manual file uploads, reduces context loss, and improves architectural correctness while preserving approval gating and execution safety.

Objective:
Enable ChatGPT to read and analyze the entire DawnTrader repository (read-only) via Chaplet, using an authoritative repo mapping file and strict governance rules.
