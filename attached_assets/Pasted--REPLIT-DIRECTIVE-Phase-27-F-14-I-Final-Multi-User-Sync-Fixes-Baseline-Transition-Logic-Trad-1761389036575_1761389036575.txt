3️⃣ Implement Baseline Transition Logic
🧩 Phase-Based Rules
Phase	Duration	Baseline Type	Guardrails/Filters	Notes
Short Burst (5–10 min)	Debug tests	Reset per simulation	Reset to defaults	Baseline = 0 at start of every test
25-Minute Simulation	Stability test	Cumulative within session	Resets on new run	LATTI begins adaptive learning mid-run
48-Hour Simulation	Learning phase	Persistent cumulative baseline	Persist between restarts	Produces final baseline for live trading
Implementation Details

Add a field in system_context:

Each simulation startup checks this value:

If per_simulation → reset LATTI baseline

If cumulative or persistent → reload and continue
