Task 2 — Pattern Injection in VTS

File: /server/services/vts-runner.ts

Import the pattern detector:

import { detectPatterns } from '@/core/pattern-recognizer';


Before creating a trade record:

const detectedPattern = detectPatterns(ohlc);

if (signalType === 'HYBRID' && !detectedPattern) signalType = 'QUANT';
if (signalType === 'PATTERN' && !detectedPattern) return; // discard invalid pattern


Attach the pattern to telemetry:

pattern: detectedPattern ?? null
