🧭 Directive 8.8.4-A4.R10R-3.T4 — Adaptive Concurrency Tuner
Objective

To implement, test, and validate an Adaptive Concurrency Tuner (ACT) for the RTB Refresh Service, allowing the system to dynamically adjust its signal-processing concurrency pool (POOL_SIZE) in real time, based on observed cycle duration and CPU headroom.

This will allow the system to maintain consistent performance and prevent under- or over-utilization of resources as the number of signals in the Ready-to-Buy (RTB) queue fluctuates.

Implementation Plan
1️⃣ Add Adaptive Concurrency Logic

In server/services/rtb-refresh-service.ts:

Introduce adaptive pool control parameters:

let POOL_SIZE = 5;
const MIN_POOL = 3;
const MAX_POOL = 10;
const TARGET_DURATION_MS = 5000;
const SAFE_CPU_THRESHOLD = 60;  // %
const SCALE_STEP = 1;


After every completed refresh cycle (CYCLE_COMPLETE log event), sample:

Average cycle duration (avgDuration)

CPU utilization or event loop lag (use 1ms baseline = ~25–30% load)

Adjust POOL_SIZE accordingly:

if (avgDuration < TARGET_DURATION_MS * 0.8 && cpuLoad < SAFE_CPU_THRESHOLD * 0.8 && POOL_SIZE < MAX_POOL) {
    POOL_SIZE += SCALE_STEP;
    console.log(`[T4][ACT] Increased POOL_SIZE to ${POOL_SIZE}`);
} else if (avgDuration > TARGET_DURATION_MS * 1.5 || cpuLoad > SAFE_CPU_THRESHOLD) {
    POOL_SIZE = Math.max(MIN_POOL, POOL_SIZE - SCALE_STEP);
    console.log(`[T4][ACT] Decreased POOL_SIZE to ${POOL_SIZE}`);
}


Log adaptive adjustments under the tag:

[8.8.4-A4.R10R-3.T4][ACT][POOL_ADJUST] poolSize=..., duration=..., cpu=...

Testing Procedure
Duration

⏱️ Run paper trading for 10–15 minutes under normal signal load.

Goal

To confirm that:

The RTB Refresh Service dynamically adjusts pool size

Cycle durations remain below 7 seconds

CPU remains under 60%

No overlap or drift events occur

Expected Behavior
Condition	Expected Action
Duration < 4 s, CPU < 45 %	Increase pool +1 (until max 10)
Duration > 8 s, CPU > 60 %	Decrease pool −1 (until min 3)
Duration 4–8 s, CPU < 60 %	Keep pool steady
Overlap or “refresh in progress”	Force pool −1 to avoid contention
