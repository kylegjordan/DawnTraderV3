🧠 Directive 11.1A — Persistent Intelligence: Contextual State Retention & Telemetry Resilience (Revised)
Phase: 11.1A
Schema Version Target: v1.5.2
Issued: January 2026
Objective:

Establish durable, SQL-backed, context-aware persistence of telemetry and adaptive intelligence, ensuring continuity across restarts while preventing split-brain storage and maintaining full integrity via checksum validation.

🧭 1. Purpose

This directive implements Persistent Intelligence within the DawnTrader architecture, providing intelligent rehydration of adaptive telemetry state from the PostgreSQL telemetry_history table upon system restart.

It also ensures that:

All telemetry records are tagged by market regime (critical for the DSS phase).

Telemetry is cryptographically verified for integrity.

Persistence is enabled only in live mode, with a FORCE_PERSIST=true flag for testing.

The previous JSON-based storage method is deprecated and removed to avoid split-brain scenarios.

New: /server/services/telemetry-repository.ts

import { db } from "../config/database";
import { telemetry_history } from "../schema/tables";

export async function loadRecentTelemetry(regime: string, limit = 100) {
  return await db
    .select()
    .from(telemetry_history)
    .where(telemetry_history.regime.eq(regime))
    .orderBy(telemetry_history.timestamp.desc())
    .limit(limit);
}

export async function saveTelemetryRecord(entry) {
  await db.insert(telemetry_history).values(entry);
}


Telemetry rehydration in aggregator:

import { getCurrentMarketRegime } from "../core/market-evaluation";
import { loadRecentTelemetry } from "./telemetry-repository";

export async function rehydrateTelemetryState() {
  const regime = getCurrentMarketRegime(); // e.g. "BULL_TREND"
  const recent = await loadRecentTelemetry(regime);
  telemetry.merge(recent);
  console.log(`[Telemetry] Rehydrated ${recent.length} entries for ${regime}`);
}
