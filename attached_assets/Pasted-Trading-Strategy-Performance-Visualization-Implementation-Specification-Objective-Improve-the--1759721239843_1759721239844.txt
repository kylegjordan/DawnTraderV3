Trading Strategy Performance Visualization — Implementation Specification
🎯 Objective

Improve the clarity and usability of strategy-level performance metrics on the dashboard and reports panel, making it easy to compare, diagnose, and refine each active or historical trading strategy.

1️⃣ Core Design Principles
Principle	Description
Separation of modes	Live and Paper results displayed independently but identically formatted.
Comparative context	Users can see how each strategy contributes to total portfolio performance.
Drill-down capability	Click into a strategy to view detailed stats and charts (e.g., win rate trends, average R-multiple).
Visual intelligence	Immediate visual cues (color, shape, trend) signal strong vs weak strategies.
Integration	Use existing metrics, feedback engine data, and daily brief generation pipeline.
2️⃣ Backend (already supported)

The backend now exposes everything needed for this feature via:

Trades table — strategy-level P&L, R-multiples, win/loss.

PredictionOutcomes table — prediction accuracy by strategy.

SignalWeights table — which signals contributed most.

FeatureSnapshots table — feature behavior per strategy.

✅ No new tables or endpoints required.
You only need to aggregate and visualize existing data.

3️⃣ New Frontend Components & Enhancements
A. Strategy Performance Widget (Dashboard)

Location:
Below Portfolio Overview, above Daily Brief Card.
Purpose:
Summarize how each strategy performed over the last 7 days.

Metric	Description
Win Rate %	% of profitable trades executed by that strategy
Avg R-Multiple	Mean R value per trade
Total P&L ($)	Realized profit/loss in USD
Prediction Accuracy %	% of correct directional calls (from Learning Feedback Engine)
Confidence Score (weighted)	Weighted average of confidence across trades
Status Indicator	🔵 Stable

Visuals:

Mini bar chart showing 7-day performance trend.

Strategy badge (VWAP Pullback / ABCD Long / SMA Trend Ride).

Color-coded gradient (green positive → red negative).

Tooltip: displays contributing signals from SignalWeights.

B. Strategy Detail View (Reports Panel)

Access: Click “View Details” from the Strategy Performance Widget.

Sections:

Overview

Total trades, win rate, avg holding time, cumulative P&L.

Confidence-weighted accuracy trend.

Signal Insights

Table of top signals by weight change (from SignalWeights).

“Influence ↑” or “Influence ↓” arrows to show shifts over time.

Prediction Diagnostics

Confusion matrix-style card:

Predicted Long / Correct | Predicted Long / Incorrect

Predicted Short / Correct | Predicted Short / Incorrect

Shows where prediction drift is happening.

Equity Curve Chart

Time-series of cumulative P&L for that strategy only.

Option to overlay Live vs Paper results for comparison.

Optional Filter Controls:

Date range selector

Mode toggle (Live / Paper)

“Show only top strategies” checkbox

C. Strategy Insights Section in Daily Brief

Add a new block in both Live and Paper Daily Briefs:

Strategy Insights Summary
🟢 SMA Trend Ride — Leading today with +2.3R, 86% prediction accuracy
🔴 ABCD Long — 4 consecutive losses, confidence drop from 0.78 → 0.61
💡 Recommendation: Reduce position size by 20% until volatility stabilizes

This section draws from:

The Learning Feedback Engine (confidence + accuracy trends).

Strategy-level metrics (R-multiple, P&L, win rate).

4️⃣ Technical Requirements
A. Frontend Data Sources
Widget	Endpoint	Mode Support
Strategy Performance Widget	/api/metrics/strategies	Live
Strategy Performance Widget (Paper)	/api/paper/metrics/strategies	Paper
Strategy Detail View	/api/metrics/strategies/:strategy_id/details	Both
Daily Brief Integration	/api/briefs/today (already includes strategy context fields)	Both

(If these endpoints don’t exist yet, Replit can create lightweight aggregations using existing metrics tables.)

B. State Management

Extend TradingModeContext to also store selected strategy for detail drill-down.

Use React Query caching for strategy metrics (15-minute refresh).

C. Responsiveness

Single-column stack for mobile.

2-column for tablets.

Full grid for desktop (Portfolio + Strategy + Brief in view).
