Strategy Presets & Defaults UI — Replit Prompt Specification
1️⃣ Purpose & Overview

Add a simple, powerful way for users to quickly load recommended parameter sets for each trading strategy (VWAP Pullback, ABCD Long, SMA Trend Ride).
Each preset defines a known-good configuration of validated parameters and can be:

loaded instantly into the form,

optionally modified,

saved through the existing /api/strategies/settings endpoint.

Presets help users (and later AI) restore or compare baseline configurations without manual entry.

2.2 Add Preset API Endpoints

File: server/routes.ts

import { STRATEGY_PRESETS } from "./services/strategy-presets.js";

// GET list of presets for a strategy
app.get("/api/strategies/presets", authRequired, async (req, res) => {
  const strategy = String(req.query.strategy || "");
  if (!STRATEGY_PRESETS[strategy])
    return res.status(404).json({ ok: false, message: "Strategy not found" });
  res.json({ ok: true, presets: STRATEGY_PRESETS[strategy] });
});

// GET a specific preset
app.get("/api/strategies/presets/:strategy/:presetName", authRequired, async (req, res) => {
  const { strategy, presetName } = req.params;
  const presets = STRATEGY_PRESETS[strategy];
  if (!presets || !presets[presetName])
    return res.status(404).json({ ok: false, message: "Preset not found" });
  res.json({ ok: true, preset: presets[presetName] });
});


No DB persistence required — presets are static, validated server-side.

2.3 Frontend UI Integration

File: client/src/components/goals/strategies-tab.tsx

Enhance the Strategies tab with:

Buttons:

Load Preset — populates the form with preset values.

Reset to Defaults — reloads default schema values (already implemented).

Save Preset — optional, saves as user custom preset (future Milestone #8).

On load, the system fetches available presets from /api/strategies/presets?strategy=....

Example hook:

const [presets, setPresets] = useState<Record<string, any>>({});
const [selectedPreset, setSelectedPreset] = useState<string>("");

useEffect(() => {
  if (!strategy) return;
  apiRequest("GET", `/api/strategies/presets?strategy=${strategy}`)
    .then((r) => setPresets(r.presets))
    .catch(() => setPresets({}));
}, [strategy]);

function handleLoadPreset() {
  if (!selectedPreset || !presets[selectedPreset]) return;
  setFormData(presets[selectedPreset]); // reuse existing form state setter
  toast.success(`Loaded ${selectedPreset} preset for ${strategy}`);
}

2.4 Validation and Hot-Reload

When a preset is loaded, form values are automatically validated with your existing Zod schema (from Milestone #6).

On Save, data follows the same flow: PUT /api/strategies/settings → validation → audit → EngineSettingsBus publish → hot-reload.

No new engine logic required.
