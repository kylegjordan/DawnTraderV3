🎯 Objective

Update the dashboard so that instead of showing a “Realized P/L (24h)” widget, the app displays a new Earnings Summary widget that shows total earnings over different time periods.
Also, add a new Earnings Chart (each tick = 1 day) below the existing “Portfolio Value Over Time” chart.

This will give an instant overview of how the trading bot is performing over time — both visually and numerically — without clutter.

🧮 2. EARNINGS SUMMARY WIDGET DETAILS
Purpose

Display total trading earnings over various time periods — without including deposits, withdrawals, paper trades, or the initial balance.

Title

Earnings Summary

Display layout example
Today:        +$320  
Yesterday:    +$280  
This Week:    +$1,050  
This Month:   +$3,700  
This Year:    +$12,500  
Lifetime:     +$18,300

Rules

“Earnings” = realized profit or loss from real trades only.

Exclude any transactions marked as deposits, withdrawals, or paper trades.

Update automatically whenever a trade closes or when the dashboard is refreshed.

Show amounts in USD, formatted to two decimal places.

Use color to indicate gain/loss:

Green for positive values

Red for negative values

Gray for zero

Design guidelines

Match the size and style of existing top widgets.

Keep light gray background and simple border like current design.

Text alignment should be clean and consistent (labels left, numbers right).

📈 3. EARNINGS CHART (Below Portfolio Chart)
Chart Title

Earnings Over Time

Purpose

Show daily trading earnings (realized profit/loss) so performance trends can be seen at a glance.

Placement

Position directly below the existing Portfolio Value Over Time chart.

Display rules

X-axis: Dates (1-day intervals).

Y-axis: Daily profit/loss (in USD).

Each tick on the chart represents one day.

Positive days should appear as blue or green line segments.

Negative days should appear in red.

Hovering the mouse should display a tooltip showing:

The date

The total earnings for that day

Update automatically as new trades close.

Data

Use the same source that feeds realized trade data.
Each day’s total = sum of all profits and losses from real trades closed on that date.
Exclude paper trades, deposits, and withdrawals.

🔌 5. CONNECTION CHECKS (No-Code Testing)

Before release, the Replit team should confirm the following:

Step 1 — Data connections

Verify that the data for earnings is being read correctly from the trading database or API.

Confirm that deposits, withdrawals, and paper trades are excluded.

Confirm that live and paper trades are being correctly categorized.

Check that timestamps are being recorded in the same timezone used for daily charts.

Step 2 — Display checks

All four widgets appear at the top of the dashboard.

The new Earnings Summary widget shows valid numbers for each period.

Values refresh automatically when a new trade closes.

No errors appear if there are no trades (zeros should display cleanly).

Step 3 — Chart checks

The “Earnings Over Time” chart appears below the portfolio chart.

Each tick represents exactly one day.

Hovering over any point shows the correct date and earnings amount.

The chart updates automatically when new daily data is recorded.
