Phase 27.F.21 — Trading Pace Data Alignment and Refresh Stabilization
🎯 Goals

Confirm and display the actual numeric values LATTI produces for each trading pace.

Correct percentage scaling so 1.5 % displays as 1.50 %, not 0.15 %.

Synchronize the manual input field with the current preset’s true LATTI value.

Eliminate the one-minute flashing refresh cycle.

1️⃣ Expose True LATTI Values for Diagnostics

Add a short-term console log or on-screen debug panel to verify backend returns:

console.table({
  conservative: lattiTargets.conservative?.target_daily_avg_earning_pct,
  baseline:     lattiTargets.baseline?.target_daily_avg_earning_pct,
  optimistic:   lattiTargets.optimistic?.target_daily_avg_earning_pct,
  aggressive:   lattiTargets.aggressive?.target_daily_avg_earning_pct,
});


✅ We expect numbers around 0.001 – 0.02 (decimals).
If these are already multiplied by 100 (e.g., 0.15 instead of 0.0015), then the frontend must not multiply again.

2️⃣ Fix Scaling and Display Logic

Correct rule

Source	Format	Display As	Store As
LATTI API	Decimal (0.015 = 1.5 %)	× 100 → 1.50	unchanged
Manual input	Percent string (1.5)	÷ 100 → 0.015	Decimal

Frontend adjustment

// When setting from LATTI
setTargetPct((latti.target_daily_avg_earning_pct * 100).toFixed(2));

// When saving
const saveValue = parseFloat(userInput) / 100;

3️⃣ Preset Switch = Auto-Fill LATTI Value

When a user selects a trading pace, populate the manual input with LATTI’s recommended percent:

useEffect(() => {
  if (!userOverride) {
    setTargetPct((latti.target_daily_avg_earning_pct * 100).toFixed(2));
  }
}, [selectedPace]);


No previous override values should persist between paces.

4️⃣ Eliminate Projection Table Flashing

Replace interval or subscription updates with a 5-minute throttle and “value-changed” guard:

const lastRefresh = useRef(0);
useEffect(() => {
  const now = Date.now();
  if (Math.abs(now - lastRefresh.current) > 300000) {
    refetch();                // once every 5 min
    lastRefresh.current = now;
  }
}, [targetPct]);              // only trigger on user input


✅ Table updates only when the percentage actually changes or every 5 minutes.

5️⃣ Confirm Defaults Per Pace

After fixing scaling, verify LATTI outputs approximately:

Pace	Expected Daily %	Behavior
Conservative	≈ 0.3 % – 0.5 %	Low risk
Baseline	≈ 0.8 % – 1.0 %	Balanced
Optimistic	≈ 1.2 % – 1.3 %	Growth
Aggressive	≈ 1.5 % – 2.0 %	High intensity

If the backend prints drastically lower values (like 0.0015 %), then multiply by 100 once on the frontend.
