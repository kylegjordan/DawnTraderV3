Directive 8.8.4-B.3 — Signal Flow Correction & Confidence Source Consolidation
Objective

Align the Signal Orchestration and Evaluation Pipeline with the approved architectural model defined in Directives 8.8.4-B and 8.8.4-B.1, ensuring:

Correct sequencing of all processing layers (including Sizing → SQE → RTB → TCL → Execution).

Consolidation of confidence handling under NGC (Normalized Global Confidence).

Deprecation of the legacy Confidence Threshold (%) filter and verification of NGC as the single confidence source across all UI and back-end references.

Implementation Tasks
Task 1 — Correct the Signal Orchestrator Flow

Re-establish the correct operational sequence in server/services/signal-orchestrator.ts:

Current (incorrect):

Compute Metrics → SQE Filter → TCL → Execution


Required (correct):

Signal Orchestrator
   → Sizing Helper (assigns trade size)
   → Compute Extended Metrics (NGC, CWQI, ProfitRate, ExpectedDuration)
   → Signal Quality Evaluator (SQE Filter)
   → Ready-to-Buy Queue (RTB ranking by CWQI)
   → Trade Capacity Limits (TCL)
   → Execution Engine


Specific Requirements

SQE must run after sizing is complete.

SQE output must be forwarded to RTB, not directly to TCL.

RTB must continue to rank signals by CWQI and only promote top-ranked signals when slots open.

TCL must never receive raw SQE output directly.

Update SLAL tagging for SQE → RTB → TCL transitions.

Confirm [B.3][FLOW_CORRECTED] log entry on initialization.

Task 2 — Deprecate the Legacy Confidence Threshold Filter

File: client/src/components/goals/screener-filters-tab.tsx

Remove or comment out the “Confidence Threshold (%)” control under Universe & Signal Controls.

Ensure it no longer applies any active filtering logic in:

Front-end state or context providers.

Back-end filter evaluation code (search for references to confidenceThreshold, filterConfidence, baseConfidence).

Replace any data-binding to baseConfidence with NGC.

Add [B.3][DEPRECATE_CONFIDENCE] log entry in initialization confirming removal.

Task 3 — Verify NGC as the Single Confidence Source

Confirm and document that NGC is now used in all of the following:

Area	File(s)	Verification Target

Trade History Tab	client/src/pages/trade-history.tsx	Confidence column → NGC

Database Schema	(if applicable)	Confidence field mapping → NGC

Each location must output [B.3][NGC_SOURCE_CONFIRMED] in logs after verification.

Task 4 — Confirm Ready-to-Buy Queue Integration

Ensure:

All signals passing SQE are inserted into RTB storage (insertRtbSignal).

RTB ranking is by CWQI (descending).

RTB promotions trigger when availableSlots > 0.

Logging: [B.3][RTB_FLOW_ACTIVE].
