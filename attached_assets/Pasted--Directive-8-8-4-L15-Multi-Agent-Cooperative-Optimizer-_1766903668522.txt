1 | Objective

Evolve the single reinforcement learning policy from L14 into a multi-agent cooperative optimization framework, where each strategy becomes an independent learning agent.

Each agent learns its own allocation policy while sharing reward and state feedback through a central Coordination Layer.
The collective goal is to balance exploration (testing new strategy behaviors) and exploitation (reinforcing profitable ones) to maximize total portfolio reward.

2 | System Overview
Component	Purpose
Strategy Agents (SA)	Individual reinforcement learners representing each active trading strategy.
Coordinator (COORD)	Aggregates agent states and rewards; enforces shared learning signals.
Exploration Manager (EM)	Dynamically modulates exploration probability (ε) based on global performance variance.
Policy Consensus Engine (PCE)	Uses gradient averaging to align agent policies toward the global optimum.
