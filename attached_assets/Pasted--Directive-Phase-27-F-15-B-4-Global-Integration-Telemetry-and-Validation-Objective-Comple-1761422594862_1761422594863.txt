4️⃣ Expand ModeRegistry → Telemetry Layer

Transform the existing placeholder into an active telemetry manager.

File: server/services/mode-registry.ts

Add runtime tracking fields:

export const ModeRegistry = {
  paper: { engineStatus:'stopped', riskSummary:{}, alerts:0, trades:0, lastUpdate:new Date() },
  live:  { engineStatus:'stopped', riskSummary:{}, alerts:0, trades:0, lastUpdate:new Date() },
};

export function updateModeStatus(mode, data) {
  ModeRegistry[mode] = { ...ModeRegistry[mode], ...data, lastUpdate:new Date() };
  contextBridge.broadcast({ type:'mode_status_updated', payload:{ mode, ...ModeRegistry[mode] } });
}


Integrate this telemetry into:

TradingEngine, RiskManager, PaperExecutionEngine

AlertService, MetricsService, DataBob
