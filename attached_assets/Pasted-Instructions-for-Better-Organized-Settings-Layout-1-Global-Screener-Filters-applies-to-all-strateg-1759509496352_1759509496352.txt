Instructions for Better-Organized Settings Layout
1. Global Screener Filters (applies to all strategies)

Purpose: These filters decide which coins are considered for trading before any strategy logic is applied. They reduce noise and screen out “junk” assets.

Parameters to include:

Minimum 24h Trading Volume ($)

Description: Excludes illiquid coins with low trading activity.

Default: 20,000,000.00

Minimum Daily Price Range (%)

Description: Ensures only coins with sufficient volatility are included.

Default: 5%

Market Cap Category Filters

Description: Define major pairs (BTC/ETH/top 20), mid-caps, and small/meme coins.

Usage: Used for categorization and slippage tolerance later.

Minimum Price Threshold ($)

Description: Filters out “dust” tokens or micro-price assets.

Default: $0.01

Allowed Trading Pairs

Description: Restrict to USD/USDT pairs or specific whitelisted bases.

Default: Only USD/USDT.

Bid-Ask Spread Filter (%)

Description: Excludes pairs with spreads above a threshold (slippage risk).

Default: 1.0%

Stablecoin Exclusion (Toggle)

Description: Removes stablecoins and pegged assets from screener.

Default: ON

Data History Requirement (days)

Description: Ensures sufficient candle history exists for backtesting/analysis.

Default: 90 days

Blacklist/Whitelist (manual entry)

Description: User-defined exclusion/inclusion of certain coins.

2. Portfolio Guardrails (global risk management)

Purpose: These are universal risk protections that apply after a strategy signals a trade but before execution.

Parameters to include:

Risk Per Trade ($)

Description: Maximum amount of capital risked per trade.

Default: $100

Maximum Portfolio Exposure (%)

Description: Caps total exposure across all open trades.

Default: 20%

Maximum Open Trades (#)

Description: Limits the number of concurrent positions.

Default: 3

Stop Buffer (%)

Description: Adds extra margin beyond calculated stop levels.

Default: 0.30%

Slippage Tolerance (%)

Global defaults by category:

Majors (BTC/ETH/top 20): 0.5%

Mid-caps: 2.0%

Small/Meme: 5.0%

Description: Maximum tolerated slippage during order execution.

Note: Allow per-strategy override.

3. Strategy-Specific Sections

Purpose: Each strategy gets its own dedicated block with a plain-language description and its own configurable parameters.

A. VWAP Pullback

Description: Trades pullbacks to VWAP (Volume-Weighted Average Price) during uptrends, aiming to capture continuation moves.

Parameters:

VWAP timeframe (minutes/hours)

Pullback threshold (%)

Confirmation volume multiplier

Max holding period (bars/candles)

B. ABCD Long

Description: Trades the breakout from consolidation after forming the A-B-C-D price structure.

Parameters:

Minimum consolidation length (bars)

Breakout threshold (%)

Volume confirmation multiplier

Exit condition (target % or trailing stop)

C. SMA Trend Ride

Description: Rides momentum trends based on Simple Moving Average (SMA) alignment and crossovers.

Parameters:

SMA length (periods)

Entry condition (above/below SMA, crossover rule)

Exit condition (break SMA, trailing stop %)

Slippage tolerance override (optional per strategy)

4. Layout / UI Instructions

Settings Page Tabs/Sections:

Screener Filters

Portfolio Guardrails

Strategies

Each strategy collapsible → with:

Text description (plain English)

Editable parameter fields

Labels must be beginner-friendly → e.g.:

Instead of “SMA Length,” use “SMA Length (number of periods in moving average).”

Instead of “Max Exposure,” use “Maximum Portfolio Exposure (% of account).”

Defaults pre-filled, but user can override.
