🧩 3. Corrective Code Changes for Replit

Apply the following exact edits:

(a) server/services/price-cache.ts
// Remove this local helper:
function normalizePair(symbol: string): string {
  return symbol.replace(/^X|Z/g, '').replace(/Z(USD|EUR|GBP|JPY|CAD|AUD)$/, '/$1');
}

// Add this import near top:
import { normalizeKrakenPair } from './kraken-normalizer';

// Replace all normalizePair() calls with:
const norm = normalizeKrakenPair(symbol);

(b) server/services/fx5-scanner.ts

Find all occurrences of:

const batchData = await fetchKrakenTickerBatch(symbols);


Replace with:

const batchData = await priceCache.getBatch('fx5Snapshot', symbols);


Ensure import { priceCache } from './price-cache'; is at the top.

(c) server/services/trade-executor.ts

Locate:

const price = await getKrakenPrice(symbol);


Replace with:

const price = priceCache.has(symbol)
  ? priceCache.get(symbol)
  : await getKrakenPrice(symbol);

(d) server/connectors/kraken-api.ts

Remove redundant retry logic around fetchKrakenTickers.
Change:

await safeFetchWithBackoff(url, retryCount);


To:

return await safeFetch(url);


and add a top-of-file comment:

// NOTE: Rate governance handled by price-cache.ts [A4.R10R-1]
