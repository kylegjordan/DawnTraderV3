Classification: Operational Directive

Objective:
Finalize the integrity of the Signal Quality Evaluator (SQE) and the Ready-to-Buy (RTB) system by enforcing strict pair-level duplicate checks, reconfirmation re-validation, and codebase alignment auditing to prevent unauthorized or improvisational code changes.

1. Pair-Level Duplicate Validation
Purpose

Ensure that signals are uniquely identified and qualified by their trading pair (symbol + quote currency) rather than by symbol alone.

Implementation

Update the SQE duplicate check to use a normalized pair key:

const pairKey = `${signal.base}/${signal.quote}`.toUpperCase();
const existsInRTB = await readyToBuyService.hasPair(pairKey, mode);
const existsInActive = await openTradeService.hasPair(pairKey, mode);

if (existsInRTB || existsInActive) {
  return { valid: false, reason: 'duplicate_pair_active' };
}


Update storage methods accordingly:

readyToBuyService.hasPair(pairKey, mode)

openTradeService.hasPair(pairKey, mode)

Database uniqueness key: (base, quote, mode)

Verification condition:

Two pairs with the same base but different quote (e.g., SOL/USD and SOL/GBP) are allowed.

Two identical pairs (e.g., SOL/USD and SOL/USD) across RTB + Active trades are prohibited.

2. Re-Qualification of Reconfirmed Signals
Purpose

Ensure that each RTB entry remains valid and high-quality through continuous re-evaluation of its CWQI and NGC scores.
Signals must be re-passed through SQE on every 30-second reconfirmation cycle.

Implementation

In ready_to_buy_service.refreshAndRank():

for (const signal of signals) {
  const updated = await fx5Service.fetchSignalData(signal.symbol);

  const validation = await sqe.validateSignal(updated, mode);

  // Remove any signal that fails re-qualification
  if (!validation.valid) {
    await this.removeSignal(signal.pairKey, mode);
    console.log(`[SQE][Expired] ${signal.pairKey} ${validation.reason}`);
    continue;
  }

  updated.CWQI = validation.cwqi;
  updated.NGC = validation.ngc;
  await this.updateSignal(signal.pairKey, updated);
}


Expected behavior

Signals failing thresholds are automatically removed from RTB.

CWQI and NGC dynamically re-weight ranking each cycle.

Logs clearly show SQE validation outcomes for auditability.
