Source

Kraken WebSocket → KrakenWebSocketAdapter

REST fallback → KrakenREST → live-pricing-adapter

Price caching

Where is the “latest price” per symbol stored? (e.g. in a map inside live-pricing-adapter)

Engine consumption

When PaperExecutionEngine evaluates exits, which function does it call to get the price?

Does it always request the latest cached price? Is there any per-position “currentPrice” stored?

API exposure

/api/paper-sim/active-trades → which fields come from where?

currentPrice

priceSource

priceAgeMs (or equivalent)

The goal is that we can read this and say:

“This is exactly how an updated Kraken tick becomes Current in Active Trades.”

4. Goal B — Fix backend pricing / exits if diagnostics show gaps

After you wire up A1–A3, run a short trading session (see verification section below). Use the diagnostics to confirm or fix the following:

WebSocket prices actually flow into the engine

For most active symbols, priceSource should be kraken_ws and priceAgeMs should stay reasonably low (e.g. under 10–20 seconds most of the time).

If symbols stay priceSource: "kraken_rest" and priceAgeMs grows large:

Check I7-WS-F coverage & subscriptions.

Ensure KrakenWebSocketAdapter updates the same price cache that the engine uses.

Exit evaluation uses fresh prices

When lastExitEvalAt advances, the new /api/diagnostics/i7-price/status should show new lastExitEvalPrice values, not stale copies.

For a symbol with a tight SL/TP:

If its Current price moves past SL/TP thresholds in the cache, a subsequent exit evaluation cycle should produce an actual close (stop_hit / target_hit) in Trade History.

Stuck trades (“Open – Not Closed Yet”)

If diagnostics show positions where:

priceSource is valid

priceAgeMs is low

lastExitEvalAt is moving
but they remain “Open – Not Closed Yet” indefinitely, investigate the exit condition logic in paper-execution-engine.ts:

are SL/TP comparisons correct?

is there any threshold / dead-band preventing triggers?

Only make minimal changes necessary to ensure:

For a reasonably volatile symbol, some trades are closed by stop_hit or target_hit within a 10–15 minute session.
