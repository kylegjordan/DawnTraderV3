2.4 Passive-Mode Behaviour Rules (Engine STOPPED)

When the paper trading engine is STOPPED and passive learning is ON, behaviour should be:

Kraken Universe

Shows the current universe size from REST. OK to keep real value here.

Cycle Info

Next Scan In may continue to tick as a heartbeat based on the real FX5 scanner interval (Option A, mini-ticks allowed).

Last Scan Time / Cycle ID should reflect the latest actual FX5 scan (if any); if the scanner is not running at all, show an appropriate “—” or “No scan yet” state.

Cycles per Hour should reflect reality (if only a few scans in the last hour, show a small value; if none, show 0 or “0.0”).

Last Scan Result (This Scan)

Values should follow whatever the latest real FX5 scan produced.

When the scanner is effectively idle, these may be zeros most of the time; occasional mini-ticks are acceptable as long as they are genuine.

24h Filter Activity & Filter Breakdown

When there have been no ACTIVE trading cycles in the last 24 hours:

All 24h metrics must be 0.

All Filter Breakdown per-category counts must be 0.

There must be no stale values carried over from the last ACTIVE session.

If you prefer, you may show an explicit “No 24h data available yet” message when totals are zero and there is genuinely no active history.

Active Filtered Pool

Total active filtered pairs should be 0.

Table shows “No Eligible Pairs” empty state, no spinner.
