📌 REPLIT DIRECTIVE

Phase M4.4 — Directive Lifecycle Enforcement Templates

CONTEXT / WHY THIS EXISTS

We have confirmed that the Bridge now successfully preserves context, governance, and phase anchoring.
However, there is currently no enforced lifecycle loop that guarantees:

Directives are paused after execution

Human approval is explicitly requested

Canonical history is always written

Phase advancement cannot silently occur

This creates a risk of:

Lost execution history

Unlogged decisions

Phase drift due to human forgetfulness

This directive introduces mandatory lifecycle enforcement using templates only — no automation.

OBJECTIVE

Upgrade Bridge templates so that every directive must follow a formal lifecycle:

DRAFT → EXECUTED → AWAITING_APPROVAL → CANONICALIZED


This lifecycle must be:

Explicit

Human-gated

Logged

Impossible to bypass accidentally

SCOPE (STRICT)

✅ Allowed

Editing Bridge templates and READMEs

Adding lifecycle language and required sections

🚫 Not Allowed

No automation

No background jobs

No logic changes

No execution triggers

No phase changes
