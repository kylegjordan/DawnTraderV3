🚀 DIRECTIVE — Phase 8.8.1 Scanner Output Audit

This directive describes EXACTLY what to do, step-by-step.

📘 Objective

Audit and document the complete structure of FX5 scanner output, ensuring:

eligibleSymbols is clean, consistent, typed correctly

breakdown is correct and aligned with UI & downstream expectations

Stage 3 scan_tick emits correct, complete payloads

NO legacy or deprecated fields exist

NO missing fields

NO undefined values

NO NaN

NO stale V1/V2 attributes

This ensures the data pipeline is strong before signals → strategies → trades begin.

🔷 STEP 1 — Inspect scanner output structures

Open and inspect these files:

server/services/market-scanner.ts
server/services/stage3/stage3-state-cache.ts
server/services/stage3/stage3-state-emitter.ts
server/services/filtering/fx5.ts
server/services/filtering/fx5-breakdown.ts


Confirm:

eligibleSymbols[] must only contain:
symbol: string
baseCurrency: string
quoteCurrency: string
volume24h: number
currentPrice: number
dailyRange: number
vwap: number | null

Breakdown keys must be exactly:
failed_min_volume
failed_spread
failed_daily_range
failed_min_price
failed_stablecoin
failed_quote_currency
failed_history
failed_market_cap
failed_guardrail_risk
failed_universe_size
already_active
passed_all_filters

Must also confirm:

✔ NO "score"
✔ NO "confidence"
✔ NO "reason"
✔ NO "priority"
✔ NO "trend"
✔ NO V1/V2 fields

🔷 STEP 2 — Add temporary audit logging

Add the following logging inside:

market-scanner.ts → inside runUnifiedCycle(), right after eligibleSymbols is created:

console.log("[8.8.1][AUDIT] Eligible sample:", eligibleSymbols.slice(0, 5));


Add this logging after breakdown is constructed:

console.log("[8.8.1][AUDIT] Breakdown keys:", Object.keys(breakdown));


Add this logging in Stage 3 emitter:

stage3-state-emitter.ts → emitStage3ScanTick()

console.log("[8.8.1][AUDIT][STAGE3] scan_tick payload:", {
  evaluated: payload.evaluated,
  eligible: payload.eligible,
  sample: payload.eligibleSymbols.slice(0, 5)
});

🔷 STEP 3 — Validate Stage 3 scan_tick payload

Call this endpoint:

GET /api/market-scanner/scan-summary?mode=paper
GET /api/market-scanner/24h-activity?mode=paper


Check:

evaluatedCount exists

eligibleCount exists

ineligibleCount exists

breakdown count matches breakdown keys above

eligibleSymbols array contains only valid fields
