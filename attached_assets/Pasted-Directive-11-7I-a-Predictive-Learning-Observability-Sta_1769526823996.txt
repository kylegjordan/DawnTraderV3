Directive 11.7I.a — Predictive Learning & Observability Stabilization (Phase A)

Phase: 11
Sub-Phase: 11.7I.a
Status: REQUIRED before Phase B (LATTi removal / replacement)
Scope: Infrastructure correctness, observability, scheduling, diagnostics, and simulation integrity
Non-Goals:

No LATTi / Adaptive Guardrails refactor yet

No new strategy logic

No paper trading activation yet

Purpose

Phase 11 introduced multiple predictive learning, telemetry, and diagnostics systems.
However, several critical services were not running, not wired, or not observable, resulting in misleading UI states and silent failures.

This directive does not add new intelligence.
It ensures that all Phase 11 systems are actually running, observable, auditable, and understandable before proceeding.

Every task below MUST include verifiable proof of execution.

MANDATORY RULE (Read First)

For each task below, implementation is not considered complete until Replit provides concrete proof that the system is live, executing, and producing data.

Acceptable proof includes:

Logs (with timestamps)

API responses (raw JSON)

Screenshots of populated UI tabs

Manual trigger output

Before/after comparisons

“No errors” or “code added” is not proof.
