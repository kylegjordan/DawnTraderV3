🔄 Revision Note (Gemini Addendum)

Architectural Enhancement:
Adaptive learning weights must carry their updatedAt timestamp through the persistence and rehydration process so that the AdaptiveManager can apply time-based decay.
This prevents stale learning from exerting undue influence on current trading behavior.

⚙️ Affected Section: Task 2 (Extend Telemetry Aggregator)

Original Code:

export async function rehydrateAdaptiveLearning() {
  const regime = getCurrentMarketRegime();
  const weights = await loadAdaptiveWeights(regime);
  adaptiveManager.initialize(weights);
  console.log(`[Learning] Rehydrated ${weights.size} adaptive weight profiles for ${regime}`);
}

✅ Updated Implementation (with Timestamp Awareness)
export async function rehydrateAdaptiveLearning() {
  const regime = getCurrentMarketRegime();
  const results = await loadAdaptiveWeightsWithTimestamps(regime);

  const timestampedWeights = new Map(
    results.map(r => [r.strategyId, { weights: JSON.parse(r.weights), updatedAt: new Date(r.updatedAt) }])
  );

  adaptiveManager.initializeWithTimestamps(timestampedWeights);
  console.log(`[Learning] Rehydrated ${timestampedWeights.size} adaptive profiles for ${regime}`);
}

🧩 Companion Repository Function

File: /server/services/adaptive-learning-repository.ts

Add this function to preserve timestamps:

export async function loadAdaptiveWeightsWithTimestamps(regime: string) {
  return await db
    .select({
      strategyId: adaptive_learning.strategyId,
      weights: adaptive_learning.weights,
      updatedAt: adaptive_learning.updatedAt,
    })
    .from(adaptive_learning)
    .where(and(adaptive_learning.mode.eq("live"), adaptive_learning.regime.eq(regime)));
}

🧠 Adaptive Manager Interface Update

File: /server/core/adaptive-manager.ts

Add a new method for time-weighted initialization:

export function initializeWithTimestamps(data: Map<string, { weights: AdaptiveWeights, updatedAt: Date }>) {
  data.forEach((entry, strategyId) => {
    const ageDays = (Date.now() - entry.updatedAt.getTime()) / (1000 * 60 * 60 * 24);
    const decayFactor = Math.exp(-0.05 * ageDays); // 5% decay per day

    const decayedWeights = Object.fromEntries(
      Object.entries(entry.weights).map(([k, v]) => [k, v * decayFactor])
    );

    internalWeights.set(strategyId, decayedWeights);
  });
  console.log(`[Learning] Initialized ${data.size} adaptive profiles with time decay applied`);
}


✅ This introduces a natural temporal decay to learning weights based on their age, preventing old data from overpowering new market intelligence.
