📘 Directive 11.8B-C2 — Purpose Tab Removal & Strategy Preset Audit
Objective

Complete the final cleanup of legacy UX and API artifacts remaining after Goals ML & Preset decommission (11.8B-C), by:

Removing the Purpose tab entirely from the Goals Engine UI and routing.

Auditing and decommissioning /api/strategies/presets if confirmed to be a legacy, non-functional artifact.

Ensuring no downstream strategy logic, execution logic, or UI paths depend on strategy presets.

Providing verifiable evidence that nothing references the removed components.

This directive does NOT introduce new functionality.
It strictly removes dead or misleading surfaces.

🔒 Scope Guardrails (Read Carefully)

Replit MUST NOT:

Modify any Phase 11 predictive learning systems

Modify strategy execution logic

Modify signal generation, SQE, DSS, VTS, or TEC

Add new abstractions, defaults, or replacement logic

Reinterpret “strategy presets” as something new

If /api/strategies/presets is still required by live strategy execution, it must be preserved — but only if proven.
