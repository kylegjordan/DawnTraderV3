Topic: Portfolio Value mismatch and earnings validation

🎯 Objective

Ensure the Portfolio Value widget reflects the actual live value from your linked Kraken account, and confirm that the Earnings Summary and Earnings Chart are pulling accurate, real-time data (excluding paper trades, deposits, and withdrawals).

1️⃣ Portfolio Value — Verification & Correction

Issue:
The Portfolio Value displayed in the dashboard does not match the live Kraken balance.

Steps to verify:

Confirm data source

Check where the portfolio value is currently being fetched from.

It should read directly from the Kraken account API, not from a cached or simulated balance.

Make sure paper trades or test data aren’t included in this total.

Check Kraken API connection health

Verify the connection token is valid and not using sandbox/test credentials.

Confirm that the last sync time (if displayed) matches within the last 1–2 minutes.

If it’s out of sync, trigger a manual balance refresh and ensure the new data updates on the dashboard.

Reconcile totals

Compare the total shown in the dashboard with:

The Kraken account total (USD equivalent).

The app’s internal cash + crypto breakdown in the “Cash vs Crypto” widget.

Both should add up to the same value as the live Kraken total.

Perform a live test

Make a small change in Kraken (e.g., open or close a small trade) and check if the Portfolio Value updates accordingly within 60 seconds.

If not, confirm whether the refresh endpoint or polling mechanism is functioning.

2️⃣ Earnings Summary — Accuracy Check

Steps to confirm:

Ensure earnings exclude:

Deposits and withdrawals

Paper trades

Initial seed balance

Confirm that each line in the Earnings Summary updates correctly:

“Today” should match the total realized P/L of all trades closed today.

“Yesterday” should show the previous day’s total.

“Week,” “Month,” and “Year” should roll up correctly based on calendar periods.

“Lifetime” should show cumulative realized P/L since first live trade.

Ask Replit to perform cross-check tests by comparing:

The earnings summary values with the backend database or API logs of closed trades.

The cumulative total with the value shown in the Earnings Chart for the same date range.

3️⃣ Earnings Chart — Data Validation

Confirm the following:

Each tick on the chart represents exactly one day.

When hovering, the date and daily earnings value match backend records.

Positive days appear in blue or green; negative in red.

Zero-activity days are displayed as flat points or zero-value bars.

The chart’s rightmost point reflects today’s activity.

Testing recommendation:
Ask Replit to generate a 7-day test dataset with mock trades (3 profitable, 2 losses, 2 no-trade days) to confirm that the chart correctly visualizes all cases.

4️⃣ Connection & Data Health Checks

Request that Replit logs and reports the following back to you:

✅ Kraken connection test result (status, latency, and API key validation)

✅ Portfolio balance source (live API vs internal cache)

✅ Timestamp of last data sync

✅ Backend calculation verification for each Earnings Summary category

✅ Chart rendering data (how many daily entries returned, total range covered)

You should receive a short report summarizing:

• Kraken API status: ✅ Connected (Last sync: 2:14 PM UTC)
• Portfolio Value Source: Live API (Kraken)
• Dashboard Value: $50,149.96
• Kraken Account Total: $50,300.00
• Variance: -$150.04 (due to pending open trade value sync)
• Earnings Summary Validation: ✅ All calculations correct
• Chart Data Points: 30 days (29 populated, 1 pending)

5️⃣ Final Confirmation Checklist

Ask Replit to confirm the following before closing the ticket:

Check	Expected Result
Kraken API connection	Stable and using live credentials
Portfolio Value	Matches Kraken balance ± 1% tolerance
Cash vs Crypto totals	Sum equals portfolio value
Earnings Summary	Matches backend calculations
Earnings Chart	Matches per-day earnings records
Data Refresh	Updates within 1–2 minutes of trade change
Error Handling	Graceful message if connection fails
