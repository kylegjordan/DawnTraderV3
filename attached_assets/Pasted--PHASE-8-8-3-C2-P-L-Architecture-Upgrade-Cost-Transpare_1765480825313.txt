✅ PHASE 8.8.3-C2 — P/L Architecture Upgrade, Cost Transparency, Trade History Enhancements
Primary Goal

Separate Gross P/L from all execution costs, clearly surface slippage + fees, calculate Net P/L, and ensure Trade History + Active Trades display consistent, accurate values.

🎯 Part A — Data Model & Backend Logic Updates
A1. Database Fields Required (Trade History Only)

You do NOT need to change open-positions schema — only the closed trade records (paper_sim_trades).

Ensure the following fields exist (many are already present):

Trade Table Required Columns
Column	Type	Description
entry_fee	numeric	Actual entry fee paid
exit_fee	numeric	Actual exit fee paid (or estimated at close)
total_fee	numeric	entry_fee + exit_fee
entry_slippage	numeric	Actual entry slippage cost
exit_slippage	numeric	Calculated when trade closes
total_cost	numeric	entry_fee + exit_fee + entry_slippage + exit_slippage
gross_pnl	numeric	Market P/L without costs
net_pnl	numeric	gross_pnl – total_cost
net_pnl_percent	numeric	Percent net return on the position
Directive

Add missing DB columns if not present

Ensure exit_slippage, total_cost, gross_pnl, net_pnl, net_pnl_percent exist

Backfill: Existing trades may have zero cost values — this is acceptable

A2. Execution Engine Updates (Open Trades Only)

Open trade P/L should now include:

Gross P/L
grossPL = (currentPrice – entryPriceWithoutSlippage) × quantity

Costs (separate columns)

entry_slippage (actual from entry)

entry_fee (actual)

exit_fee_estimate (estimated using fee rate × current value)

exit_slippage_estimate (apply same slippage % used for entry)

Estimated total_cost
estimatedTotalCost = entry_fee + entry_slippage + estimated_exit_fee + estimated_exit_slippage

Net P/L
netPL = grossPL – estimatedTotalCost

Directive

DO NOT modify core trade execution logic for slippage or fees

DO add the new calculations for UI consumption

Expose these to the /api/paper-sim/open-positions response

A3. Guardrail and Balance Logic

Current guardrails incorrectly use startingBalance.

Directive

Update guardrails to use currentBalance, where:

currentBalance = startingBalance + realizedNetPL + unrealizedNetPL
