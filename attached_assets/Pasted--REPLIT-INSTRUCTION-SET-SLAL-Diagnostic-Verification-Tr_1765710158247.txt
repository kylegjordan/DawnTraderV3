⚙️ Phase 3 — Add Post-Validation Hook (Code Update)
Objective

Ensure SLAL only records EXECUTION events after the trade object has been confirmed and added to the system’s active trade set.

Steps

In /server/services/paper-execution-engine.ts, find the section that currently calls:

signalLifecycleAudit.recordExecution(signal.id, payload);


Modify logic to delay SLAL recording until after trade creation is successful:

const trade = await this.createTrade(signal);

if (trade && trade.id) {
  signalLifecycleAudit.recordExecution(signal.id, {
    tradeId: trade.id,
    status: 'confirmed',
    strategy: signal.strategy,
    pair: signal.pair
  });
} else {
  console.warn(`Trade creation failed for signal ${signal.id}`);
}


Restart the workflow and verify that new EXECUTION logs now include:

tradeId always populated

Matching count between “Executed” signals and “Active Trades”
