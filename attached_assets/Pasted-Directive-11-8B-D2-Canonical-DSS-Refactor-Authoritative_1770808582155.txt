SECTION 5 — DSS SELECTION ALGORITHM
5.1 Selection Flow
const regime: CanonicalRegime = detectCanonicalRegime(indicatorContext);


const strategies = CANONICAL_REGIME_STRATEGY_MAP[regime];


for (const strategyKey of strategies) {
  if (preconditions[strategyKey](indicatorContext)) {
    return {
      regime,
      selectedStrategyKey: strategyKey,
      signalType: getSignalType(strategyKey)
    };
  }
}


return null;

No scoring. No ranking. No fallback.

SECTION 6 — PRECONDITIONS (EXPLICIT, CANONICAL-METRIC-ALIGNED)

Each strategy must implement a precondition function matching its canonical secondary metrics exactly.

isEligible_sma_trend_ride(ctx) {
  return ctx.price > ctx.sma50 * 1.005 && ctx.adx > 25;
}


isEligible_vwap_pullback(ctx) {
  return ctx.vwapDeviation < -1 * ctx.stdDev && ctx.momentum > 0;
}

Pattern and Hybrid preconditions must reflect canonical table metrics only.

No reinterpretation allowed.
