🟦 SECTION B — Correct Price Flow for Trade-Monitoring Engine
B1 — Stop using DB prices for engine decisions

Open paper-portfolio-manager.ts and/or trade-monitoring engine (where SL/TP and exit logic are checked):

Replace:

const price = trade.entryOrStoredPrice;


With:

const price = livePricingAdapter.getLatestPrice(trade.symbol);
if (!price) return; // no tick received yet → safely skip this cycle

B2 — Evaluate SL/TP using live price
if (price <= trade.stopLoss) closeTrade("stop_hit");
if (price >= trade.takeProfit) closeTrade("take_profit");

B3 — Recompute P/L using live price

Remove any P/L code that uses DB values.
