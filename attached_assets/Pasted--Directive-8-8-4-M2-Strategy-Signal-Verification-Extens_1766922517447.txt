🧭 Directive 8.8.4-M2 — Strategy & Signal Verification Extension (SSVE)
🔹 Purpose

Validate correctness of all strategy-level calculations, weight propagation, and ranking logic.
Ensure that CWQI, NGC, Decision Index (DI), and related metrics are applied properly across the signal lifecycle — from raw input to RTB queue ranking — and that authentication-protected modules (MACO, ARA) are now included.

🧩 Step 1 — Create Extended Audit Service

Create:

/server/services/strategy-signal-audit-engine.ts


Code:

import fs from "fs";
import path from "path";
import axios from "axios";

export class StrategySignalAuditEngine {
  private report: any = {
    timestamp: new Date().toISOString(),
    sampleSize: 0,
    mismatches: [],
    summary: {},
    authUser: "testuser123",
  };

  private baseUrl = process.env.AUDIT_BASE_URL || "http://localhost:5000";

  private async authHeaders() {
    return {
      headers: {
        Authorization:
          "Basic " +
          Buffer.from("testuser123:SecurePass123!").toString("base64"),
      },
    };
  }

  async run() {
    console.log("[SSVE] Starting Strategy & Signal Verification...");
    const headers = await this.authHeaders();

    const rtbRes = await axios.get(`${this.baseUrl}/api/signals/ready`, headers);
    const signals = rtbRes.data?.signals || [];
    this.report.sampleSize = signals.length;

    console.log(`[SSVE] Found ${signals.length} signals to audit`);

    for (const sig of signals.slice(0, 100)) {
      const recomputed = this.recalculate(sig);
      this.compare(sig, recomputed);
    }

    this.report.summary = this.buildSummary();

    const outDir = path.join(process.cwd(), "reports");
    if (!fs.existsSync(outDir)) fs.mkdirSync(outDir, { recursive: true });
    const outPath = path.join(outDir, `SSVE_Report_${Date.now()}.json`);
    fs.writeFileSync(outPath, JSON.stringify(this.report, null, 2));

    console.log(`[SSVE] Completed. Report saved at ${outPath}`);
    return this.report;
  }

  private recalculate(sig: any) {
    // Recompute CWQI, NGC, DI using raw data
    const { volume, volatility, confidence, profit_pred, loss_pred, ageMinutes } = sig;

    // CWQI = weighted composite quality index
    const cwqi =
      0.4 * confidence +
      0.3 * (1 - volatility) +
      0.2 * (profit_pred - loss_pred) +
      0.1 * Math.max(0, 1 - ageMinutes / 600);

    // NGC = normalized gain coefficient
    const ngc = (profit_pred - loss_pred) / (Math.abs(profit_pred) + Math.abs(loss_pred) + 1e-6);

    // Decision Index approximation
    const di = 0.25 * cwqi + 0.25 * ngc + 0.25 * (sig.strategyWeight || 0.5) + 0.25 * (sig.exposureMult || 1);

    return { cwqi, ngc, di };
  }

  private compare(original: any, recomputed: any) {
    const tolerance = 0.05;
    for (const key of ["cwqi", "ngc", "di"]) {
      const o = Number(original[key]) || 0;
      const r = Number(recomputed[key]) || 0;
      const diff = Math.abs(o - r);
      if (diff > tolerance) {
        this.report.mismatches.push({
          symbol: original.symbol,
          strategy: original.strategy,
          metric: key,
          original: o,
          recomputed: r,
          diff,
        });
      }
    }
  }

  private buildSummary() {
    const mismatches = this.report.mismatches;
    const total = this.report.sampleSize;
    const mismatchRate = (mismatches.length / total) * 100;
    return {
      total,
      mismatches: mismatches.length,
      mismatchRate: `${mismatchRate.toFixed(2)}%`,
      ok: mismatchRate < 10,
    };
  }
}

export const ssveEngine = new StrategySignalAuditEngine();

if (require.main === module) {
  ssveEngine.run();
}

🧩 Step 2 — Add Route for Signal Verification Audit

Create:

/server/routes/signal-audit.ts


Code:

import express from "express";
import { ssveEngine } from "../services/strategy-signal-audit-engine";
const router = express.Router();

router.get("/run", async (_req, res) => {
  try {
    const report = await ssveEngine.run();
    res.json({ status: "OK", report });
  } catch (err) {
    res.status(500).json({ status: "FAIL", error: err.toString() });
  }
});

export default router;


Then register in your main server index:

import signalAuditRoutes from "./signal-audit";
app.use("/api/signal-audit", signalAuditRoutes);

🧩 Step 4 — Verify Data Flow Integrity

The audit will confirm:

CWQI, NGC, and DI recomputed match DB-stored values.

Strategy weighting (SWGT) and exposure multipliers propagate correctly.

Ranking logic in the Ready-to-Buy pool sorts signals consistently.

If mismatch rate < 10 %, metrics are functioning normally.
If > 10 %, that strategy’s formula or weighting flow is broken.
