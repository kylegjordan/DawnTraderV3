All trades with closed_at = null must either:

still have a matching open position OR

be immediately closed with an appropriate close_reason.

2. RTB Metrics correctly represent reality

RtbMetricsService is the single source of truth for:

total attempts

total opened

total blocked

all block reasons

The RTB Breakdown UI table must show:

every guardrail block reason that increments metrics

correct counts

totals that equal blockedTotal

Top-level RTB Summary:

attemptsTotal === openedTotal + blockedTotal must always hold

Breakdown subtotal must equal blockedTotal

3. No changes to trading behavior

Do NOT implement RTB queueing logic

A. TRADE STATUS CONSISTENCY FIX
A1. On STOP, fully reconcile trade records

Modify the stop flow (paper-sim-service + portfolio manager) to:

After force-closing all open positions:

Query DB for any trades for this session where:

closed_at IS NULL


For each such trade:

If a matching row exists in paper_sim_open_positions → leave it as open

If no matching open position exists → close it immediately:

closed_at = NOW()

Emit trade-lifecycle event: { type: 'trade_closed_cleanup', ... }

Result:
No “Open – Not Closed Yet” trades after a stop unless the DB truly has an open position.
