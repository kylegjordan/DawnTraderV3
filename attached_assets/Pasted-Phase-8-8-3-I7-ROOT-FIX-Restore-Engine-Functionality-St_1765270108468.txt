Phase 8.8.3-I7-ROOT-FIX — Restore Engine Functionality, Stop Behavior, and Remove Duplicates
Context for Replit

The trading system has regressed in multiple critical ways:

The engine is no longer closing trades.
Despite receiving price updates (or at least appearing to), the engine does not execute exit checks or closures.

Prices appear static on both UI and engine side.
There are no trade history entries despite 15 active positions.

Clicking “Stop Trading” still results in new positions opening.
This indicates that:

The wrong engine instance may be stopped

Or stop() is not having effect

Or a second engine instance is still consuming signals

Active Trades + Ready To Buy are showing duplicate entries.
These duplicates were not present before recent phases were implemented, so they are likely a consequence of new changes.

The purpose of this directive is to fix the root problems, not symptoms.

The entire I7-MAP series (MAP-FIX, MAP-AUTO, MAP-VER) produced correct diagnostics, but mapping was never the cause of these failures.

This phase introduces minimal, targeted patches to restore:

Engine evaluation cycle

Exit execution

True stop behavior
