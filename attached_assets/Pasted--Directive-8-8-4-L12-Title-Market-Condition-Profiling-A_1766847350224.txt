🧭 Directive 8.8.4-L12
Title: Market Condition Profiling & Adaptive Regime Switching
Phase: L-Series Intelligence Tier III (Global Adaptive Layer)
Status: Ready for Implementation
1 | Objective

To integrate a global market-state classifier and adaptive control layer that continuously profiles market conditions using live and historical data, identifies current “regimes,” and automatically adjusts:

Active strategy mix

Strategy weights (α bias × β exposure × confidence)

Risk allocation and ARA guidance

Result → The system trades differently in different markets instead of treating all volatility the same.

2 | Core Concept
Concept	Description
Market Condition Profiler (MCP)	Collects multi-asset indicators to classify current regime.
Adaptive Regime Engine (ARE)	Maps each regime → strategy mix matrix.
Dynamic Allocator (DA)	Adjusts exposure multipliers & weights based on regime score.
3 | Regime Categories
Regime ID	Description	Typical Profile
T1 – Trending Bull	Persistent uptrend, low volatility	Breakout ↑ Bias
T2 – Trending Bear	Persistent downtrend	Reversal ↑ Bias
R1 – Range-Bound	Mean-reverting sideways markets	Momentum ↓ Bias
V1 – High Volatility Chop	Whipsaw, large swings	DHMA ↑ Bias
C1 – Calm Consolidation	Low volatility, flat volume	Low exposure
4 | Implementation Tasks
4.1 Market Profiler Service

📁 server/services/market-profiler.ts

Inputs

OHLC candles (multi-symbol aggregate)

Realized volatility (σ)

Average true range (ATR)

Volume z-score (ζ)

Trend slope + strength (via linear regression)

Cross-asset correlation matrix

Outputs

{
  "timestamp": "2025-12-22T17:00Z",
  "regime": "T1",
  "confidence": 0.82,
  "metrics": {"volatility":0.14,"trend":0.87,"volume_z":0.5}
}


Runs every 15 minutes; publishes to in-memory cache and WebSocket bus.

4.2 Adaptive Regime Engine (ARE)

📁 server/services/adaptive-regime.ts

Responsibilities

Subscribe to MCP updates.

Look up regime-strategy matrix:

Regime	Strategy Mix (Target %)
T1	Breakout 45
T2	Reversal 50
R1	Momentum 50
V1	DHMA 60
C1	All ≤ 10 (low exposure)

Update live strategyWeight and exposureBias scalars used by signal orchestrator.

Log transitions:

[L12][REGIME_SWITCH] R1→T1 (confidence 0.82)

4.3 Python ML Service Enhancements

📁 services/ml_service.py

Add /regime/current endpoint returning latest MCP output.

Include regime in /predict/profit metadata.

Store regime labels with training samples for conditional re-training (“context-aware ML”).

When regime changes, temporarily increase learning rate for fast adaptation.

5 | Formulas & Parameters
Symbol	Meaning	Default
σ	Realized volatility	20-period std dev
ζ	Volume z-score	(Vol – mean) / σVol
T	Trend strength	
R_conf	Regime confidence	softmax over classifier outputs
Switch Threshold	0.65	minimum confidence for regime change

Classifier model: LightGBM (5 features → 5 regimes), trained on VTS synthetic history.
