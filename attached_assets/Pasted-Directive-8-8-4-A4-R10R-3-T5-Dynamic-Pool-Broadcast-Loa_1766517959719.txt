2️⃣ Smoothed CPU Averaging

Add rolling CPU array in rtb-refresh-service.ts:

let cpuSamples = [];
function recordCpuSample(cpu) {
  cpuSamples.push(cpu);
  if (cpuSamples.length > 5) cpuSamples.shift();
  const avgCpu = cpuSamples.reduce((a,b)=>a+b,0)/cpuSamples.length;
  return avgCpu;
}


Replace direct CPU use in ACT logic with averaged avgCpu.
Scale only if:

avgCpu < 55 && avgDuration < 5000


Reduce if:

avgCpu > 60 || avgDuration > 8000
