💡 Data Source (Amended per Gemini Recommendation)

Instead of accessing Kalman-smoothed price feeds directly,
the CovarianceEngine will fetch raw OHLC close prices from the MarketDataService or FX5Scanner cache.

This ensures:

Simplicity and independence from the Orchestrator layer

Robust data flow and no circular dependencies

Minimal deviation in correlation accuracy (<2%)

Implementation:

// server/services/risk-concentration.ts
const closes = await marketDataService.getRecentCloses(symbol, 50);
const returns = calculateReturns(closes);
covarianceEngine.addReturns(symbol, returns);


Rationale: Pearson correlations are robust to micro-noise;
using raw OHLC prices yields equivalent results without complexity.

⚙️ Example Implementation (Condensed)
server/utils/covariance-engine.ts
export function calculateReturns(prices: number[]): number[] {
  const returns: number[] = [];
  for (let i = 1; i < prices.length; i++) {
    const r = (prices[i] - prices[i - 1]) / prices[i - 1];
    if (isFinite(r)) returns.push(r);
  }
  return returns;
}

export function computeCovarianceMatrix(returns: Record<string, number[]>): Record<string, Record<string, number>> {
  const symbols = Object.keys(returns);
  const mean: Record<string, number> = {};
  symbols.forEach(s => mean[s] = returns[s].reduce((a,b) => a+b, 0) / returns[s].length);

  const cov: Record<string, Record<string, number>> = {};
  symbols.forEach(i => {
    cov[i] = {};
    symbols.forEach(j => {
      const n = Math.min(returns[i].length, returns[j].length);
      const cov_ij = returns[i].slice(-n).reduce((a, _, k) =>
        a + (returns[i][k] - mean[i]) * (returns[j][k] - mean[j]), 0) / (n - 1);
      cov[i][j] = cov_ij;
    });
  });
  return cov;
}

export function computeCorrelationMatrix(cov: Record<string, Record<string, number>>): Record<string, Record<string, number>> {
  const symbols = Object.keys(cov);
  const corr: Record<string, Record<string, number>> = {};
  symbols.forEach(i => {
    corr[i] = {};
    const sigma_i = Math.sqrt(cov[i][i]);
    symbols.forEach(j => {
      const sigma_j = Math.sqrt(cov[j][j]);
      corr[i][j] = cov[i][j] / (sigma_i * sigma_j);
    });
  });
  return corr;
}

🔧 Implementation Steps
1️⃣ Data Source

Pull last 30–50 OHLC closes per symbol from MarketDataService.
Convert to returns and store rolling history (max 100).

2️⃣ CovarianceEngine

Compute Σ and ρ matrices every 60 seconds (or N ticks).

Cache result in Redis with timestamped hash key (cov:matrix:<timestamp>).

3️⃣ RiskConcentrationAnalyzer

File: server/services/risk-concentration.ts

const corr = covarianceEngine.computeCorrelationMatrix(cov);
for (const symbol of symbols) {
  const C_i = Object.keys(corr[symbol])
    .reduce((acc, j) => acc + Math.abs(corr[symbol][j]) * weights[j], 0);
  if (C_i > 2.5) console.warn(`[9.4][RISK] ${symbol} overexposed: ${C_i.toFixed(2)}`);
  scalingFactors[symbol] = Math.min(1, 2.5 / C_i);
}
