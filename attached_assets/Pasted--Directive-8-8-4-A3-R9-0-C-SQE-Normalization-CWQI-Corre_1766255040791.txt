2️⃣ CWQI Calculation Correction
File: server/core/helpers/cwqi_calculator.ts (or wherever defined)
Change Set: R9C-2
Remove post-blend normalization.

Maintain weights summing to 1.0.

ts
Copy code
// OLD
const blended = normalize(ngc * 0.6 + (1 - risk) * 0.3 + profit * 0.1);

// NEW
const blended = (ngc * 0.6) + ((1 - risk) * 0.3) + (profit * 0.1);
return clamp(blended, 0, 1);
