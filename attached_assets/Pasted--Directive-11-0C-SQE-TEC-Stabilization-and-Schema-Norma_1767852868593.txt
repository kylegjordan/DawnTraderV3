Add regression tests ensuring dynamic configuration propagation.

⚙️ Task 2 — Normalize Adaptive Sizing Configuration (TEC)
Files:
server/services/execution-controller.ts
server/config/execution-config.ts (new)
server/db/migrations/2026-11-0C-schema-cleanup.sql

Actions:
1️⃣ Create new config file /server/config/execution-config.ts
export const EXECUTION_CONFIG = Object.freeze({
  ADAPTIVE_EXPAND_FACTOR: 1.10,
  ADAPTIVE_CONTRACT_FACTOR: 0.90,
  TRAILING_STOP_BASE: 0.015,       // 1.5 % base trailing distance
  TRAILING_STOP_ACCELERATION: 0.002, // increment per positive candle
  MAX_POSITION_RISK: 0.02,         // 2 % of equity cap
  VERSION: "v1.0.0"
});

2️⃣ Update TEC adaptive sizing

In /server/services/execution-controller.ts, replace:

if (trade.trendline.reinforced) trade.positionSize *= 1.1;
if (trade.trendline.weakened) trade.positionSize *= 0.9;


with:

import { EXECUTION_CONFIG } from "../config/execution-config";

if (trade.trendline.reinforced)
  trade.positionSize *= EXECUTION_CONFIG.ADAPTIVE_EXPAND_FACTOR;
if (trade.trendline.weakened)
  trade.positionSize *= EXECUTION_CONFIG.ADAPTIVE_CONTRACT_FACTOR;

3️⃣ Update trailing exit logic

Replace hard-coded trailing constants:

const trailingStop = price * 0.015;


with:

const trailingStop = price * EXECUTION_CONFIG.TRAILING_STOP_BASE;

4️⃣ Add migration file /server/db/migrations/2026-11-0C-schema-cleanup.sql
-- Migration for execution configuration and cleanup
ALTER TABLE screener_filters
  ADD COLUMN IF NOT EXISTS final_score_min REAL DEFAULT 0.35,
  ADD COLUMN IF NOT EXISTS regime_weight_min REAL DEFAULT 0.30;

CREATE TABLE IF NOT EXISTS execution_settings (
  id SERIAL PRIMARY KEY,
  adaptive_expand_factor REAL DEFAULT 1.10,
  adaptive_contract_factor REAL DEFAULT 0.90,
  trailing_stop_base REAL DEFAULT 0.015,
  trailing_stop_acceleration REAL DEFAULT 0.002,
  max_position_risk REAL DEFAULT 0.02,
  version TEXT DEFAULT 'v1.0.0'
);


✅ TEC now reads configuration from a single source of truth.
