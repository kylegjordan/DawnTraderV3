⚙️ Directive 11.0B — Trade Control Integrity & FinalScore Unification
Phase: 11.0B

Title: FinalScore Promotion Logic, SQE Purification, Adaptive Sizing Integration

🎯 Objective

To finalize the restoration of the Trade Control Layer by:

Replacing legacy CWQI/NGC-based ranking with FinalScore-based promotion logic in the TCL.

Purifying the SQE so it filters only by FinalScore and RegimeWeight.

Migrating Adaptive Sizing (trendline-based) logic into the TEC.

Verifying exposure, correlation, and cooldown checks exist only within the Signal Orchestrator/SQE and nowhere else.

Reinforcing the Implementation Discipline policy to prevent unapproved architectural additions.

🧱 Task 1 — Purify TCL: FinalScore Ranking Only
Files:

server/core/criteria-limiter.ts

server/services/ready-to-buy-refresh.ts

Actions:

Remove all references to legacy ranking fields:

cwqi, ngc, profitRate, riskCalc.

Replace ranking function with:

const rankedSignals = rtbQueue.sort((a, b) => b.finalScore - a.finalScore);


In promoteTopSignals(), use:

const openSlots = this.getOpenSlots();
const topSignals = rankedSignals.slice(0, openSlots);
for (const signal of topSignals) {
    this.promoteToTrade(signal);
}


Verify triggers remain unchanged:

onFailsafeTimer()

onReadyToBuyQueueFull()

Confirm promotion event logging:

log.info(`[TCL] Promoted ${topSignals.length} signals using FinalScore ranking`);


✅ Expected Outcome:
TCL promotes signals exclusively by finalScore, ranked descending, when triggered by failsafe or RTB queue fullness.

⚙️ Task 3 — Migrate Adaptive Sizing into TEC
Files:

server/services/execution-controller.ts

server/core/sizing-helper.ts

server/services/trade-engine.ts

Context:

Adaptive sizing logic was originally implemented pre-TEC (Phase 9–10) inside trade-engine.ts and sizing-helper.ts.
It must now reside under TEC, which owns all post-entry trade behavior.

Actions:

Move adaptive sizing logic into execution-controller.ts:

updateAdaptiveSize(trade) {
    const trend = trade.trendline;
    if (!trend) return;

    if (trend.reinforced) trade.positionSize *= 1.1;  // Expand by 10%
    if (trend.weakened) trade.positionSize *= 0.9;   // Contract by 10%
}


Call this inside monitor(trade):

monitor(trade) {
    this.updateTrailingStop(trade);
    this.updateAdaptiveSize(trade);
    if (this.shouldExit(trade)) this.closeTrade(trade);
}


Remove adaptive sizing calls from:

/server/services/trade-engine.ts

/server/core/sizing-helper.ts (if they reference runtime trade adjustments)

✅ Expected Outcome:
TEC owns dynamic, runtime adaptive sizing — aligned with trailing exits and trendline feedback.
