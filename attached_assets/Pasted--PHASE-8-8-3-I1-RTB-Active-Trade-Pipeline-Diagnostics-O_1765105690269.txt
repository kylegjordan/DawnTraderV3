2. Restore and Expand RTB Block-Reason Visibility

Problem:
The Ready-to-Buy tab used to show a breakdown of why attempts were blocked (max positions, max trades, LPCP, etc.). Now we only see high-level counts (Attempts, Opened, Blocked) with no per-reason breakdown.

We suspect:

Either the UI isn’t getting the per-reason data anymore, or

A new / unexpected block reason is being used and not reported.

Task 2.1 – Identify Current Block Reasons

In whatever code builds RTB entries and evaluates guardrails (likely in or around signal-orchestrator.ts, risk-manager.ts, guardrail-policy.ts):

Identify every place where an attempt can be blocked before becoming an open trade.

Enumerate all block reasons, e.g.:

MAX_POSITION

MAX_TRADES

POSITION_LIMIT

LPCP_LOW_PRICE

LPCP_ATR_TOO_LOW

COOLDOWN

TOO_VOLATILE

UNKNOWN (if exists)

Any new reason you find

Write the list into:

docs/diagnostics/Phase-8.8.3-I1_Trading_Pipeline_Diagnostics.md under a section:

“RTB Block Reasons (Current Code)”

Task 2.2 – Add Unified RTB Block Diagnostics Service

Create a new service:

server/services/rtb-diagnostics-service.ts

Responsibilities:

Maintain in-memory counters (resettable) of RTB attempts and block reasons, keyed by:

symbol

strategyName

blockReason (string)

Provide methods (usable ONLY by the existing pipeline, no new behavior):

recordAttempt(symbol, strategyName);
recordOpen(symbol, strategyName);
recordBlock(symbol, strategyName, blockReason);
getSummary(); // aggregated stats
clear();      // reset counters


Add no new guardrail decisions here; just record what the existing code already decided.

Wire this into the existing RTB / guardrail pipeline:

At the point where a signal is evaluated for RTB:

Call recordAttempt.

If it passes and becomes an open trade:

Call recordOpen.

If any guardrail or rule blocks it:

Call recordBlock(symbol, strategyName, <existing blockReason>).

All calls must log JSON to the main log with prefix:

[8.8.3-I1][RTB_ATTEMPT] ...

[8.8.3-I1][RTB_BLOCK] ...

[8.8.3-I1][RTB_OPEN] ...

with fields:

{
  "symbol": "ADAUSD",
  "strategy": "mean_reversion",
  "blockReason": "MAX_POSITION",  // only for RTB_BLOCK
  "ts": "2025-12-07T10:00:51.123Z"
}
