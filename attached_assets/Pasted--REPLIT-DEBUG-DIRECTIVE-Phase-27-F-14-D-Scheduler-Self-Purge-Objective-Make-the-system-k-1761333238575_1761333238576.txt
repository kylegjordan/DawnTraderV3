2) Add REAL-TIME SELF-PURGING (reactive layer)
2A) On INSERT (MarketScanner / StrategyEngine → saveTradingSignal)

Required behavior

If expires_at <= NOW() → skip insert, log:
[SignalManager] Skipped insert — expired (SYMBOL, strategy)

Enforce de-dup before insert on (mode, symbol, strategy):

Delete any existing rows with same (mode, symbol, strategy) before insert.

Log: [SignalManager] Replaced N duplicate(s) for SYMBOL/strategy in mode=paper

Defensive DB constraint (migration)

Add unique index to guarantee no dupes even if code path misses:

CREATE UNIQUE INDEX IF NOT EXISTS ux_trading_signals_mode_symbol_strategy
ON trading_signals (mode, symbol, strategy);


(If there’s a composite PK already, adapt accordingly; if multi-status is required, include status too.)

2B) On FETCH (API for Filtered/Ready/Active signals)

All data select queries must filter and purge on the fly:

Selection: WHERE expires_at > NOW()

Side-effect purge (same request, best-effort):
DELETE FROM trading_signals WHERE expires_at <= NOW();

Log once per request (rate-limit logs to 1/10s):
[RealtimeCleanup] Purged K expired on fetch (endpoint=ready_to_buy)

2C) On INVALIDATION (guardrail/safety turn a signal “bad”)

Immediately remove it:

DELETE FROM trading_signals WHERE id = $1

Log: [RealtimeCleanup] Removed invalidated signal (SYMBOL, reason=GuardrailFailed)

2D) Query performance (optional but recommended)

Indexes:

CREATE INDEX IF NOT EXISTS ix_trading_signals_expires_at
ON trading_signals (expires_at);

CREATE INDEX IF NOT EXISTS ix_trading_signals_mode_status
ON trading_signals (mode, status);

3) Fix the TradingStateSync enum error

Symptom:
error: invalid input value for enum trading_mode: "3ace5ebb-..."

Root cause: trading-state-sync.ts passes userId to getSystemContext() after the global-mode refactor; the function expects mode.

Fix

In server/services/trading-state-sync.ts:

Replace the call to getSystemContext(userId) with getSystemContext(mode) where mode ∈ { paper, live } (from global context).

If the service used to loop users, collapse to one global record per mode.

Add log:

[TradingStateSync] Initialized (mode=paper) 


Ensure no DB writes attempt to store userId in trading_mode enum fields.
