🧩 Directive 8.8.4-C.14.A — RTB Table Columns & Cadence Functionality Audit (Non-Interruptive)
🎯 Objective

Verify that:

The Ready-to-Buy (RTB) table updates made under Directive 8.8.4-C.13.C were correctly applied in both backend and frontend layers (schema + render).

The decoupled RTB refresh cadence is functioning as intended—i.e., signals are cycling, expiring, and re-ranking dynamically during the trading session.

The investigation must be performed without stopping or resetting the ongoing C.14 validation trading session.

🔍 Context

Under Directive 8.8.4-C.13.C, Replit implemented:

RTB Table Schema Update:

Added columns → Rank, CWQI, NGC, Price, Entry, Target, Stop, Qty, 24h Volume, Strategy

Removed columns → Name, VWAP, Range % (unless explicitly in use)

Decoupled RTB Cadence:

Moved RTB refresh logic out of the TCL event dependency

Introduced an independent 30-second refresh cycle for dynamic queue updates

Allowed continuous queue cycling and re-ranking based on CWQI values

Current observation:

The table still displays the deprecated columns (Name, VWAP, Range %)

New columns (Rank, CWQI, NGC) are not visible

RTB queue populated once at startup (6 signals) and remains static
