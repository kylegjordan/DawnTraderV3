The modernization replaces the outdated CWQI/NGC/DI/GSI scoring pipeline with Phase-10 canonical metrics and integrates market regime calculation, signal type mapping, and real strategy execution (Hybrid, Pattern, Quantitative).

It ensures that the VTS:

Maintains full isolation from live trading components

Task 2 — Add Pair-Level Regime Calculator

File: /server/core/metrics/market-regime.ts

export function calculatePairRegime(ohlc) {
  const vol = computeVolatility(ohlc);
  const mom = computeMomentum(ohlc);
  const adx = computeADX(ohlc);

  if (vol < 0.015 && Math.abs(mom) < 0.002) return 'LOW_VOL_CHOP';
  if (mom > 0.002 && adx > 25)              return 'BULL_STABLE';
  if (mom < -0.002 && adx > 25)             return 'BEAR_VOLATILE';
  if (vol > 0.025)                          return 'HIGH_VOL_IMPULSE';
  return 'TRANSITION';
}

Task 4 — Refactor VTS Runner

File: /server/services/vts-runner.ts
New Responsibilities:

Fetch top 100 pairs from the Ideal Pool

Calculate per-pair regime

Select signalType + strategy via regimeStrategyMap

Dynamically import and execute the strategy

Calculate Phase-10 finalScore

Send resulting VirtualSignal to vtsService.createVirtualTrade()

Implementation:

async function runSimulationCycle() {
  const pairs = await idealPoolService.getTopPairs(100);
  if (pairs.length < 10) {
    console.warn('[VTS] Ideal pool too small, delaying cycle...');
    await sleep(30000);
    return;
  }

  for (const pair of pairs) {
    const ohlc = await marketDataService.getRecentOHLC(pair.symbol);
    const regime = calculatePairRegime(ohlc);
    const { signalType, strategies } = regimeStrategyMap[regime];
    const strategy = randomChoice(strategies);

    try {
      const modulePath = `../strategies/${signalType}/${strategy}.ts`;
      const { executeStrategy } = await import(modulePath);
      const metrics = await executeStrategy(pair.symbol, '15m', { virtual: true });

      const finalScore =
        metrics.hybridScore * 0.4 +
        metrics.predictiveConfidence * 0.3 +
        metrics.regimeWeight * 0.2 -
        metrics.decayPenalty * 0.1;

      const signal = { symbol: pair.symbol, regime, signalType, strategy, ...metrics, finalScore, timestamp: Date.now() };
      await vtsService.createVirtualTrade(signal);
    } catch (err) {
      console.warn(`[VTS] Strategy load failed (${signalType}/${strategy}): ${err.message}`);
      continue; // skip pair, don't crash the loop
    }
  }
}
