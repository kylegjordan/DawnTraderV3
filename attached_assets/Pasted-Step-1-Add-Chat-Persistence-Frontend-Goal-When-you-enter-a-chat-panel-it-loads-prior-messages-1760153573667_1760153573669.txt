Step 1 — Add Chat Persistence (Frontend)

Goal:
When you enter a chat panel, it loads prior messages from the database.
When you send a message, it saves immediately.

Actions:

1. Locate the chat component (GoalsChat.tsx, GPTChat.tsx, or similar).


2. On mount (useEffect), call:

GET /api/chats?context=goals

or the appropriate route.


3. Populate chat UI from response (setMessages(res.data)).


4. On every send (after message + response):

POST /api/chats/save

with { user_id, role, message, context, timestamp }.



Check:
✅ Refresh or navigate away/return — chat history still there.
✅ Reload browser — messages reload instantly.

Step 2 — Backend Routes for Chat History

Goal:
Provide REST endpoints to store and retrieve chat logs.

Actions:

1. In server/routes.ts add:

router.get('/api/chats', verifyJWT, getChats);
router.post('/api/chats/save', verifyJWT, saveChat);


2. In server/services/chatService.ts add SQL:

CREATE TABLE IF NOT EXISTS chats (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT,
  context TEXT,
  role TEXT,
  message TEXT,
  timestamp INTEGER
);

Functions:

saveChat → INSERT row.

getChats → SELECT * WHERE user_id = ? AND context = ? ORDER BY timestamp ASC.




Check:
✅ Database table chats created.
✅ Sending a message inserts a row.
✅ GET returns correct list.
