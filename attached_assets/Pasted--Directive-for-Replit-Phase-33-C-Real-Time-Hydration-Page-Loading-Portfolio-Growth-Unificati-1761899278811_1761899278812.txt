0️⃣ Base Fetcher & Query Configuration

Goal: remove custom fetch calls that bypass authentication and cause 401 → infinite loading.

client/src/lib/api.ts

export async function apiFetch(input: string, init?: RequestInit) {
  const controller = new AbortController();
  const timeout = setTimeout(() => controller.abort(), 10000);
  try {
    const res = await fetch(input, {
      credentials: 'include',
      signal: controller.signal,
      ...init,
    });
    if (!res.ok) {
      const text = await res.text().catch(() => '');
      throw new Error(`HTTP ${res.status}: ${text}`);
    }
    return res.json();
  } finally {
    clearTimeout(timeout);
  }
}


client/src/main.tsx (or React Query Provider)

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      queryFn: ({ queryKey }) => apiFetch(queryKey[0] as string),
      refetchOnWindowFocus: false,
      staleTime: 15000,
      retry: 1,
    },
  },
});


✅ Effect: All API calls automatically include authentication, timeout properly, and fail visibly instead of hanging forever.

4️⃣ Fix “Loading…” Pages (Trading, Goals Engine, System Monitoring)

Root cause: Background tasks (watchlist populate, goals refresh, metrics refresh) finish but never trigger revalidation.

Backend (server/services/paper-sim-service.ts)

Broadcast job completion:

await contextBridge.broadcast({
  type: 'background_jobs_complete',
  payload: {
    jobs: ['watchlist_populate', 'goals_refresh', 'metrics_refresh'],
    ts: new Date().toISOString(),
  },
});

Frontend (client/src/hooks/use-trading.tsx)

Handle these events:

if (msg.type === 'background_jobs_complete') {
  const jobs = msg.payload.jobs || [];
  const invalidate = (key) => queryClient.invalidateQueries([key]);
  if (jobs.includes('watchlist_populate')) invalidate('/api/trading/filtered-pairs');
  if (jobs.includes('goals_refresh')) {
    invalidate('/api/goals/config');
    invalidate('/api/goals/guardrails');
  }
  if (jobs.includes('metrics_refresh')) invalidate('/api/paper/metrics/history');
}


✅ Effect: Once background jobs finish, the relevant tabs re-render automatically and no longer hang.
