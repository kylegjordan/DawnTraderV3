📜 Directive 11.8B-C — Goals ML & Preset System Decommission

Phase: 11.8B-C
Status: Mandatory cleanup before predictive baseline authority
Nature: Destructive (explicit removals) + UI surface hardening
Execution Authority: Replit (code changes only)
Approval Authority: Kyle

1️⃣ PURPOSE (NON-NEGOTIABLE)

This directive permanently decommissions all remaining Goals ML, Preset, and Adaptive Risk / Auto-Tuning systems that:

Operate as parallel learning loops

Mutate parameters outside Phase 11 Predictive Learning

Introduce rollback, snapshot, or preset authority

Conflict with the Phase 11 single-authority model

After this directive:

There must be exactly ONE learning system capable of adjustment:
Phase 11 Predictive Learning.

No legacy “smart” systems may remain dormant, hidden, or partially wired.
