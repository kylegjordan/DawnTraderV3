Dawn Trader is an advanced autonomous trading application designed to trade at better-than-expert human levels. Its purpose is to intelligently grow portfolio value as fast and as much as possible within defined risk boundaries.
The system includes a deterministic trading engine, risk management guardrails, adaptive intelligence (LATTI), and coordination layers (Orchestrators). LATTI’s role is to provide continual learning and a programmed motivation to make real-time adjustments — observing the market, adjusting behaviors – to drive as much portfolio value growth as possible as fast as possible within the set risk parameters.
Our goal is not to strip down or remove functionality, but to get the system working as it was intended — efficiently, reliably, and sustainably. If we have to remove components, this can be accepted, but we would like to preserve as much of the intended functionality, features and operating capabilities and stability that allows us to achieve the intended objectives/results as possible. Over time, the system accumulated layers of legacy code, hard-coded values, and multi-user artifacts from previous rebuilds (v2), which compromised stability. We’ve rolled back to a single-tenant architecture and are refactoring to restore a solid, modular foundation.
Your task is to review the current state and produce the best possible technical plan to make the system stable and high-performing using the components already built, as well as the existing UI design. You may recommend changes to the connections, design, or structure to improve efficiency — but the focus is on making it reliably and stably operational and optimizing that, not replacing or introducing new technologies.
If additional code snippets, configuration files, or implementation details are needed, ask for them — we’ll provide whatever you need to make your analysis accurate and actionable.
