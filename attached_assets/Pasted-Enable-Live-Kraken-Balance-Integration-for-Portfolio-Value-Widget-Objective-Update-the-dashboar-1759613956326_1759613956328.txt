Enable Live Kraken Balance Integration for Portfolio Value Widget”
🎯 Objective

Update the dashboard so that the Portfolio Value displayed at the top of the screen reflects the actual live balance from the connected Kraken account, rather than the internal simulation that assumes a $50,000 base plus profit/loss.

The feature must work seamlessly with the existing Earnings Summary, Earnings Chart, and Cash vs Crypto widgets — without breaking or slowing the dashboard.

⚙️ Implementation Goals

1️⃣ Use Live Kraken Balance as the Source

Use the existing KrakenService.getAccountBalance() method to query the user’s live Kraken account.

The system should retrieve balances for all held assets (BTC, ETH, USDT, etc.).

Include both spot balances and cash (USD/USDT/USDC) in the calculation.

2️⃣ Convert All Balances to USD

For each asset returned from Kraken:

If it’s already denominated in USD, keep it as is.

If it’s crypto (e.g., BTC, ETH), convert it to its USD equivalent using the latest market price.

Use the same live price feed currently used by the Portfolio Chart (Kraken or CoinGecko).

Sum all values to produce one total portfolio value in USD.

3️⃣ Display This Total as the Portfolio Value

Replace the existing “base value + realized/unrealized P/L” calculation with the true Kraken balance total.

Keep the same widget layout and formatting (large bold USD number).

The Portfolio Value widget should always reflect the most recent synced total from Kraken.

4️⃣ Schedule Regular Auto-Updates

Refresh the Kraken balance data every 30–60 seconds, or whenever the dashboard is manually refreshed.

Do not flood the API; one update per minute is sufficient.

If possible, also refresh immediately after a new trade executes.

5️⃣ Add a Sync Status Label

Underneath the Portfolio Value number, add a small line of text:

“Synced from Kraken • Last updated [hh:mm:ss UTC]”

This shows when the last successful balance sync occurred.

The time should always display in UTC (not browser local time).

6️⃣ Add Fallback and Error Handling

If the Kraken API request fails, show a subtle message or tooltip:

“Using internal estimate (live sync unavailable).”

In this case, temporarily fall back to the internal simulated total so the dashboard never goes blank.

The label should change to something like:

“Sync failed • Showing internal estimate”

The app should automatically retry on the next scheduled refresh (no need for user action).
