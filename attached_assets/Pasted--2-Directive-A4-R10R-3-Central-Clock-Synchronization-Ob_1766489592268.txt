⚙️ 2️⃣ Directive A4.R10R-3 – Central Clock Synchronization
Objective

Transition the Ready-To-Buy Refresh Service from its internal setInterval() loop to synchronization with the Central Clock tick mechanism.
This ensures deterministic refresh scheduling, eliminates drift and overlap, and enables precise measurement of cycle duration and coverage.

🔧 Implementation Plan
1️⃣ File Changes

Files impacted:

server/services/rtb-refresh-service.ts
server/core/clock/central-clock.ts
server/index.ts
replit.md

2️⃣ Remove Internal Timer

In rtb-refresh-service.ts:

Remove setInterval() or equivalent scheduling logic.

Add a start() method that subscribes to the Central Clock:

centralClock.on('tick', (tickNumber) => {
  rtbRefreshService.onTick(tickNumber);
});

3️⃣ Implement Tick-Driven Logic

Replace the 15-second interval logic with this:

private readonly MICRO_CYCLE_INTERVAL = 15; // seconds
private readonly MACRO_CYCLE_INTERVAL = 120; // seconds
private readonly TOTAL_BUCKETS = this.MACRO_CYCLE_INTERVAL / this.MICRO_CYCLE_INTERVAL; // 8 buckets

onTick(tickNumber: number) {
  if (tickNumber % this.MICRO_CYCLE_INTERVAL !== 0) return;
  const bucketIndex = (tickNumber / this.MICRO_CYCLE_INTERVAL) % this.TOTAL_BUCKETS;
  this.refreshBucket(bucketIndex);
}


That means:

every 15 s, one “bucket” refreshes;

full coverage (8 buckets) = 120 s total.

4️⃣ Add Load Instrumentation

Inside refreshBucket(bucketIndex):

const start = Date.now();
const bucket = this.getBucket(bucketIndex);
this.log(`[A4.R10R-3][RTBRefresh][CYCLE_START] bucket=${bucketIndex} size=${bucket.length}`);
await this.refreshSignals(bucket);
const duration = Date.now() - start;
this.log(`[A4.R10R-3][RTBRefresh][CYCLE_COMPLETE] bucket=${bucketIndex} size=${bucket.length} duration=${duration}ms`);


This will tell us exactly how long each refresh takes and how many signals were processed.

5️⃣ Update Startup Order

In server/index.ts, ensure:

await priceCache.initialize();
await centralClock.start();
await rtbRefreshService.start();
await fx5Scanner.bootstrap();
await tclWatchdog.bootstrap();


This guarantees RTB refresh has the clock available when it subscribes.
