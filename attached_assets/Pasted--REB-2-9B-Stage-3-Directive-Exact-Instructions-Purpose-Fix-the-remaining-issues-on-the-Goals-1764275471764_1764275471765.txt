✅ SECTION 1 — ALWAYS FORMAT NUMERIC FIELDS ON BLUR (Manual + LATTI)
🎯 Goal:

Whenever a numeric field loses focus (blur), the UI must format the displayed number with commas (e.g. 50000000 → 50,000,000), regardless of whether:

LATTI manages the field

Manual override manages the field

Formatting is visual-only. The backend must continue to store bare numeric values.

🔧 Implementation Steps (filters-with-override.tsx)
1. Add number formatting helpers

Add these two functions at the top of the file:

const formatNumber = (value: number | string) => {
  if (value === null || value === undefined || value === "") return "";
  const num = typeof value === "number" ? value : parseFloat(value.toString().replace(/,/g, ""));
  if (isNaN(num)) return "";
  return num.toLocaleString("en-US");
};

const unformatNumber = (value: string) => {
  if (!value) return "";
  return value.replace(/,/g, "");
};

2. When an input field is focused → remove commas

Inside the numeric input component:

onFocus={(e) => {
  const raw = unformatNumber(e.target.value);
  e.target.value = raw;
}}

3. When input field blurs →

format the number

save the value

show toast

update local UI

onBlur={(e) => {
  const rawValue = unformatNumber(e.target.value);
  const numericValue = Number(rawValue);

  if (!isNaN(numericValue)) {
    updateValueMutation.mutate(
      { filterName: filter.name, value: numericValue },
      {
        onSuccess: () => {
          toast.success("Value updated successfully");
          e.target.value = formatNumber(numericValue);
        }
      }
    );
  }
}}

❗ REQUIRED

Ensure formatting also applies to values coming from React Query cached data.
