🛠 Phase 32.D-Fix.2 — Passive Flag Isolation & UI Sync
1️⃣ Lock Passive Flag During Active Paper Mode

File: server/services/system-config.ts

Right after your existing if (newFlags.activeMode !== "paper") … block, add:

// Prevent passive mode override while paper trading is active
if (systemFlags.activeMode === "paper" && systemFlags.passiveMode) {
  console.log("[32.D-Fix.2] Passive flag detected during paper mode — overriding to false");
  systemFlags.passiveMode = false;
  await broadcastSystemFlags(systemFlags);
}


This ensures that if paper mode is on, the passive flag is force-off, so the UI won’t stay frozen.

2️⃣ Confirm Frontend Derivation

File: client/src/components/layout/top-bar.tsx
or whichever renders the blue bar.

Locate something like:

const isActive = systemFlags?.isEngineActivePaper;
const isPassive = systemFlags?.passiveMode;


Make sure the render condition prioritizes active trading:

const tradingStatus = isActive && !isPassive ? "active" : "stopped";


and not the inverse (some builds use if (isPassive || !isActive)).
If needed, flip the logic to ensure passive cannot override active in paper mode.
