🎯 Objective

Directive 11.0F completes the modernization and purification of the DawnTrader math and trade architecture.
It finalizes the removal of all legacy math data and transitional code, consolidates schema and telemetry fields, and establishes a clean, stable foundation for the next stage: Phase 11.1 – Persistent Intelligence.

This directive formally closes the 11.0 series by:

Dropping deprecated database columns (cwqi, ngc, profitRate).

Cleaning up residual telemetry and diagnostic transitional flags.

Freezing the FinalScore model as Metric Engine v1.0 (Canonical).

Archiving all legacy metric data for future audit reference.

Verifying a stable schema and telemetry alignment under v1.5.0.

⚙️ Scope of Work

This directive applies to:

Database schemas

Telemetry aggregation and diagnostics

Legacy archival handling

Documentation (technical + schema reference)

Regression and validation testing
