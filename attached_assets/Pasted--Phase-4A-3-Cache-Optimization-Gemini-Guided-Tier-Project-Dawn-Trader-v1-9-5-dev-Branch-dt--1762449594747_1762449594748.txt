1️⃣ Extend Cache TTL and Instrumentation

File: server/services/cache.ts

Increase default TTL → 90 s.

Add logging + counters for hit/miss metrics.

const cache = new Map();
let hits = 0, misses = 0;

export function getCache(key: string) {
  const e = cache.get(key);
  if (!e || e.exp < Date.now()) { 
    cache.delete(key); misses++; 
    console.log(`[Gemini-Cache] miss ${key}`); 
    return null; 
  }
  hits++;
  console.log(`[Gemini-Cache] hit ${key}`);
  return e.v;
}

export function setCache(key: string, v: any, ttl = 90000) {
  cache.set(key, { v, exp: Date.now() + ttl });
}

export function cacheStats() {
  const ratio = hits + misses === 0 ? 0 : hits / (hits + misses);
  return { hits, misses, ratio };
}


✅ Expected: visible [Gemini-Cache] hit|miss logs and ratios in profiling.

3️⃣ Implement Request Coalescing

Prevent duplicate in-flight fetches for same key.

const pending: Record<string, Promise<any>> = {};

export async function coalesce(key: string, fn: () => Promise<any>) {
  if (pending[key]) return pending[key];
  pending[key] = fn().finally(() => delete pending[key]);
  return pending[key];
}


Use inside route:

const data = await coalesce(key, () => portfolioService.getOverview(mode));


✅ Expected: zero overlapping DB queries under load.
