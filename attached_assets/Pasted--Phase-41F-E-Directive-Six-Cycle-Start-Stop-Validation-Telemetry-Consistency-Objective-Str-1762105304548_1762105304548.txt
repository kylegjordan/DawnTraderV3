🎯 Objective

Stress-test both Paper and Live trading engines through repeated start/stop operations while validating:

Engine state synchronization

Queue integrity and lock release

Telemetry broadcast consistency

UI responsiveness and metric updates

🧩 Cycle Plan
Mode	Cycle	Steps
Paper	1–3	Start → Stop → Start → Stop → Start → Stop
Live	4–6	Start → Stop → Start → Stop → Start → Stop

Each start begins a new session; each stop ensures graceful shutdown and queue drain.

🧠 Validation Focus

During all six cycles, confirm via logs + UI:

System Status Tile updates to ✅ Active / 🛑 Stopped correctly.

Broadcast Latency remains < 100 ms.

Queue Health (Paper & Live) always returns depth ≤ 3 and executing ≤ 1.

Engine Health shows accurate isRunning state.

Market Data / Database / WebSocket reconnects automatically if disrupted.

No busy-flag lock persists between cycles.
