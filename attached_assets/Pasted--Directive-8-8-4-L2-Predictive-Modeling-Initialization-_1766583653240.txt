⚙️ Directive 8.8.4-L2 – Predictive Modeling Initialization
📘 Purpose

Establish the first generation of DawnTrader’s predictive learning engine, using aggregated passive + active data to model:

Expected Profit Rate (continuous) → LightGBM Regressor

Trade Promotion Probability (binary) → Logistic Classifier

These models will feed inference back into the Signal Quality Evaluator (SQE), Ready-to-Buy (RTB), and Signal Orchestrator for confidence and profit-based weighting.

🧩 1️⃣ New Modules to Create
File	Description
server/services/model-trainer.ts	Builds, trains, and saves models from the aggregated dataset.
server/services/model-predictor.ts	Loads models and performs inference in real time.
server/services/feature-engineer.ts	Extracts and normalizes input features from captured data.
models/ directory	Stores serialized models (profit_predictor.json, promotion_classifier.json).
server/services/model-versioning.json	Tracks current model versions and training timestamps.
🧮 2️⃣ Training Data Source

Use aggregated hourly JSON files produced by data-aggregator.ts:

🧠 3️⃣ Feature Engineering (feature-engineer.ts)

Implement an exported function:

export function extractFeatures(sample) {
  return {
    ngc: sample.ngc,
    cwqi: sample.cwqi,
    riskRatio: sample.riskRatio,
    profitTarget: sample.profitTarget,
    signalAge: sample.signalAge,
    priceRange: (sample.exit - sample.entry) / sample.entry,
    stopDepth: (sample.entry - sample.stop) / sample.entry,
    strategyCode: hashStrategy(sample.strategy),
  };
}


Normalize all numeric inputs to 0-1 scale; categorical strategyCode as integer hash.

🔬 4️⃣ Model Training (model-trainer.ts)

Import LightGBM (JS binding via lightgbm or xgboost-js).

Import Logistic Regression from scikitjs or similar library.

Load aggregated data via fs glob.

Split dataset 80/20 (train/test).

Train two models:

// Regressor – expected profit
trainLightGBM(X, y_profitRate);

// Classifier – promotion probability
trainLogistic(X, y_tradeExecuted);


Evaluate R² and F1 scores; log metrics.

Save models under /models/ and record metadata in model-versioning.json.

⚡ 5️⃣ Live Inference (model-predictor.ts)

Expose async methods:

export async function predictProfit(features) { ... }
export async function predictPromotion(features) { ... }


Cache loaded models in memory for fast use (<10 ms).

🔗 6️⃣ Integration Points
Module	Integration	Action
signal-quality-evaluator.ts	Post-NGC calculation	Adjust final NGC → blend(ngc, predictedPromotion, 0.6)
ready_to_buy_service.ts	During refresh and rank	Use predictedProfit as secondary ranking weight
signal-orchestrator.ts	During price generation	Use predictedProfit to refine profit target and stop ratios

All inference calls must be non-blocking (await … .catch(()=>{})).

🧰 7️⃣ Scheduled Retraining Task

Add a daily cron job (03:00 UTC):

import { trainModels } from './model-trainer';
schedule('0 3 * * *', trainModels);


Rotates model versions automatically and keeps past ones for rollback.
