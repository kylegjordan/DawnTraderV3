Task 2 — Database Integrity Audit

Target Tables: telemetry, virtual_trades, session_metrics

Execute the following SQL queries:

-- 1️⃣ Hybrid signals missing patterns
SELECT COUNT(*) AS invalid_hybrids
FROM telemetry
WHERE signal_type = 'HYBRID' AND pattern IS NULL;

-- 2️⃣ Deprecated strategy names still present
SELECT COUNT(*) AS legacy_adaptive
FROM telemetry
WHERE strategy = 'AdaptiveFlow';

-- 3️⃣ Ghost regimes that should have been normalized
SELECT COUNT(*) AS ghost_regimes
FROM telemetry
WHERE regime IN ('BULL_VOLATILE', 'EXTREME_NOISE');

-- 4️⃣ ⚠ NEW Casing mismatch check (added per Gemini recommendation)
SELECT COUNT(*) AS casing_errors
FROM telemetry
WHERE signal_type NOT IN ('QUANT', 'PATTERN', 'HYBRID');


Expected Results:

Check	Expected	Meaning
invalid_hybrids	0	All HYBRID signals have patterns
legacy_adaptive	0	No deprecated AdaptiveFlow entries
ghost_regimes	0	Only canonical 5 regimes in use
casing_errors	0	All SignalType values are uppercase

If any count > 0, export offending records to
/audit/reports/final_system_integrity_failed.csv for inspection.
