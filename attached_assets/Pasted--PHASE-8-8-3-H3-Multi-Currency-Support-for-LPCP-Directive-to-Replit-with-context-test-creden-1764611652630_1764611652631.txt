✅ PHASE 8.8.3-H3 — Multi-Currency Support for LPCP
(Directive to Replit — with context & test credentials)

Summary:
Enable Low-Priced Coin Protection (LPCP) to operate correctly on pairs quoted in EUR, GBP, USDT, JPY, CAD, etc., not only USD.
All LPCP guardrails (Low-Price Threshold, Min Stop ATR multiple, Min Notional) must operate on USD-normalized values, even when the quote currency differs.

🧭 CONTEXT FOR REPL.IT

The LPCP module was implemented in Phase 8.8.3-H.

LATTi/manual locking was fixed in Phase 8.8.3-H2.

LPCP currently assumes that all quote currencies = USD, which is incorrect for many Kraken pairs.

This phase adds an FX conversion layer so that LPCP logic remains consistent across markets.

📌 REQUIREMENTS FOR IMPLEMENTATION

2. Create a new FX Conversion Service

New file:

server/services/fx-conversion-service.ts

Responsibilities:
A. Cache FX quotes (30 seconds TTL)

Fetch once every 30 seconds:

USDT/USD

EUR/USD

GBP/USD

JPY/USD

CAD/USD

CHF/USD

Use Kraken endpoint:

/0/public/Ticker?pair=USDTUSD,EURUSD,GBPUSD,JPYUSD,CADUSD,CHFUSD

B. Provide function
async function convertToUSD(value: number, quoteCurrency: string): number


Logic:

If quote = USD → return value

Else use cached FX multiplier:

if cache empty → fetch immediately

if fetch fails → fail-safe: block trade + log error [8.8.3-H3][FX_FAIL]

3. Apply FX conversion inside LPCP

Update risk-manager:

Convert before running LPCP:
priceUSD = convertToUSD(entryPrice, quoteCurrency)
atrUSD   = convertToUSD(atrValue, quoteCurrency)
notionalUSD = convertToUSD(positionNotional, quoteCurrency)
stopDistanceUSD = convertToUSD(stopDistance, quoteCurrency)


Then run the same existing LPCP logic with these USD values.

No other logic changes.
