🧭 Directive 11.7A — Unified Signal Filter Integration (VTS + SQE Parity)
Dawn Trader Project — Phase 11.7 Series

Objective: Synchronize profitability gating, liquidity normalization, and signal filtering across both the Virtual Trade Simulator (VTS) and Signal Quality Evaluator (SQE), using canonical market regimes and metrics.

1. PURPOSE

This directive ensures that:

All simulated and live-mode signals use identical mathematical filters.

Filters are regime-aware, adjusting dynamically based on the current pair-level market condition.

Low-ROI or illiquid signals are logged (for ML) but not traded, preserving simulation capacity.

All filtering parameters are visible in the UI (Goals Engine → Screeners tab, SQE section).

🧩 Task 1 — Regime-Aware ROI Threshold Function

File: /server/core/calculations/expectancy.ts

Add the following exported helper:

// regime-aware ROI thresholds (pair-level)
export function getMinROIForRegime(regime: string): number {
  switch (regime) {
    case "BULL_STABLE": return 0.0125;     // 1.25%
    case "BEAR_VOLATILE": return 0.0250;   // 2.50%
    case "LOW_VOL_CHOP": return 0.0175;    // 1.75%
    case "HIGH_VOL_IMPULSE": return 0.0300; // 3.00%
    case "TRANSITION": return 0.0200;      // 2.00%
    default: return 0.0200;
  }
}


Add a unified NetEV check method for both VTS and SQE:

export function isSignalProfitable(entryPrice: number, targetPrice: number, regime: string): boolean {
  const roi = (targetPrice - entryPrice) / entryPrice;
  return roi >= getMinROIForRegime(regime);
}

💡 Task 2 — Integrate ROI Gate in VTS

File: /server/services/vts-runner.ts

Before creating a simulated trade (createTradeRecord() or equivalent):

import { isSignalProfitable } from "../core/calculations/expectancy";
import { telemetry } from "../core/logging/telemetry";

...

if (!isSignalProfitable(entryPrice, targetPrice, regime)) {
  telemetry.logSkippedSignal({
    symbol,
    reason: "Low_ROI",
    regime,
    expectedROI: ((targetPrice - entryPrice) / entryPrice),
    signalType,
  });
  return; // Skip creating the trade
}


This prevents low-ROI signals from filling the 300-slot VTS queue while preserving the data for ML ingestion.
