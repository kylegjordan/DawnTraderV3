STEP 1 — Log In and Capture TOKEN

APP_TEST_PASSWORD="testpassword123"

  -H "Content-Type: application/json" \
  -d '{"username":"'"$APP_TEST_USERNAME"'","password":"'"$APP_TEST_PASSWORD"'"}' \
  | jq -r '.token')

Return the full command output.

STEP 2 — Start Paper Trading (fresh session)

  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"mode":"paper"}' | jq .


Then wait 10 seconds:

sleep 10


Return the full output.

STEP 3 — Query Engine Status (critical)
