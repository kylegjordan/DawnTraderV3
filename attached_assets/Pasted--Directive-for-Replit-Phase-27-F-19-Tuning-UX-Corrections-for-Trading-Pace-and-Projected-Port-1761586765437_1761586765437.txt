🧩 Directive for Replit — Phase 27.F.19 (Tuning & UX Corrections for Trading Pace and Projected Portfolio Growth)

Goal:
Clean up the Trading Pace UI, correct percentage units, fix default behavior, expand projection table, stabilize refresh behavior, and improve design clarity for the Aggressive preset.

🧠 1️⃣ Fix Percentage Unit Scaling

Problem:
All LATTI target percentages are being displayed 10× too low.
Example – Aggressive shows +0.15 %, but true value is 1.5 %.

Fix:
Multiply the displayed percentage by 100 when rendering:

// Before
{targetDailyAvgEarningPct.toFixed(2)} %
// After
{(targetDailyAvgEarningPct * 100).toFixed(2)} %


Also ensure consistency across:

Trading Pace blue bar

Target Daily Goals input

Projected Portfolio Growth calculations (targetPct / 100 → targetPct / 10 000 after scaling).

🧠 2️⃣ Default Behavior When Switching Trading Pace

Problem:
When a user selects a pace preset, Target Daily Goals resets to 42.35 %, triggering a BLOCK warning.

Fix:
On preset change, populate the Target Daily Average Earnings % with LATTI’s recommended value —not the last manual override.

if (!userOverride) setTargetPct(latti.target_daily_avg_earning_pct);


Only persist an override after Save is clicked.

🧠 3️⃣ Stabilize Target Daily Goals Component

Problem:
The Projected Portfolio Growth table flashes periodically because the component auto-re-renders on WebSocket pings.

Fix:
Throttle re-renders to max once per 5 minutes or on manual input change only:

const lastUpdateRef = useRef(0);
useEffect(() => {
  if (Date.now() - lastUpdateRef.current > 300000) {
    refetch();
    lastUpdateRef.current = Date.now();
  }
}, [targetPct]);

🧠 4️⃣ Extend Projection Table

Add 6-Month and 1-Year rows below 3 Months:

[
  { label: 'Tomorrow', days: 1 },
  { label: '1 Week', days: 7 },
  { label: '1 Month', days: 30 },
  { label: '3 Months', days: 90 },
  { label: '6 Months', days: 180 },
  { label: '1 Year', days: 365 },
]

🧠 5️⃣ Format Dollar Values with Commas

Use Intl.NumberFormat for currency:

const fmt = new Intl.NumberFormat('en-US', { style: 'currency', currency: 'USD', maximumFractionDigits: 2 });


Render each value as fmt.format(value) for readable figures (e.g., $1,200.50 instead of $1200.5).

🧠 6️⃣ Update Aggressive Preset Styling

Replace the ⚠️ triangle icon and refine color palette.

New visuals:

Icon: Lucide ArmFlex (💪) or Zap for power.

Color: Use Deep Red → Saturated Crimson (#E63946) or Fire Orange (#FF5A36) to convey “high energy,” not error.

Hover tooltip: “High intensity trading mode — higher reward and risk balance.”

<TradingPaceCard
  variant="aggressive"
  icon={<ArmFlex className="text-red-500" />}
  color="bg-red-100 border-red-400"
  description="Highest risk, high-intensity mode for advanced users"
/>

🧠 7️⃣ Projected Growth Validation

If user-entered daily % > safe threshold (guardrail limit), show:
BLOCK – Target exceeds maximum safe threshold (${safeLimit} %)
Safe limit = guardrails.daily_loss_kill_switch × 5.
Otherwise display OK / WARN / BLOCK status colors as before.

Behavior	Result
