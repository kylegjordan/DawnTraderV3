🧩 Part II — Benchmark Filtering Fix (Implementation Instruction)

Please restore benchmark exclusion behavior for simulated trades.

Root Cause

The isBenchmark flag is lost in fx5-scanner.ts when the updateCurrentBatch() function maps survivor pairs into the batch consumed by VTS.

Required Fix

In fx5-scanner.ts (≈ lines 860–869):
Add the missing field in the batch map:

const batch: ScanBatchPair[] = survivors.map(s => ({
  symbol: s.symbol,
  pool: s.poolType || 'ideal',
  price: s.currentPrice,
  volume24h: s.volume24h,
  isBenchmark: s.isBenchmark, // ✅ restore benchmark flag propagation
  // ... other fields
}));


In server/services/vts-runner.ts:
Update the function getIdealPoolPairs() (or equivalent batch filter logic) to exclude benchmarks:

const idealPairs = scanBatch.filter(p => !p.isBenchmark);

❌ Never appear in “Open Simulated Trades” or “Closed Simulated Trades.”
