🧠 Implementation Steps
1️⃣ Modify ready_to_buy_service.ts

a. Remove legacy staggered delay

// REMOVE this line inside refreshAndRank():
await staggeredDelay(index * STAGGER_INTERVAL);


b. Introduce concurrent processing pool
Replace the sequential loop over activeSignals with a bounded concurrency pool:

const poolSize = 5; // initial safe concurrency level
const chunks = chunkArray(activeSignals, poolSize);

for (const group of chunks) {
  await Promise.all(
    group.map(async (signal) => {
      try {
        const metrics = await this.fetchFreshMetrics(signal);
        const updated = await this.recalculateAndPersist(signal, metrics);
        if (updated) bulkUpdates.push(updated);
      } catch (err) {
        bulkDeletes.push(signal.id);
      }
    })
  );
}


c. Batch database writes

After the loop, replace per-signal storage calls with batched operations:

if (bulkDeletes.length > 0)
  await this.storage.deleteRtbSignals(bulkDeletes);

if (bulkUpdates.length > 0)
  await this.storage.updateRtbSignals(bulkUpdates);

2️⃣ Modify or add helper function in storage/rtb-storage.ts

(if not already present)

Add batched DB operation support:

async updateRtbSignals(signals: RtbSignal[]) {
  return this.db.transaction(async (trx) => {
    for (const s of signals) {
      await trx('rtb_signals')
        .where({ id: s.id })
        .update(s);
    }
  });
}


(If a batch or transaction API already exists, reuse that instead.)
