B. Add a temporary anomaly guard in closePosition

Still in closePosition, after computing actualExitPrice, profit, profitPct, but before writing to DB:

Add a sanity check:

const priceMoveRatio =
  position.avgPrice > 0 ? Math.abs((actualExitPrice - position.avgPrice) / position.avgPrice) : 0;


If the price move is absurd (for debugging purposes, say > 100% within a short hold time):

if (priceMoveRatio > 1 && position.openedAt) {
  const msOpen = Date.now() - new Date(position.openedAt).getTime();

  if (msOpen < 5 * 60 * 1000) { // opened less than 5 minutes ago
    this.logger?.error('[B8.PNL][ANOMALOUS_CLOSE]', {
      symbol: position.symbol,
      strategy: position.strategyName,
      side: position.side,
      quantity: position.quantity,
      entryPrice: position.avgPrice,
      actualExitPrice,
      priceMoveRatio,
      msOpen,
      closeReason,
    });
  }
}


For now do not block the close, just log the anomaly. We want a clean view into what values are being used.
