✅ REB 2.11B — Symbol Mapping Trace Directive

GOAL: Identify exact string mismatches, normalization differences, ordering issues, or storage discrepancies between:

survivor symbols

active filter pool symbols

internal normalized symbols

Kraken API symbols

These mismatches are the root cause of the “Already Active” category never incrementing.

⚠️ MANDATORY RULES
❗ No business logic changes
❗ No filter behavior changes
❗ No active pool logic changes
❗ No scanner behavior changes
✔ Only add diagnostic output
✔ All instrumentation must be non-blocking and low-overhead
✔ Output must go to REB 2.11A diagnostic buffer (not console spam)
🟦 SECTION 1 — Add Symbol Mapping Interface

File: server/services/market-scanner.ts

Add this interface near the REB 2.11A interfaces:

export interface SymbolTraceEntry {
  cycle: number;
  mode: 'paper' | 'live';

  pair: string;                 // Raw survivor pair string (e.g., "FWOG/USD")
  normalizedPair: string;       // String after scanner normalization
  activePoolEntry: string | null;  // Exact string stored in active-filter-pool, if any
  krakenSymbol: string | null;     // Kraken API pair key (e.g., "XBTUSD") if available

  inActiveBefore: boolean;      // True if raw or normalized pair exists in activeBeforeCleanup
  inActiveAfter: boolean;       // True if raw or normalized pair exists in activeAfterCleanup
  wasCountedAlreadyActive: boolean; // What scanner *reported*
  shouldBeAlreadyActive: boolean;   // What REB audit says SHOULD be active

  mismatchType: 'NONE' | 'FORMAT' | 'NOT_FOUND' | 'ORDER' | 'LIMIT';
}


Add a 20-cycle FIFO buffer:

const reb211bSymbolTraceBuffer: SymbolTraceEntry[] = [];
export function getReb211bSymbolTraces(limit = 20) {
  return reb211bSymbolTraceBuffer.slice(-limit);
}

🟩 SECTION 2 — Instrument collectMixedBatch() for Symbol Mapping

Inside the survivor evaluation loop, immediately after filtering is complete and before survivors are finalized, create the symbol trace entry.

Below the existing REB 2.11A alreadyActive logic, add:

const trace: SymbolTraceEntry = {
  cycle: globalCycleCounter,
  mode,

  pair: pair.symbol,                  // raw survivor string
  normalizedPair: pair.symbol.trim().toUpperCase(),   // scanner canonical string

  activePoolEntry: activeBeforeCleanup.has(pair.symbol)
    ? pair.symbol
    : activeBeforeCleanup.has(pair.symbol.toUpperCase())
      ? pair.symbol.toUpperCase()
      : null,

  krakenSymbol: tickerMap[pair.symbol]?.krakenSymbol || null,

  inActiveBefore: activeBeforeCleanup.has(pair.symbol) ||
                  activeBeforeCleanup.has(pair.symbol.toUpperCase()),

  inActiveAfter: activeAfterCleanup.has(pair.symbol) ||
                 activeAfterCleanup.has(pair.symbol.toUpperCase()),

  wasCountedAlreadyActive: already_active.has(pair.symbol),
  shouldBeAlreadyActive:
      activeBeforeCleanup.has(pair.symbol) ||
      activeBeforeCleanup.has(pair.symbol.toUpperCase()),

  mismatchType: 'NONE',
};

Add mismatch classification:
if (trace.shouldBeAlreadyActive && !trace.wasCountedAlreadyActive) {
  trace.mismatchType = trace.activePoolEntry === null
    ? 'NOT_FOUND'
    : 'FORMAT';
}

Push trace into buffer:
reb211bSymbolTraceBuffer.push(trace);
if (reb211bSymbolTraceBuffer.length > 400) {
  reb211bSymbolTraceBuffer.shift();
}
