Ensure Walter’s cognitive and learning layers automatically recognize the new global-context data bindings introduced in Addendum A, forget obsolete schema paths, and keep all future self-learning anchored to verified sources.

🪜 Implementation Tasks
Task 1 – Schema Binding Validation

Confirm that the following schema references are the only active data sources for both modes:

Goals → portfolio_goals_state

Strategies → strategy_settings_global

Portfolio → portfolio_state

In walter-cognitive-layer, create a Retraining Map defining authoritative data origins:

goals → portfolio_goals_state
strategies → strategy_settings_global
balances → portfolio_state


On startup, Walter should automatically load this map into memory and tag it as immutable (frozen=true).

Log line: [LearningAlignment] Cognitive source map loaded and frozen.

Task 3 – Memory Sanitization

Purge all walter_memory entries where domain = goals, strategy_status, risk_metrics, or legacy_snapshot.

Rebuild each domain from live provenance data.

Confirm rebuild by logging:
[MemoryRebuild] goals,strategy domains refreshed from live-api ✓

Task 4 – BoB and Cortex Learning Alignment

Update the Learning Bob and Cognitive Interpreter so any new learning fragment stores its source_table from the Retraining Map.

On each learning cycle, verify that fragment sources match the map.

If any fragment references legacy tables, quarantine it under legacy_learning and log:
[LearningAlignment] Quarantined fragment with legacy reference.

Task 5 – Provenance Cross-Check

Generate a test lineage run (trace_validation=true) and verify the following traceId path for both live and paper modes:

Database → BoB → Cortex → Walter → UI


Expected source_table sequence:

goals → portfolio_goals_state

strategies → strategy_settings_global

balances → portfolio_state

Report continuity ≥ 99 %.

Governance report should show “Provenance Continuity: PASS”.

Task 6 – Auto-Learning Lock

Enable an autoLearningLock flag so that, after successful validation, Walter cannot relearn from any unverified source until manually unlocked.

Log confirmation:
[LearningAlignment] Auto-learning locked to validated schema.
