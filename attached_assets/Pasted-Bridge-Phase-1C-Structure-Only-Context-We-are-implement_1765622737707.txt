📄 Step 4 — Create Decision Ledger README

Create this file:

/bridge/decisions/README.md


With exactly the following contents:

# DawnTrader Decision Ledger

This folder records **explicit human-approved decisions**.

Rules:
- No decision exists unless documented here
- ChatGPT must not assume decisions
- Replit must not reinterpret decisions
- Decisions override historical discussion

Required format for each decision:
- Date
- Context
- Decision
- Scope
- Immutable constraints

📄 Step 5 — Create Directives README

/bridge/directives/README.md

# Approved Directives

This folder contains directives that were:

1. Proposed by ChatGPT
2. Explicitly approved by the human
3. Executed by Replit

Drafts, ideas, or unapproved instructions do NOT belong here.

📄 Step 6 — Create Bridge README

Create this file:

/bridge/README.md


With exactly the following contents:

# DawnTrader Bridge

The Bridge is the durable coordination layer between:

- ChatGPT (architecture, reasoning, directives)
- Replit (execution and implementation)
- Human authority (final approval)

Purpose:
- Prevent context loss
- Preserve decisions across sessions
- Enforce explicit approval
- Protect canonical system truth

Canonical truth lives in:
- /bridge/canonical

Searchable history lives in:
- /bridge/reference

Nothing executes without approval.
