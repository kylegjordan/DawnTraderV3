⚙️ Pre-Test Setup

Stop the paper-trading engine

curl -X POST http://localhost:5000/api/paper-sim/stop \
     -H "Authorization: Bearer $TOKEN"


Clear residual data

curl -X DELETE http://localhost:5000/api/paper-sim/clear-rtb \
     -H "Authorization: Bearer $TOKEN"
curl -X DELETE http://localhost:5000/api/paper-sim/clear-trades \
     -H "Authorization: Bearer $TOKEN"


Initialize portfolio manually (not hard-coded)

curl -X PATCH http://localhost:5000/api/paper-sim/config \
     -H "Authorization: Bearer $TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"starting_balance":824.00}'


Confirm environment thresholds

SQE_NGC_MIN=0.30
SQE_CWQI_MIN=0.20
SQE_PROFIT_RATE_MIN=0.00
SQE_MAX_RISK=0.95
MIN_VOLUME_USD=5000

🚀 Start Validation Session
curl -X POST http://localhost:5000/api/paper-sim/c14-validation/start \
     -H "Authorization: Bearer $TOKEN"
