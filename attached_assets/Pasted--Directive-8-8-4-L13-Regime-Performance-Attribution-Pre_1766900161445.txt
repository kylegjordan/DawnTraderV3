1 | Objective

To enable forward-looking market adaptation, this directive builds on L12 (Market Condition Profiling) by:

Measuring each regime’s historical and real-time impact on trading performance (PnL, win rate, drawdown, stability).

Learning to predict regime transitions before they occur.

Biasing strategy allocation pre-emptively based on regime forecasts, rather than reactively.

The goal is to create a self-anticipating system that positions Dawn Trader ahead of market changes.

2 | Core Components
Component	Description
Regime Performance Tracker (RPT)	Continuously aggregates performance stats by current regime.
Transition Predictor (RTP)	ML model predicting probability of regime shifts (e.g., R1 → T1) within the next cycle.
Proactive Allocator (PA)	Adjusts regime weights and exposures based on RTP probabilities.
Performance Dashboard Extension	Adds historical regime performance & predicted next regime indicators to the Adaptive Risk Advisor (ARA).

3.2 Transition Predictor (RTP)

📁 services/ml_service.py

Purpose: Forecast probability of next regime using historical transitions and market metrics.

Model:

Type: Logistic Regression (multi-class)

Inputs: last 3 regime states, volatility σ, trend slope, volume z-score, Sharpe ratio deltas

Target: next regime in sequence

Retrained nightly or on demand via /api/market/retrain_transitions

Output Example:

{
  "current": "R1",
  "predicted_next": "T1",
  "probabilities": {
    "T1": 0.63,
    "R1": 0.22,
    "T2": 0.08,
    "V1": 0.05,
    "C1": 0.02
  }
}

Fully async, non-blocking, low CPU (<2%).

All data persisted under /logs/regime_forecast/.
