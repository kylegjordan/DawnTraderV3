Parent Phase: 11 (Predictive Stability & Diagnostic Clarity)
Schema Version: predictive-diagnostics/v1.0
Predecessor Directives:

11.7C — Predictive Confidence Normalization

1. Objective

To expand DawnTrader’s Analytics & Diagnostics interface with a new Predictive Diagnostics & Filter Transparency Panel, giving operators full interpretability over:

Filter logic and gating conditions

Predictive model calibration and accuracy

Signal confidence and attribution weighting

End-to-end traceability for every model and trade decision

This directive transforms the predictive system from a “black box” into a transparent, auditable decision engine.

2. Core Deliverables

4. Data Structure & API Schema
Endpoint:

GET /api/system/predictive-diagnostics

JSON Response:
{
  "schema": "predictive-diagnostics/v1.0",
  "timestamp": "2026-01-24T00:00:00Z",
  "predictiveModels": {
    "ensemble_primary": {
      "calibrationDrift": 0.12,
      "meanConfidence": 0.78,
      "accuracy7d": 0.82,
      "weightContribution": { "volZ": 0.33, "trendZ": 0.29, "adx": 0.22, "momentum": 0.16 }
    }
  },
  "filters": {
    "macroFilter": { "status": "PASS", "reason": "Trend > threshold" },
    "volatilityFilter": { "status": "BLOCKED", "reason": "VolZ > +1.5σ" },
    "confidenceGate": { "status": "PASS", "threshold": 0.65, "confidence": 0.72 },
    "riskScreen": { "status": "PASS", "riskRatio": 0.9 }
  },
  "recentDecisions": [
    {
      "pair": "BTCUSDT",
      "signalType": "HYBRID",
      "predictedRegime": "HIGH_VOL_IMPULSE",
      "modelUsed": "ensemble_primary",
      "decision": "APPROVED",
      "tracePath": ["Signal", "Volatility Filter", "Confidence Gate", "Model", "Trade Execution"]
    }
  ]
}

🧩 Minor Technical Adjustments

recentDecisions Cap:
Limit to last 100 entries (slice(-100)) to prevent unbounded array growth or UI lag.

WeightContribution Labeling:
UI to show “Weight Contribution (%)” instead of “SHAP / Feature Attribution”.
These values reflect Directive 11.7D Predictive Weights, not deep model SHAP outputs.

Decision Traceback

Node-level info for confidence, filter triggers, and outcome

Color Legend:
Status	Color	Meaning
PASS	🟩 Green	Filter passed
BLOCKED	🟥 Red	Filter failed
SKIPPED	🟨 Yellow	Filter not evaluated
DRIFT	🟧 Orange	Model calibration drift > 1σ
