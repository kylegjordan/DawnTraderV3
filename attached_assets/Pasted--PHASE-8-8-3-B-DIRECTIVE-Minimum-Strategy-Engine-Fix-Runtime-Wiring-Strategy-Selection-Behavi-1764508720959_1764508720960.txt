🔷 STEP 4 — Validate and Harden StrategySignal → Ready-To-Trade Wiring

From the 8.8.3-A audit, StrategySignal → TradeSignal mapping is structurally compatible.

Now we need to protect against bad runtime values.

Where signals are handed off to the ready-to-trade / ready-to-buy pipeline (likely via lifecycleEventsService.emitReadyToTrade()):

Add a small validation function that checks:

function validateStrategySignal(signal: StrategySignal): { ok: boolean; reason?: string } {
  if (!signal.symbol) return { ok: false, reason: "missing symbol" };
  if (!signal.strategy) return { ok: false, reason: "missing strategy" };
  if (typeof signal.entryPrice !== "number" || signal.entryPrice <= 0)
    return { ok: false, reason: "invalid entryPrice" };
  if (typeof signal.stopPrice !== "number" || signal.stopPrice <= 0)
    return { ok: false, reason: "invalid stopPrice" };
  if (typeof signal.targetPrice !== "number" || signal.targetPrice <= 0)
    return { ok: false, reason: "invalid targetPrice" };
  if (signal.stopPrice >= signal.entryPrice)
    return { ok: false, reason: "stopPrice >= entryPrice" };
  if (signal.targetPrice <= signal.entryPrice)
    return { ok: false, reason: "targetPrice <= entryPrice" };
  if (typeof signal.confidence !== "number" || signal.confidence < 0 || signal.confidence > 100)
    return { ok: false, reason: "invalid confidence" };

  return { ok: true };
}


Before emitting:

const validation = validateStrategySignal(strategySignal);
if (!validation.ok) {
  console.warn("[8.8.3-B][ROUTING] Dropped malformed StrategySignal", {
    reason: validation.reason,
    signal: strategySignal
  });
  return;
}

console.log("[8.8.3-B][ROUTING] StrategySignal accepted", {
