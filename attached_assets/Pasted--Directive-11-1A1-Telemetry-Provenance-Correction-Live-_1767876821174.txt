🧭 1. Purpose

This directive resolves a data-provenance flaw introduced in Directive 11.1A.
It ensures that:

Telemetry records preserve their true execution mode (paper, live, staging) regardless of persistence overrides.

FORCE_PERSIST acts only as a gate to allow saving test data, never to mis-label it as live.

The rehydration pipeline exclusively loads legitimate live-mode telemetry into runtime memory.

Failure to correct this creates a “Fake Live Data” condition that pollutes production intelligence and corrupts adaptive learning in Phase 11.1B.

🧩 3. Technical Tasks
Task 1 — Refactor Mode Logic

File: /server/services/telemetry-repository.ts

Replace the misleading function:

// ❌ Old
export function getEffectivePersistMode() {
  const mode = process.env.MODE || "paper";
  const force = process.env.FORCE_PERSIST === "true";
  return force ? "live" : mode;
}


with the corrected dual-function design:

// ✅ New
export function shouldPersist(): boolean {
  const mode = process.env.MODE || "paper";
  const force = process.env.FORCE_PERSIST === "true";
  return (mode === "live" && process.env.PERSIST_TELEMETRY !== "false") || force;
}

export function getTrueMode(): string {
  return process.env.MODE || "paper";
}


All telemetry writes must now use:

if (shouldPersist()) {
  await saveTelemetryRecord({
    ...telemetryEntry,
    mode: getTrueMode(), // preserve actual environment
  });
}

Task 2 — Update Rehydration Logic

File: /server/services/telemetry-aggregator.ts

Restrict SQL query to live data:

export async function rehydrateTelemetryState() {
  const regime = getCurrentMarketRegime();
  const records = await db
    .select()
    .from(telemetry_history)
    .where(and(
      telemetry_history.mode.eq("live"),
      telemetry_history.regime.eq(regime)
    ))
    .orderBy(desc(telemetry_history.timestamp))
    .limit(100);

  telemetry.merge(records);
  console.log(`[Telemetry] Rehydrated ${records.length} live entries for ${regime}`);
}


✅ Result: No paper/staging data can enter live runtime memory.
