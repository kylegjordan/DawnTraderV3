⚙️ Directive 11.6 H — Correct Quantity & Dollar Value Calculation in VTS

Phase: 11.6 H
Author: Kyle Jordan
Date: 2026-01-21
Status: Approved for Implementation
Scope: VTS → Machine Learning Dashboard → Simulated Trades Tables

🎯 Objective

Ensure all Virtual Trading Simulator (VTS) simulated trades reflect realistic capital allocation by separating:

Dollar Value — fixed per-trade USD exposure (capped at 25 % of paper portfolio balance)

Quantity — the variable number of asset units based on entry price

This change removes the misleading “250 units” artifact and brings the passive-learning simulation into alignment with the real-world trade sizing logic used by TEC.

🧱 I. Implementation Tasks
🧩 1 — Backend: VTS Trade Record Computation

File: /server/services/vts-runner.ts
Approx. Location: Lines 395 – 415

Replace the current assignment logic with:

// === Compute capital allocation ===
const tradeAllocation = Math.min(positionSize, maxPositionSize);   // USD exposure cap

// === Convert to variable quantity ===
const quantity = tradeAllocation / entryPrice;

// === Record both ===
tradeRecord.dollarValue = tradeAllocation;   // total USD exposure
tradeRecord.quantity    = quantity;          // number of coin units


Add verification log:

console.log(`[VTS][Sizing] ${symbol}: $${tradeAllocation.toFixed(2)} exposure → ${quantity.toFixed(6)} units`);
