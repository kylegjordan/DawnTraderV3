DASHBOARD & GOALS ENGINE — FULL IMPLEMENTATION SPECIFICATION

(For Development and Testing in Replit)

🌐 OVERVIEW

This enhancement restructures the trading dashboard and introduces a Goals Engine System — a complete loop that allows users to define, monitor, and iteratively optimize performance targets with the help of the AI Analyst.

It includes:

Four redesigned Dashboard Widgets

A full-width Goals Summary Widget

A new Goals Engine Panel (replacing the previous static Settings sections)

AI-assisted goal definition and adjustment through both structured input and conversational discussion

Automatic synchronization between Live and Paper trading modes (data fully separated)

Integration with strategy logic and trade prioritization systems to achieve defined goals

⚙️ 3. GOALS ENGINE PANEL — NEW STRUCTURE

The Goals Engine becomes its own top-level navigation panel, replacing the old “Settings” panel for portfolio and strategy management.

Tabs within Goals Engine Panel
🧮 Tab 1: Goals Engine (Main Tab)

Top Section: Editable goals table

Columns: Metric | Goal | Actual | % Achieved

User can input or edit goals.

If user enters one of the grouped earnings values (daily, weekly, monthly, yearly), the others auto-calculate.

Bottom Section: Conversational AI panel

Contextual chat with the AI Analyst.

Supports conversational goal-setting (e.g. “I want to increase monthly earnings by 30% without raising risk exposure.”).

AI:

Evaluates feasibility based on capital, risk, and strategy parameters.

Suggests new target values.

Proposes specific strategy/guardrail/screener variable changes.

Requests confirmation before implementation.

Upon Agreement:

Goals saved to database.

AI applies updated configuration automatically.

📈 Tab 2: Portfolio

Moves from previous “Settings” panel.

Displays current portfolio configuration and performance metrics.

Allows AI to adjust allocation suggestions based on goals.

🛡️ Tab 3: Guardrails

Displays and allows adjustments to portfolio-level risk parameters (e.g. max drawdown, position size limits).

AI can modify guardrails based on agreed goals.

🔍 Tab 4: Screener Filters

Shows active filters used to identify trade opportunities.

AI can adjust screener parameters to align with goal strategy (e.g. higher return focus vs. safer consistency).

⚙️ Tab 5: Strategies

Shows all configured trading strategies with their current variables (entry conditions, risk/reward, etc.).

AI proposes and applies variable changes tied to goal achievement.

🔄 6. TRADE PRIORITIZATION INTEGRATION

When multiple trades are eligible, AI calculates a goal_alignment_score for each.

Incorporates alignment with goals (e.g., profitability vs. consistency).

Formula:

final_score = (signal_confidence × 0.7) + (goal_alignment_score × 0.3)


Result: The system prioritizes trades most likely to help achieve active goals.
