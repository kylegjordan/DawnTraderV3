🎯 Objective

Ensure that whenever Paper Trading starts or stops, the backend broadcasts a unified trading_state_changed WebSocket event so all connected clients immediately show the correct “ACTIVE / STOPPED” state in the top bar and toggle.

🧱 1️⃣ Update Paper Sim Start Route

File: server/routes/paper-sim.ts

Find the handler for

router.post('/start', async (req, res) => {


and immediately after the log line confirming the simulation started (for example console.log('Paper simulation started')), add 👇

// Phase 32.D-Fix.4 — Broadcast unified trading_state_changed event on Paper Start
contextBridge.broadcast({
  type: 'trading_state_changed',
  payload: {
    mode: 'paper',
    active: true,
    isEngineActivePaper: true,
    timestamp: new Date().toISOString(),
  },
});
console.log('[32.D-Fix.4] Broadcasted paper trading_state_changed (active = true)');

🧱 2️⃣ Update Paper Sim Stop Route

Still in server/routes/paper-sim.ts, inside the /stop handler, add 👇 right after you log that the simulation stopped:

// Phase 32.D-Fix.4 — Broadcast unified trading_state_changed event on Paper Stop
contextBridge.broadcast({
  type: 'trading_state_changed',
  payload: {
    mode: 'paper',
    active: false,
    isEngineActivePaper: false,
    timestamp: new Date().toISOString(),
  },
});
console.log('[32.D-Fix.4] Broadcasted paper trading_state_changed (active = false)');

🧱 3️⃣ Ensure the Event Uses payload (not data)

All frontend listeners expect:

msg.payload.mode
msg.payload.active


If your existing broadcast utility sends { type, data }, change data → payload to match this schema.

🧱 4️⃣ (Recommended) Force Sync on Server Start

File: server/services/trading-state-sync.ts

Inside the reconciliation block where you log
[32.D-Fix.1] Active paper session(s) detected,
append 👇

contextBridge.broadcast({
  type: 'trading_state_changed',
  payload: {
    mode: 'paper',
    active: true,
    isEngineActivePaper: true,
    timestamp: new Date().toISOString(),
  },

This guarantees clients always resync to the correct state within seconds of connection.
