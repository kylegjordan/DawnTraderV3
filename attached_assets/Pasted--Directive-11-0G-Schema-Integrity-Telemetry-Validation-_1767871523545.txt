Task 2 — Add Archive Integrity Checksum

File: /server/legacy/metrics_archive.ts

Add a checksum field to ensure immutability:

import crypto from "crypto";

export function sealLegacyArchive(data: any) {
  const serialized = JSON.stringify(data);
  const checksum = crypto.createHash("sha256").update(serialized).digest("hex");
  data.archiveChecksum = checksum;
  return data;
}


When creating a new archive snapshot (legacy_metrics_snapshot.json), the system will automatically add:

"archiveChecksum": "<sha256-hash>"

Task 3 — Telemetry Schema Validation

Files:

/server/services/telemetry-aggregator.ts

/client/pages/diagnostics/telemetry_panel.tsx

Add a runtime schema validation check:

function validateTelemetrySchema(backendSchema, frontendSchema) {
  if (backendSchema !== frontendSchema) {
    console.warn(`[Telemetry] Schema mismatch detected: backend=${backendSchema}, frontend=${frontendSchema}`);
    telemetryHealth = "yellow";
  } else {
    telemetryHealth = "green";
  }
}


Expose validation result in telemetry:

  metricEngineVersion: "v1.0",
