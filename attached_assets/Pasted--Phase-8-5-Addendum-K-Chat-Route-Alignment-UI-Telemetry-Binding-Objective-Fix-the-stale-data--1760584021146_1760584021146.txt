2️⃣ Add Telemetry Hooks to Dashboard

File: client/src/pages/dashboard.tsx

Import React Query or useEffect interval logic to poll every 30 seconds:

useEffect(() => {
  const fetchTruthData = async () => {
    const { data } = await api.get("/api/system/truth-check");
    setTruthData(data);
  };
  fetchTruthData();
  const timer = setInterval(fetchTruthData, 30000);
  return () => clearInterval(timer);
}, []);


Pass truthData into the SystemTruthPanel component props.

4️⃣ Bind Data Flow Trace (Dev Only)

File: client/src/components/dashboard/data-flow-trace.tsx

Intercept Axios/Fetch requests in api.ts and push a record into a small in-memory array:

api.interceptors.response.use((response) => {
  logTrace({
    endpoint: response.config.url,
    method: response.config.method,
    latency: Date.now() - response.config.metadata.start,
    status: response.status,
  });
  return response;
});


Display the last 5 records in a simple table with columns:
Time | Endpoint | Method | Latency (ms) | Status.
