1️⃣ Diagnose Missing Hybrid/Pattern Signals

Observed Behavior:

The Top Batch (Ideal Pool) currently shows only QUANT signals.

All 17 canonical strategies are available, but only QUANT are surfacing in runtime telemetry.

Goal: Determine which layer is failing

There are three possible failure points:

Layer	Function	Possible Failure
VTS Runner	Generates and filters trade candidates.	Filter logic may still exclude HYBRID/PATTERN signalTypes (hardcoded).
Pattern Detector / Pattern Synthesizer	Confirms pattern match and populates patternType field.	Detector may not be executing post-canonicalization.
Telemetry Aggregator	Receives the generated payload from VTS and emits to analytics layer.	PatternType or SignalType may be getting dropped in serialization (missing schema field).
Diagnostic Procedure

Step 1: Instrumentation Logging

Insert temporary structured logs in these three files:

/server/services/vts-runner.ts

console.debug('[VTS] Candidate generated:', {
  pair,
  signalType,
  strategy,
  score,
  patternDetected: patternType || 'none'
});


/server/core/pattern-detector.ts

console.debug('[Pattern Detector]', { pair, patternType });


/server/services/telemetry-aggregator.ts

console.debug('[Telemetry] Emitted trade:', {
  signalType,
  strategy,
  patternType,
  regime
});


Step 2: Run Diagnostic Sweep
Run:

npm run vts:scan -- --pairs=100 --logLevel=debug > /audit/logs/pattern_signal_trace.log


Step 3: Analyze Log Outputs

Expected Finding	Interpretation
Logs show hybrid/pattern strategies generated in VTS but missing at telemetry	Serialization issue in Telemetry Aggregator.
No hybrid/pattern candidates generated at all in VTS	Filter logic issue (signalType filter).
Pattern detector shows matches but patternType not attached to final output	Pattern-to-strategy binding missing in canonical linkage.

Step 4: Generate Diagnostic Summary
Output → /audit/reports/missing_pattern_rootcause.json

Fields:

{
  "rootCause": "VTS_FilterLogic", 
  "hybridCandidatesGenerated": 0,
  "patternMatchesDetected": 12,
  "telemetryEntriesReceived": 0,
  "recommendation": "Enable hybrid/pattern filters in VTS and propagate patternType in payload"
}


Once confirmed, only then execute the appropriate fix directive (G3).
