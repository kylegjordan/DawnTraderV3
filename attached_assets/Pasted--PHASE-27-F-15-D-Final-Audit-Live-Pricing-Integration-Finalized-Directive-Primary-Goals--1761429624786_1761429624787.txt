⚙️ 2. LIVE PRICING ADAPTER
New Service

/server/services/live-pricing-adapter.ts

Features:

Fetches live quotes via public API (Binance, CoinGecko, or test sandbox).

Default refresh: every 15 seconds.

Caches results under live_prices:<symbol> via in-memory or Redis store.

Broadcasts via WebSocket as:

{
  "type": "price_updated",
  "mode": "live",
  "symbol": "BTCUSDT",
  "price": 68451.22,
  "timestamp": "2025-10-27T14:42:11Z"
}


Adds [27.F.15.D][Pricing] logs to system console.

Mock / Offline Fallback

If no API key or connection available:

Generates synthetic price updates ±0.2% every 15s.

Logs [27.F.15.D][Pricing-MOCK] with simulated deltas.

Prevents dependency on external connectivity during testing.
