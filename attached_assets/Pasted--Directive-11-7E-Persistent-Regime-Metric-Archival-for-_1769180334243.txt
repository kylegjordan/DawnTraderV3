🧩 Task 2 — Archival Collector & Checksum Logic

File: /server/scripts/archive-regime-metrics.ts

Process:

Load latest telemetry + canonical weights.

Merge into regime-strategy records.

Deterministic Checksum:

function canonicalStringify(obj) {
  return JSON.stringify(obj, Object.keys(obj).sort(), 3);
}
const checksum = crypto
  .createHash("sha1")
  .update(canonicalStringify(record))
  .digest("hex")
  .slice(0, 8);


✅ Ensures key order consistency, eliminating false mismatches.

Validate schema → log warnings for missing metrics (<2 strategies).

Retry + rollback if checksum verification fails after write.

Append safely via safeAppendJSON with file lock.
