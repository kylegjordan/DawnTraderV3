📌 Directive: Update Chaplet Grounding Schema to Include Assistant Expertise Reference

Directive ID: M4.1-GROUNDING-EXPERTISE
Phase: M4.1
Target System: DawnTrader (Embedded Chaplet Context Service)
Scope: Read-only context grounding
Risk Level: Low
Authorization: Governance / Architecture
Execution Authority: Replit Agent only

🎯 Objective

Update the Chaplet grounding response so that assistant expertise requirements are explicitly declared as mandatory authoritative context, sourced from the bridge.

This ensures all ChatGPT sessions operating under Chaplet are required to acknowledge and adhere to the defined expertise persona before any planning or directive work.

📂 Authoritative Source

The expertise definition already exists at:

/bridge/reference/ChatGPT Expertise Persona for The Dawn Trader.md


No new files are to be created.

🔧 Required Changes
1️⃣ Update the Grounding Response Schema

Modify the response returned by:

GET /chaplet/context/grounding


to include a new top-level object:

"assistant_context": {
  "expertise_reference": {
    "path": "/bridge/reference/ChatGPT Expertise Persona for The Dawn Trader.md",
    "role": "Defines the required expertise, perspective, and decision standards for the ChatGPT assistant operating on DawnTrader.",
    "mandatory": true
  }
}


This object must be always present in the grounding response.
