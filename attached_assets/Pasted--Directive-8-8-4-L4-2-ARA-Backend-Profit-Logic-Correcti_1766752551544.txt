2️⃣ Backend Fix
In /server/services/ara-service.ts:

Replace the current logic with:

function calculateARAMetrics({ portfolioValue, riskPerTrade, maxExposure, mlExpectedProfit }) {
  const avgValuePerTrade = (portfolioValue * riskPerTrade) / 100;
  const numTrades = Math.floor(maxExposure / riskPerTrade);

  // ML-predicted expected profit rate (e.g., 0.05 = 5%)
  const predictedProfitRate = mlExpectedProfit || 0.05;

  // Gross Profit
  const estimatedGrossProfit = avgValuePerTrade * predictedProfitRate;

  // Trading fees & slippage (both sides, ~0.7%)
  const totalTradeCost = avgValuePerTrade * 0.007;

  // Net Profit
  const estimatedNetProfit = estimatedGrossProfit - totalTradeCost;

  // Expected profit percent (net)
  const expectedProfitPercent = (estimatedNetProfit / avgValuePerTrade) * 100;

  return {
    numTrades,
    avgValuePerTrade,
    estimatedGrossProfit,
    estimatedNetProfit,
    expectedProfitPercent
  };
}


Then export through:

export const ARAService = { calculateARAMetrics };
