✅ TASK A — Add Diagnostic Logging (NO LOGIC CHANGES)

Add log lines at the following points:

A1 — When the system subscribes to a WebSocket pair

In KrakenWebSocketAdapter.subscribe(pair) add:

[I7-WS-A][SUB_REQ] kraken_ws_pair=<pair> internal_symbol=<resolver-normalized> 

A2 — When Kraken acknowledges the subscription

In the WS message handler where subscription confirmations are processed, log:

[I7-WS-A][SUB_ACK] kraken_ws_pair=<pair> status=success 


If Kraken rejects a subscription:

[I7-WS-A][SUB_REJECT] kraken_ws_pair=<pair> error=<message>

A3 — When the first tick is received for a pair

When a price update from Kraken WS is received:

[I7-WS-A][FIRST_TICK] kraken_ws_pair=<pair> internal_symbol=<mapped> price=<p>


IMPORTANT:

Only log FIRST tick per symbol (use a simple Set to track which symbols have logged).

Do NOT change cache behavior.

A4 — When a tick updates the internal price cache

Where the internal price cache is updated, add:

[I7-WS-A][CACHE_UPDATE] internal_symbol=<symbol> price=<price> 

A5 — When the backend broadcasts the updated price

In the live-pricing broadcast path, add:

[I7-WS-A][BROADCAST] internal_symbol=<symbol> price=<price> mode=<mode>
