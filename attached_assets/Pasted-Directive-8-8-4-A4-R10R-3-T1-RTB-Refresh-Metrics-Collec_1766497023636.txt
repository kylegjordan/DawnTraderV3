Directive 8.8.4-A4.R10R-3.T1 — RTB Refresh Metrics Collector & 10-Minute Validation Run
🧩 Objective

Collect live performance telemetry for the Central-Clock-synchronized Ready-To-Buy Refresh Service (RTBRefreshService).
This test will measure:

Average refresh time per signal (tₛ)

Number of signals processed per 15-second micro-cycle (bucketSize)

Cycle duration per bucket (cycleDuration)

Derived capacity per bucket (xₘₐₓ)

Frequency of overlaps or skipped cycles

These results will feed into Directive 8.8.4-A4.R10R-4, defining RTB load balancing and queue capacity thresholds.

⚙️ Implementation Tasks
1️⃣ Add Instrumentation

Edit server/services/rtb-refresh-service.ts inside refreshBucket():

const start = Date.now();
const bucket = this.getBucket(bucketIndex);
const bucketSize = bucket.length;

this.log(`[8.8.4-A4.R10R-3.T1][CYCLE_START] tick=${tickNumber} bucket=${bucketIndex} size=${bucketSize}`);

for (const signal of bucket) {
  const sStart = Date.now();
  await this.refreshSignal(signal);
  const sDur = Date.now() - sStart;
  this.log(`[8.8.4-A4.R10R-3.T1][SIGNAL_METRIC] id=${signal.id} bucket=${bucketIndex} refreshTime=${sDur}ms`);
}

const duration = Date.now() - start;
this.log(`[8.8.4-A4.R10R-3.T1][CYCLE_COMPLETE] bucket=${bucketIndex} size=${bucketSize} duration=${duration}ms`);
