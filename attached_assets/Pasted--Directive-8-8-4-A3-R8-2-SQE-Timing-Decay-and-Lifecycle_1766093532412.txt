Context

Following the successful integration of the Central Clock (Directive A3.R7) and lifecycle observability (Directive A3.R8), signal evaluations within the Signal Quality Engine (SQE) began exhibiting a 100% SQE_QUALITY_REJECT rate.

Analysis of repo files (signal_quality_engine.ts, ready_to_buy_service.ts, and signal_metrics.ts) shows that this is not a data quality issue — it’s a timing misalignment caused by the Central Clock’s tick counter being used in the NGC decay formula, coupled with double-decay and double-normalization events during Ready-to-Buy (RTB) refresh cycles.

Additionally, the status column (active / reconfirmed / promoted / expired) was added to the database schema but not yet surfaced in the frontend UI table.

Objective

To restore correct SQE behavior and RTB lifecycle tracking by:

Re-synchronizing NGC decay timing with real timestamps.

Preventing redundant decay and normalization in refresh cycles.

Ensuring the RTB UI displays the full 4-state lifecycle status.

Implementation Tasks
1️⃣ server/core/sqe/signal_quality_engine.ts

Replace:

const elapsed = (CentralClock.now() - signal.createdAt) / 1000;


With:

const elapsed = (Date.now() - signal.createdAt) / 1000;


Add inline log trace:

console.log(`[A3.R8.2][NGC] symbol=${signal.symbol} pre=${pre.toFixed(4)} decay=${decay.toFixed(4)} post=${signal.metrics.ngc.toFixed(4)}`);


Ensure this logging appears in logs/diagnostics/sqe_ngc_timing_trace.log.

2️⃣ server/core/rtb/ready_to_buy_service.ts

Modify evaluateSignalQuality() signature:

async evaluateSignalQuality(signal, { skipDecay = false } = {}) { … }


Within this function:

if (!skipDecay) { applyDecay(signal); }


In refreshAndRank() and reEvaluateQueue(), call:

await this.evaluateSignalQuality(signal, { skipDecay: true });


Remove redundant normalization call following refresh:

// Remove or comment out:
signal.metrics.ngc = normalizeNGC(signal.metrics.ngc);


Confirm that only the initial SQE pass applies decay and normalization once per lifecycle.

3️⃣ shared/metrics/signal_metrics.ts

Remove secondary normalization if already normalized:

// Before:
signal.metrics.ngc = normalizeNGC(signal.metrics.ngc);
// After:
if (signal.metrics.ngc > 1) signal.metrics.ngc = normalizeNGC(signal.metrics.ngc);


Retain normalization only at the end of the initial SQE computation pipeline.

4️⃣ client/components/ReadyToBuyTable.tsx
