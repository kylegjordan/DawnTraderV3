🎯 Objective

Finalize modernization of the Virtual Trading Simulator (VTS) by:

🧩 Implementation Tasks
Task 1 — VTS Service Modernization

📁 /server/services/vts-service.ts

Goal: Replace all legacy Phase-8 metrics and persist complete Phase-10 signal data.

Actions

Extend VirtualTrade schema
Add:

finalScore: number;

regimeWeight: number;

expectedEdge: number;

Remove: cwqi, ngc, di, gsi.

Update createVirtualTrade() and closeTrade()

Persist all above fields.

Write logs to logs/virtual_trades/virtual_trades_*.json.

Ensure each record includes "source": "simulation" and "schemaVersion": "1.6.7".

Deprecate SessionMetrics legacy fields

Delete averageCWQI, averageNGC, etc.

Replace with rolling averages for finalScore, expectedEdge, realizedPnL.

Task 2 — ML Calibration Alignment

📁 /server/services/ml-calibration.ts

Goal: Consume and weight trades using Phase-10 metrics.

Actions

Modify recordTradeOutcome(trade: VirtualTrade) to compute:

const performanceScore =
  (trade.finalScore * 0.5) +
  (trade.predictiveConfidence * 0.3) +
  (trade.regimeWeight * 0.2);


Use expectedEdge vs realizedPnL delta for learning weights.

Store calibration entries under phase10Metrics.

Remove any references to CWQI/NGC/DI/GSI.

Task 3 — Strategy Execution Isolation

📁 /server/services/vts-runner.ts, /server/core/strategy-execution.ts, /server/strategies/*

Goal: Ensure virtual strategy execution cannot mutate live caches or shared memory.

3A — Transitional Cache Sandboxing (New)

In vts-runner.ts before executing strategies:

const localCache = new LocalCache();
globalThis.priceCache = new LocalCache();
globalThis.indicatorCache = new LocalCache();
globalThis.virtual = true;


After each simulation cycle:

delete globalThis.priceCache;
delete globalThis.indicatorCache;
delete globalThis.virtual;


✅ Effect: existing strategies keep working, but any cache writes occur in isolated local memory.

3B — Strategy Context Injection (Gradual Refactor)

Over time, update strategies to accept:

executeStrategy(symbol, timeframe, context: { virtual: boolean; cache: LocalCache });


Replace direct imports of priceCache/indicatorCache with context.cache.

3C — Worker Threads (Deferred)

Omit for now; revisit under Phase 11.3 – Parallel Simulation Infrastructure if concurrency becomes a bottleneck.

Task 4 — Telemetry Integration

📁 /server/services/telemetry-aggregator.ts

Goal: Record simulated trade data for learning while keeping it separate from live metrics.

Actions

Extend recordPairTelemetry() to accept source: 'live' | 'simulation'.

When source === 'simulation':

Write to telemetry.simulation namespace.

Exclude from operational P&L dashboards and risk models.

Retain for predictive learning datasets.
