## 🧩 Part B – Post-Migration Verification Script  

After all refactoring is complete and the app restarts successfully, execute the following automated verification commands to **prove the system is globally scoped**.

### 1️⃣ SQL Schema Inspection
```bash
# List every table still containing a user_id column
psql $DATABASE_URL -t -c "
SELECT table_name, column_name
FROM information_schema.columns
WHERE column_name ILIKE '%user_id%'
  AND table_schema='public'
ORDER BY table_name;"
```
✅ Expected Result:  
Zero rows returned except for the `users` table and `audit_logs`.

---

### 2️⃣ Database Data Consistency Check
```bash
# Verify one global row per mode for key configuration tables
psql $DATABASE_URL -t -c "
SELECT 'guardrails' AS tbl, mode, COUNT(*) FROM guardrails GROUP BY mode
UNION ALL
SELECT 'screener_filters', mode, COUNT(*) FROM screener_filters GROUP BY mode
UNION ALL
SELECT 'system_context', mode, COUNT(*) FROM system_context GROUP BY mode
UNION ALL
SELECT 'portfolio_state', mode, COUNT(*) FROM portfolio_state GROUP BY mode
ORDER BY tbl, mode;"
```
✅ Expected: Each table shows exactly one row per mode (`paper`, `live`).

---

### 3️⃣ API Response Audit
```bash
TOKEN=$(curl -s -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser123","password":"SecurePass123!"}' | \
  grep -o '"token":"[^"]*' | cut -d'"' -f4)

# Aggregate all JSON responses and scan for userId fields
for EP in trading/status trading/state paper-sim/filtered-pairs \
          filters/diagnostics guardrails screeners portfolio/state; do
  echo "=== Checking /api/$EP ==="
  curl -s -H "Authorization: Bearer $TOKEN" http://localhost:5000/api/$EP | jq '.' > /tmp/api_$EP.json
  grep -R "\"userId\"" /tmp/api_$EP.json && echo "⚠️ userId found in /api/$EP" || echo "✅ no userId in /api/$EP"
done
```
✅ Expected: All endpoints return “✅ no userId in /api/…”.
