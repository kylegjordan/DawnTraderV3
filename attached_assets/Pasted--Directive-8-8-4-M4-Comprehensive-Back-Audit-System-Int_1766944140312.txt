🧭 Directive 8.8.4-M4 — Comprehensive Back-Audit & System Integrity Verification
Purpose

Perform a complete, repository-wide back-audit of all adaptive, predictive, and trading subsystems implemented from Series L (8.8.4-L1 through L20) and Series M (8.8.4-M1 through M3B.2).
This ensures that:

Every directive’s formulas are correctly reflected in code,

Dependencies and data flows are synchronized,

Historical bugs or stale constants (e.g., DK decay) are fully removed, and

System metrics and learning loops produce valid, testable outputs before live simulation resumes.

🧩 Step 1 — Scope Definition

Modules under audit:

Core: CWQI, NGC, DI, DCE, ARA, VTS, MACO, MOF, GASP, PDC-ECS

Metrics & indices: relevance, stability, exposure, drawdown, context, drift, confidence

Learning systems: passive learning, VTS, retraining loop, adaptive weighting

UI/API coupling: ARA suggestions, Goals tab metrics, audit/report endpoints

🧩 Step 2 — Create Back-Audit Engine

File: server/services/back_audit_engine.ts

Responsibilities:

Traverse repository tree, verifying:

Presence of all directive-mandated constants, functions, and formulas

Absence of deprecated variables (e.g., SMOOTHING_ALPHA, DECAY_THEN_NORMALIZE)

Cross-check function signatures against directive specs (e.g., CWQI = α × profit_conf + β × vol_conf …).

Execute each module’s /status or /metrics endpoint to confirm active runtime consistency.

Correlate calculated outputs to expected value ranges and distributions.

Detect orphaned or circular dependencies (e.g., double-updates between DCE ↔ MOF).

Generate standardized audit reports.

🧩 Step 4 — Audit Sub-Modules

Each subsystem gets its own method:

Function	Checks
checkCWQI()	Valid coefficients, removal of decay terms, variance ≥ 0.01
checkNGC()	Proper normalization and correlation to actual returns
checkDCE()	All weights sum ≈ 1.0, Pearson recalibration active
checkVTS()	Mode ⇄ systemMode synchronization, buffer isolation
checkARA()	Risk/exposure derived from adaptive inputs
checkMOF()	Gradient descent parameters, clamped λ ranges
checkGASP()	Stability damping equations intact
checkPricingService()	Feed latency < 100 ms, cache ≥ 20 ticks
checkDriftDetector()	Threshold logic working (warn > 0.15, retrain > 0.25)
