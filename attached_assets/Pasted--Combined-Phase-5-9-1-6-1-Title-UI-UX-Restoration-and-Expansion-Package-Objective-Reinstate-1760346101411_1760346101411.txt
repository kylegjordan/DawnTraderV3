🧩 Combined Phase 5.9.1 + 6.1

Title: UI & UX Restoration and Expansion Package
Objective:
Reinstate the missing Reports Tab, unify all strategy-editing interfaces, enhance Walter’s user experience, and introduce the User Admin Tab inside Settings.
Result: a complete, consistent, easy-to-navigate interface where reporting, user management, strategy editing, and AI interaction all work together seamlessly.

🎯 Core Goals
#	Goal	Description
1	Restore Reports Tab	Re-add the “Reports” sidebar item with Trade History and Export Report / Diagnostics sections.
2	Unify Strategy UI	Ensure every trading strategy—new and old—has identical editable layouts and behaviors in the Goals Engine.
3	Enhance Walter Interface	Add file-upload analysis, live voice indicator, and remove duplicate chat panel so Walter is the single AI interaction hub.
4	Add User Admin Tab	Introduce a user-management area in Settings for viewing, adding, or editing user accounts.
5	Validate UI Consistency and Navigation	Confirm all new or restored features follow the same visual theme, typography, and routing patterns.
