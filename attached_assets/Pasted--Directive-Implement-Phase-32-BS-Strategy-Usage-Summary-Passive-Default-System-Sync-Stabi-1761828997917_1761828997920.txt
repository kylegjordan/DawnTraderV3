2️⃣ Passive Mode Default Behavior

Goal: Keep data flowing and models warm whenever trading is paused.

Changes

Modify SystemConfigService:

On startup, if mode ≠ live or paper, automatically set mode = passive.

Add daily auto-refresh of telemetry cache to prevent memory accumulation.

Update /api/system/config to persist and expose defaultMode = "passive".

Add log entry [PassiveMode] Activated by default — continuous learning enabled.

Benefits

Prevents cold-start gaps.

Maintains Lottie’s rolling context and SDPOE coherence.

3️⃣ Cross-User Mode Synchronization

Goal: Guarantee that toggling Paper/Live/Passive on one user session syncs to all connected users.

Additions

WebSocket broadcast from SystemConfigService → all active sessions.
Event payload:

{ "event": "MODE_CHANGE", "mode": "paper" }


UI auto-update across sessions within 2 s.

Add server-side audit line: [SystemSync] Mode changed → paper (broadcast OK).
