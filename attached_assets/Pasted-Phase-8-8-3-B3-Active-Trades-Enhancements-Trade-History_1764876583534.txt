1) Active Trades Table – Columns & Portfolio Summary

Goal: Give a clear view of how much is at risk in each trade and in total.

1.1 Add Quantity + Position Value column

Update client/src/components/trading/active-trades-v2.tsx:

Add a new stacked column “Qty / Value” with:

Top line: quantity (number of units)

Bottom line: positionValue = quantity * currentPrice

Use the current price from paper_sim_open_positions.current_price for positionValue.

Column order should be:

Symbol

Strategy

Qty / Value (stacked)

Entry

TP / SL (stacked)

Current

Distance (value, not %)

P/L $

P/L %

Duration

Slot

Actions

1.2 Portfolio summary strip above Active Trades table

Add a summary line above the Active Trades table (below the green integrity banner) that shows:

Starting Balance – paper trading starting balance for the current simulation (captured when user clicks “Start Trading”)

Current Balance – current portfolio equity:

currentBalance = cashBalance + Σ (positionValue) across all open positions

Net P/L ($) – currentBalance - startingBalance

Net P/L (%) – (currentBalance - startingBalance) / startingBalance * 100

Total Open Positions Value – Σ positionValue across all open trades

Requirements:

These values must update automatically as trades open/close and as prices update.

Current Balance & Total Open Positions Value should reflect live mark-to-market based on current_price.

If there is already a paper-trading balance service, reuse that instead of duplicating logic – but the math above is the source of truth.

3) Trade History Integrity – No Ghost Trades & Clean Analytics

Goal: The trade history list and analytics widgets should reflect real, fully-closed trades only.

3.1 Filter out ghost rows from Trade History table

In the Trade History list component (client/src/components/trading/trade-history-tab.tsx) and the backend query powering it:

Only include rows where:

closed_at IS NOT NULL

exit_price IS NOT NULL

close_reason IS NOT NULL

Any historical rows missing these fields should not appear in the UI list.

If needed, add a one-time migration / cleanup script to delete or fix malformed rows in paper_sim_trades (e.g. from earlier test sessions).

3.2 Exclude ghost rows from analytics widgets

In the analytics endpoint (e.g. /api/paper-sim/trades/analytics):

All widget counts and aggregates must be computed only for rows that satisfy:

closed_at IS NOT NULL

exit_price IS NOT NULL

close_reason IN ('target_hit', 'stop_hit', 'manual_close')
(ignore Unknown rows or treat them as invalid until we know why they exist)

Specifically:

Total Trades must count only valid closed trades

Win Rate, Avg Profit / Loss, Net P/L, etc. must be based on the same filtered set

This ensures ghost trades do not pollute the top cards.

3.3 Timestamps & header label

Ensure the Trade History list shows:

Opened At – full timestamp (date + time)

Closed At – full timestamp (date + time)

And the section header above the table should be:

“Trade History” (not “100 Trades”)

6) VWAP Target Bug – Quick, Safe Fix

Goal: Stop generating invalid long trades where target <= entry.

In server/services/strategy-engine.ts (or the equivalent):

Fix the target selection logic for long trades:

// Existing (buggy)
const targetPrice = high24h * 0.995;
const finalTarget = Math.min(targetPrice, twoRTarget);


Replace with:

const targetPrice = high24h * 0.995;
const finalTarget = Math.max(targetPrice, twoRTarget);


(For long trades we want the higher of the two candidates, not the lower.)

Add a safety validation before emitting the signal:

if (finalTarget <= entryPrice) {
  // Do not emit a trade signal if target is not above entry.
  return null; // or the local equivalent of "no valid signal"
}


Confirm that the orchestrator / validation layer still has:

if (signal.targetPrice <= signal.entryPrice) {
  return invalid;
}


so we have two lines of defence against inverted targets.

After this change, no new trades should be opened with targets below entry, and you should no longer see “Target Hit” closures that are actually losses from inverted TP logic.
