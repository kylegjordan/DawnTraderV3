🧱 Work Packages
A) Core Service — GuardrailPolicy

Create server/services/guardrail-policy.ts with:

Effective Value Resolution

Inputs: mode, raw DB row from guardrails_v2, optional manual payload.

Resolution: if is_manual_override = true OR locked_by_user[param] = true → prefer manual value; else use Lottie value.

Return a normalized object:

{
  mode: 'paper'|'live',
  portfolioRiskPerTradePct: number,
  symbolCooldownMinutes: number,
  maxOpenPositions: number,
  dailyLossKillSwitchPct: number,
  management: { isManualOverride: boolean, tunedByLatti: boolean, lockedByUser: Record<string, boolean> }
}


Coherency Validation

Load coherency_rules.yaml once; cache & hot-reload on file change.

Validate RULE_001 (risk ≤ kill/10), cooldown ≥ 1, positions ≥ 1, etc.

Produce {status: 'PASS'|'WARN'|'FAIL', failures?: RuleFailure[]}.

Conflict Detection

If both is_manual_override and tuned_by_latti true → emit RULE_005 error & block.

If incoming payload attempts to set manual values while Lottie owns field → emit guardrail.override.conflict.

Circuit Breakers

Add in-memory “daily kill switch” tripped state per mode; expose tripKillSwitch(mode) and isKillSwitchTripped(mode).

B) API Layer — Enforcement & Surfacing

PUT /api/guardrails-v2

Wrap updates with GuardrailPolicy.validate().

On FAIL → 400 with rule details.

On PASS → persist and emit guardrail.policy.updated with coherency status.

GET /api/guardrails-v2/effective?mode=

New route returning computed effective values + coherency (PASS/WARN/FAIL).

POST /api/guardrails-v2/kill-switch/trip?mode=

Trip the circuit breaker and broadcast guardrail.kill_switch.tripped.

C) Engine Integration (Runtime)

RiskManager

Replace direct DB reads with GuardrailPolicy.getEffective(mode).

Respect kill switch: abort new trades and close open ones if configured.

StrategyEngine / HeuristicTrader

Before order sizing: pull riskPct from policy.

Respect symbolCooldownMinutes and maxOpenPositions from policy only.

Remove use of any legacy fields.

LATTI Manager

When autotuning: refuse to adjust locked parameters; log latti.autotune.skipped_locked.

If coherency = FAIL: halt autotuning for mode and emit latti.autotune.blocked_by_policy.

D) Telemetry & Logs

Emit JSON logs with: ruleId, mode, param, oldValue, newValue, status.

Metrics counters:

policy_rule_fail_total{ruleId,mode}

policy_rule_warn_total{ruleId,mode}

kill_switch_trips_total{mode}

override_conflicts_total{mode}
