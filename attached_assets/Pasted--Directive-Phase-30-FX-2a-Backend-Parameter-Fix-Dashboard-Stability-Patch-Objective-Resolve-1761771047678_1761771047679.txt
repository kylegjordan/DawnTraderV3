Phase Steps

Part A – Backend Parameter Order Fix

Locate file: server/routes.ts

Find and replace incorrect API calls:

Change all instances like:

await storage.getTrades({});


to:

await storage.getTrades(mode, {});


And for other routes:

await storage.getEarningsSummary({});
await storage.getActivity({});


→ Replace with:

await storage.getEarningsSummary(mode);
await storage.getActivity(mode, { period });


✅ These updates ensure the correct mode ("paper" or "live") is passed as the first parameter to each call.

Part B – Frontend Render Guard for EarningsWidget

Locate file: client/src/components/goals/earnings-widget.tsx

Add array validation to prevent render crash:

Replace the start of the renderSparkline function with:

const renderSparkline = (sparklineData: any) => {
  if (!Array.isArray(sparklineData)) {
    console.warn("[EarningsWidget] Invalid sparklineData, skipping render", sparklineData);
    return null;
  }
  return (
    <Sparkline data={sparklineData.map(v => parseFloat(v))} />
  );
};


✅ This prevents .map() errors when backend returns invalid or empty data.
