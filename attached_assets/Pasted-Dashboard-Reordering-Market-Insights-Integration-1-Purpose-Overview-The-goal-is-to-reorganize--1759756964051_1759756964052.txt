Dashboard Reordering & Market Insights Integration
1) Purpose & Overview

The goal is to reorganize the dashboard layout to improve clarity, hierarchy, and usability, and to embed the AI Market Insights directly within the Daily Brief section for more cohesive context.

Key user experience updates:

Reorder dashboard sections in the following new layout:

Four KPI Widgets (Portfolio, Earnings, Trading Activity, Results)

Current Daily Briefing (moved up, includes Market Insights data)

Goals Summary

Portfolio Value Over Time

Earnings Over Time

Active Trades

Recent Trades

Strategy Performance

Market Insights should no longer appear as a standalone widget — it should now be embedded inside the Daily Brief box as a contextual section (using the most recent AI market analysis data).

This brings all short-term and long-term intelligence together for the user in one place before reviewing detailed trade and portfolio metrics.

2.2 Embed Market Insights inside the Daily Brief

File: client/src/components/briefs/daily-brief-section.tsx

Insert a new sub-section called “Market Context” or “AI Market Insights” within the Daily Brief render logic.

Example patch:

// client/src/components/briefs/daily-brief-section.tsx
import { useQuery } from "@tanstack/react-query";
import { apiRequest } from "@/lib/query";
import { useTradingMode } from "@/contexts/trading-mode-context";

export default function DailyBriefSection() {
  const { mode } = useTradingMode();

  // Fetch latest daily brief data
  const { data: brief, isLoading } = useQuery({
    queryKey: ["dailyBrief", mode],
    queryFn: () => apiRequest(`/api/briefs/current?mode=${mode}`),
  });

  // Fetch Market Insights data
  const { data: insights } = useQuery({
    queryKey: ["aiMarketAnalysis", mode],
    queryFn: () => apiRequest(`/api/market/ai-analysis?mode=${mode}`),
  });

  if (isLoading) return <div className="p-4">Loading daily briefing…</div>;

  return (
    <div className="bg-white shadow rounded-xl p-6 space-y-4">
      <h2 className="text-lg font-semibold">Current Daily Briefing</h2>

      {/* 🧠 Market Context Section */}
      {insights && (
        <div className="border-l-4 border-blue-400 pl-4">
          <h3 className="text-sm font-bold text-blue-700 uppercase tracking-wide">AI Market Insights</h3>
          <p className="mt-1 text-sm text-gray-700">{insights.summary}</p>
          <ul className="mt-2 list-disc list-inside text-sm text-gray-700">
            {insights.recommendations?.slice(0, 3).map((r: string, i: number) => (
              <li key={i}>{r}</li>
            ))}
          </ul>
          <p className="text-xs text-gray-500 mt-1">
            Regime: <span className="font-medium">{insights.regime}</span> · Confidence: {insights.confidence}%
          </p>
        </div>
      )}

      {/* 🗞 Main Daily Brief content */}
      <div className="mt-4 whitespace-pre-line text-gray-800 text-sm">
        {brief?.content || "No daily brief available for today."}
      </div>
    </div>
  );
}


Notes:

The Market Insights section will now appear inside the Daily Brief card.

Remove any standalone <MarketInsightsWidget /> imports.

Mode isolation (live/paper) is automatically respected via useTradingMode().
