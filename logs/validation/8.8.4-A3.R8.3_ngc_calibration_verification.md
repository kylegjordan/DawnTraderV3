# Directive 8.8.4-A3.R8.3: NGC Formula Calibration and Metric Scaling

## Date: 2025-12-18
## Status: ✅ IMPLEMENTED (Revision 3 - Final)

## Summary
This directive addresses the issue where NGC (Normalized Global Confidence) values were too low (0.10-0.12), causing 100% SQE rejection rate despite valid CWQI and ProfitRate values.

## Root Cause Analysis
1. **Multiplicative NGC Formula**: The formula `NGC = conf × (1 - vol) × (1 - risk)` produced compressed values
   - Example: conf=0.9, vol=0.3, risk=0.4 → NGC = 0.9 × 0.7 × 0.6 = 0.378
   - After normalization: ~0.11

2. **Double Normalization**: Values already in [0,1] range were being normalized again, causing further compression

3. **No Profitability in NGC**: Original NGC didn't incorporate profit rate, making it a poor indicator of signal quality

4. **CWQI Using Wrong NGC**: calculateCWQI() was recomputing NGC internally, ignoring the profitability-informed version

5. **VWAP ProfitRate Zero**: When target ≈ entry, expected return rounded to 0, triggering ProfitRate < 0.1 rejection

## Changes Implemented (Revision 3 - Final)

### 1. Conditional Normalization (quality_index.ts lines ~107-121)
- RollingNormalizer.normalize() now only normalizes if value is outside [0,1] range
- Prevents double-normalization of already-bounded metrics

### 2. BaseNGC Formula Recalibration (quality_index.ts lines ~279-284)
- **OLD Formula** (multiplicative): `NGC = conf × (1 - vol) × (1 - risk)`
- **NEW Formula** (additive): `NGC = (conf × 0.5) + ((1 - vol) × 0.3) + ((1 - risk) × 0.2)`
- Example improvement: conf=0.9, vol=0.3, risk=0.4
  - OLD: 0.378 (normalized to ~0.11)
  - NEW: 0.45 + 0.21 + 0.12 = 0.78

### 3. Profitability-Informed NGC (quality_index.ts lines ~677-686)
Implemented two-pass calculation in `calculateExtendedSignalMetrics`:
1. Compute base metrics (expectedReturn, riskScore, volatility, expectedDuration, profitRate)
2. Compute baseNGC from confidence/volatility/risk
3. Blend baseNGC with profitability:
```typescript
const profitabilityInformedNGC = (baseNGC * 0.4) + (profitRate * 0.4) + ((1 - riskScore) * 0.2);
const ngc = clamp01(profitabilityInformedNGC);
```

### 4. CWQI With Precomputed Metrics (quality_index.ts lines ~438-481)
Created new `calculateCWQIWithPrecomputedMetrics()` function that accepts pre-computed NGC and profitRate, ensuring the profitability-informed NGC is used in CWQI calculation.

`calculateExtendedSignalMetrics()` now uses this function instead of the original `calculateCWQI()`.

### 5. ProfitRate Floor (quality_index.ts lines ~355-377)
- Moved 0.15 floor from `calculateExpectedReturn()` to `calculateProfitRate()` where it belongs
- This keeps expected return truthful while preventing profit rate collapse
- Floor applied after normalization: `Math.max(normalizedRate, 0.15)`
