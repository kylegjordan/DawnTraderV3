## Critical Fix: Compounding Decay Prevention (2025-12-18)

The architect review revealed that the initial skipDecay implementation was incomplete:
- **Problem**: `signal.cwqi` was being overwritten with decayed values on each refresh, causing compounding decay
- **Solution**: Now reads TRUE original CWQI from `metadata.originalCwqi` (with fallback)
- **Result**: Decay is calculated from queuedAt using the true baseline, preventing compounding
