# Crypto Day Trading Web App

## Overview
This project is a long-only, spot-trading cryptocurrency day trading web application for Kraken. It automates advanced trading strategies, integrates real-time market scanning, disciplined risk management, and offers both live and paper trading capabilities. The application leverages OpenAI's GPT models for AI analysis, trade tracking, performance analytics, error diagnosis, and an autonomous learning engine. Its primary goal is to provide a comprehensive, resilient, and continuously improving self-optimizing trading platform, delivering a leading-edge solution in automated crypto trading with significant business and market potential.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture
The application features a React, TypeScript, Vite frontend with a mobile-first, responsive design, dynamic mode-aware UI, voice transcription, and a System Truth Panel. The backend uses Node.js with Express, providing a RESTful API and WebSocket support. Data is stored in PostgreSQL via Neon serverless driver and Drizzle ORM.

Core services include `KrakenService`, `TradingEngine`, `StrategyEngine`, `MarketScanner`, `RiskManager`, `AIAnalyst`, and `AIOpportunitiesService`, supporting 8 automated trading strategies and multi-layered risk management. Authentication uses username/password with bcrypt, JWT, and WebAuthn.

An AI Orchestrator & Command Center, powered by GPT-4o, provides insights through an AI SysAdmin Co-Pilot named Walter. Walter features a Unified Command & Conversation Layer, Semantic Memory Layer (pgvector and OpenAI embeddings), and an Intelligence Refinement Layer with a Self-optimizing Cognitive Weight Adjuster. A Paper Trading Simulation Engine provides real-time execution. The system incorporates a multi-module intelligent caching system (Bob Core) and a Hybrid Cortex Intelligent Memory Layer.

The system includes `SystemHealthMonitor`, `SelfRepairService`, a Natural Language Action Interpreter (NLAI), and a Contextual Intent Engine (CIE) for Walter's understanding and command execution. The Real-Time Execution Layer manages market data, execution timing, slippage modeling, rate control, and parity gating. A Unified Portfolio & Strategy State ensures a single source of truth, maintained by a `portfolio_state` table and `StrategySync` Service.

Walter's architecture is Hybrid Cognitive-Operational, with a Cognitive Layer for intent reflection and an Intent Gateway for validating operational commands with RBAC, risk assessment, and audit logging. All system outputs are routed through natural language interpretation via a Cognitive Interpreter Service and Event Broker. Data Provenance & Source Governance is ensured with `data_lineage` and `bob_trace_log` tables. Schema Binding Validation & Learning Alignment provides comprehensive validation of data sources and cognitive learning alignment. A `SecureCoreService` restricts Walter's domains when enabled. The Continuous Learning Pipeline extends the Event Broker to capture trade events, generate insights, and transfer knowledge from paper to live trading. A `StateAwarenessService` provides a single authoritative snapshot of the entire system state for Walter and UI components, injected into Walter's system prompt. An Intent Execution Framework provides safe, audited execution of validated intents with full RBAC, state validation, and provenance tracking, logging operations to `intent_audit_log`. A `Pre-Execution Validator` ensures every trade intent undergoes comprehensive validation before placement. The Context Bridge enables real-time, bidirectional synchronization between Walter's panel, chat widget, and backend systems via WebSocket broadcasting, logging all broadcasts to `context_bridge_log`.

The Reasoning Orchestrator enables Walter's multi-step transparent reasoning via Domain Bobs (DevOps, FullStack, UX, TradingBob) for contextual analysis, building execution plans, queuing domain-specific tasks, and logging complete reasoning traces to `reasoning_trace` and `reasoning_queue` tables. The Memory Lifecycle Manager ensures semantic memory integrity through automated checksum validation, auto-repair from file_persistence backup, and nightly learning feedback aggregation from trade insights into `learning_fragments`. An Async Task Queue provides distributed multi-domain reasoning with parallel execution, retry handling, and Context Bridge integration, using a PostgreSQL-backed queue with optimistic locking. Cognitive Tuning & Testing provides automated performance validation and tuning for Walter's cognitive subsystems via a benchmark harness with scenarios like Intent Parsing Accuracy, Multi-Domain Coordination, Memory Recovery & Integrity, Reasoning Trace Completeness, and Response Quality Metrics, storing results in `cognitive_tuning_log` and broadcasting via Context Bridge.

The Autonomy Layer introduces self-directed analysis, meta-reasoning, exploratory learning, and automated optimization capabilities, enabling Walter to operate with higher-order cognition and continuous self-improvement. Key components include `AutonomyController`, `MetaReasoningEngine`, `CuriosityEngine`, and `SelfOptimizer`, which manage self-checks, anomaly detection, recursive reasoning analysis, knowledge expansion, and performance optimization respectively. This layer also incorporates `TradingBob` for market, portfolio, and risk analysis during autonomous self-checks.

The Emergent Awareness Layer enables meta-cognitive state tracking, self-reflection, and operational context awareness. The `AwarenessCoreService` aggregates system health, cognitive performance, active domains, and recent actions into a unified awareness state stored in the `awareness_state_log` table. The `AwarenessScheduler` runs hourly state updates and 6-hour deep reflections for comprehensive self-analysis.

The Adaptive Learning & Goal Alignment Foundation enables experience-based learning, policy-aligned adaptation, and autonomous self-improvement. Core components include `ExperienceMemoryService` for capturing and synthesizing operational experiences, `AdaptiveObjectiveEngine` for managing goal alignment profiles and adapting objectives based on performance drift, and `AlignmentVerifier` for ensuring all system actions and adaptations comply with defined policies.

The Strategic Planner & Continuous Learning Model extends the Autonomy Layer with long-range strategic planning, continuous cognitive weight optimization, and policy-based guardrails. Core components include `StrategicPlannerService` for multi-phase strategic plan creation and progress tracking, `ContinuousLearningEngine` for adaptive cognitive weight adjustment through observation-adjustment-evaluation cycles, and `StrategicPolicyGuard` for enforcing strategic policies and ensuring compliance.

The Strategic Memory & Simulation Engine provides advanced decision forecasting and strategic lesson capture. `SimulationEngine` enables pre-execution strategy simulations with decision trace logging, allowing the system to evaluate potential actions before execution. `StrategicMemory` captures high-value lessons learned from simulations and operational experiences, with automated lesson extraction and applicability scoring.

The Reflective Intelligence Layer enables meta-cognitive self-reflection and decision quality analysis. `ReflectiveIntelligence` provides four reflection depth levels: surface, analytical, deep, and meta. `DecisionQualityAudit` conducts post-execution analysis of decisions, detecting cognitive biases and providing remediation guidance.

The Ethical Reasoning & Value Alignment Module enforces ethical constraints and value alignment across all system operations. `EthicalReasoningEngine` evaluates actions against defined ethical rules (e.g., risk limits, position sizing, user welfare) with pre-execution checks and blocking enforcement on violations. `ValueAlignmentService` manages the alignment matrix between system objectives and ethical values.

The Collaborative Cognition & Cross-Domain Reasoning Module enables multi-agent collaborative problem-solving through coordinated domain expert reasoning. `CollaborationManager` orchestrates collaborative sessions. `ReasoningBus` provides a message broker for cross-domain agent communication. `ConsensusEngine` evaluates agreement across agent inputs.

The Cooperative Learning Feedback Module (Phase 9.7) enables agents to learn from each other's outcomes through internal feedback loops. `LearningBridge` manages feedback recording, performance trend analysis, and learning summaries based on agent collaboration outcomes, self-checks, simulations, and reflections. Feedback is captured in the `agent_learning_feedback` table with metadata including agent name, domain, session ID, source type (collaboration/self_check/simulation/reflection), accuracy scores, and alignment scores. The `ConsensusEngine` integration automatically records feedback after consensus snapshots, enabling agents to improve based on collaborative outcomes. `AutonomyController` provides `updateLearningProfiles` for adaptive profile adjustments based on accumulated feedback. A dedicated Learning tab in the Enhanced System Monitoring UI displays agent performance metrics, learning statistics, top performers, and agents needing improvement. Safe scoring patterns prevent NaN/Infinity propagation in feedback data.

The Meta-Cognitive Oversight Engine (Phase 9.8) provides system-level bias detection, learning trend analysis, and cognitive health monitoring. `MetaCognitiveOversightService` analyzes reasoning traces and agent feedback to detect patterns of cognitive bias (confirmation, anchoring, recency), identifies learning trends (rapid improvement, stagnation, degradation), and flags systematic issues requiring intervention. Oversight data is logged to the `meta_cognition_log` table with detection timestamps, issue types, affected agents, severity levels, and actionable recommendations. The `AutonomyController` integrates oversight through `runMetaCognitiveCheck()` which performs comprehensive analysis across all autonomous subsystems. Three API endpoints provide oversight visibility: `/api/oversight/logs` for full oversight history, `/api/oversight/summary` for aggregated statistics by issue type and agent, and `/api/oversight/resolve` for marking issues as addressed. An Oversight tab in the Enhanced System Monitoring UI displays active flags, recommendations, and trend analysis. The Autonomous Task Scheduler runs meta-cognitive checks every 8 hours to maintain continuous oversight of the system's cognitive health.

The Long-Term Strategic Memory & Model Calibration Module (Phase 9.9) enables persistent knowledge archival and adaptive parameter tuning. `LongTermMemoryService` archives high-value insights from agent learning feedback into the `strategic_memory_archive` table, categorized by memory scope (short_term, medium_term, long_term) with performance delta tracking and strategic adjustments. The service performs historical performance analysis via `analyzePerformanceDelta()`, comparing recent agent accuracy (last 10 feedback entries) against historical baselines (10-30 entries) to identify improving, stable, or degrading trends. Model calibration is logged to the `model_calibration_log` table, recording parameter adjustments (old value → new value) with timestamp and rationale. The `AutonomyController` integrates strategic memory through `performStrategicCalibration()` which analyzes performance trends and adjusts cognitive parameters accordingly. Three API endpoints expose strategic memory: `/api/memory/archives` for archived insights with filtering by scope and agent, `/api/memory/calibration` for calibration history with parameter filtering, and `POST /api/memory/archive` for manual insight archival. A Memory tab in the Enhanced System Monitoring UI displays total archives, calibration history, and recent parameter adjustments with visual trend indicators. The Autonomous Task Scheduler performs strategic memory synchronization every 12 hours to maintain long-term knowledge persistence and adaptive tuning. Safe division-by-zero guards prevent crashes when historical accuracy data is zero or near-zero.

The Autonomous Task Scheduler coordinates all higher-order cognitive processes through 10 scheduled tasks: self-checks (every 6 hours), optimization (every 8 hours), strategy evaluation (every 12 hours), learning updates (every 4 hours), simulation evaluation (every 24 hours), reflection analysis (every 6 hours), collaboration maintenance (every 8 hours), learning feedback sync (every 6 hours), meta-cognitive oversight (every 8 hours), and strategic memory sync (every 12 hours).
